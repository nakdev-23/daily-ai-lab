# Stealth Mode — privacy

> Main reference: [Stealth Mode](https://docs.midjourney.com/hc/en-us/articles/32019750070669-Stealth-Mode)

---

## What is Stealth Mode

Stealth Mode (a mode that makes the images you create not appear in Midjourney's public gallery or Explore) is good for work needing privacy.

---

## Why use Stealth Mode

Normally, every image created on Midjourney (even in a Discord DM) appears in the public Explore. Stealth Mode prevents this.

### Cases where you should use it
- Client work needing confidentiality
- Projects not yet announced
- Personal work you don't want revealed
- Commercial work with a confidentiality agreement

---

## Conditions for using Stealth Mode

Stealth Mode is usable only on the **Pro and Mega plans** (not Basic and Standard).

---

## How to enable Stealth Mode

### On Discord
```
/stealth
```
Or through `/settings` and choose "Stealth Mode"

### On the web
- Go to Settings
- Toggle "Stealth Mode" to On

---

## Limitations of Stealth Mode

- Work created before enabling Stealth Mode remains Public
- You still see all your own work in the Archive
- Midjourney stores all work data, even in Stealth Mode
- Stealth Mode isn't a Delete — the Midjourney team can still see the work

---

## Toggle Stealth Mode anytime

- Enable Stealth Mode before starting Confidential work
- Disable Stealth Mode when returning to normal work
- The toggle takes effect immediately on work created afterward

---

## Visibility Settings

Even without the Pro plan, you can still set the Visibility of individual pieces:
- Right-click an image → "Make Private" (hide from Public)
- Or "Make Public" (open for viewing)

---

## Check the Stealth status

See whether Stealth Mode is enabled:
- Type `/info` in Discord — it shows "Stealth Mode: On/Off"
- On the web: see it at Settings or the Indicator on the Create page

---

## Stealth Mode and Watermark

Images created with Midjourney have no Watermark (a mark or text showing ownership) already, whether in Stealth Mode or not.

---

## Alternatives for the Standard plan

If you don't have the Pro plan but want privacy:

1. **Make Private individually** — right-click → "Make Private"
2. **Add the Bot to a private Server** — work is still Public but in a Server you can control
3. **Use DM with the Bot** — work is still Public but people in other rooms don't see it

---

## When Stealth Mode isn't enough

For work needing maximum confidentiality, such as Corporate work with an NDA (Non-Disclosure Agreement):
- Use Stealth Mode + Private Mode
- Consider using Midjourney's API instead (if available)
- Or use another AI tool offering higher privacy

---

## Summary

Stealth Mode is usable on the Pro/Mega plans to prevent all work from appearing publicly. If you don't have the Pro plan, you can still hide individual pieces with Make Private. Always enable Stealth Mode before starting Confidential work.
