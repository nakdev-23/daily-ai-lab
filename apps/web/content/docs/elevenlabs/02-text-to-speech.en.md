# Text to Speech — text becomes speech 🔊

> Adapted from the official documentation at [elevenlabs.io/docs](https://elevenlabs.io/docs), the Text to Speech section

**Text to Speech (TTS)** is ElevenLabs' main feature — type text and get natural speech. Use it for clip voice-overs, audiobooks, a speaking assistant, or teaching materials.

## 📖 Adjustable settings

| Setting | What it does |
|---|---|
| **Voice** | Choose the voice that speaks (from the Voice Library or a voice you cloned) |
| **Model** | The voice model, e.g. Multilingual (many languages), Flash (fast/low-latency) |
| **Stability** | The steadiness/consistency of the voice (low = varied, high = steady) |
| **Similarity** | How close it is to the original voice |
| **Style** | The emotion/color of the delivery |
| **Speed** | The speaking speed |

## 🌏 Languages and models

- The **Multilingual** model supports dozens of languages, including **Thai**
- The **Flash** model emphasizes speed/low latency, good for real-time work
- The model guesses the language from the input text automatically

## ✍️ Tips for natural-sounding speech

- Use **punctuation** correctly (periods, commas) to help the speech rhythm
- Want a pause? Use line breaks/ellipses
- Lower **Stability** if you want more emotion, raise it if you want a steady voice for formal work
- Try several voices/settings and compare

## ▶️ Steps

1. Go to **Text to Speech**
2. Choose a voice and model
3. Paste text (Thai/English/mixed is fine)
4. Adjust Stability/Style as you like, then hit generate
5. Listen → download (MP3, etc.)
