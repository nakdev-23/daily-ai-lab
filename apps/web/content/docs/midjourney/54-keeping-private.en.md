# Privacy of your work

> Main reference: [Keeping Your Creations Private](https://docs.midjourney.com/hc/en-us/articles/28014645615373-Keeping-Your-Creations-Private)

---

## Default privacy

By default, every piece of work created with Midjourney is **Public**, appearing in Explore for others to see.

---

## Privacy options

### 1. Stealth Mode (Pro/Mega plan only)
- All work created while Stealth Mode is on is Private
- Doesn't appear in Explore or the public Profile
- See the details in the Stealth Mode topic

### 2. Make Private (hide individual pieces)
Usable on all plans:
1. Go to the Archive
2. Right-click the image
3. Choose **"Make Private"**
4. The work hides from Public but you still see it in your own account

---

## Important points

- **Private ≠ Deleted** — Midjourney still stores the work
- The Midjourney team can always see work for security purposes
- If you really want to delete the data, you must contact Support

---

## Visibility of old work

Work that was created and already Public remains Public, even if you enable Stealth Mode later.

To hide old work:
1. Go to the Archive
2. Select images one at a time or several at once
3. Right-click → "Make Private"

---

## Bulk Privacy

You can select several images at once and change the Visibility in one go:
1. In the Archive, click the Checkbox in the image corner
2. Select the images you want
3. Click "Make Private" in the top bar

---

## The difference between Private and Delete

| Action | Result |
|---------|-----|
| Make Private | hide from public, but still in your account |
| Delete | remove from your account, but Midjourney may still keep it |
| Data Deletion Request | ask Midjourney to delete all your data |

---

## Requesting data deletion

If you want to delete all your data from the Midjourney system:
- Go to Account Settings → "Delete Account"
- Or contact Support via help.midjourney.com

---

## Summary

Use Make Private to hide some work without needing the Pro plan. If you want complete privacy for all newly created work, you must upgrade to Pro and enable Stealth Mode. For deleting all data, you must request it through Account Settings or Support.
