# Midjourney website overview

> Main reference: [Midjourney Website Overview](https://docs.midjourney.com/hc/en-us/articles/33329460426765-Website-Overview)

---

## The website's main page

When you log in at [midjourney.com](https://midjourney.com), you'll see a Navigation Bar (the bar that helps you travel to various parts of the web) on the left, with these main menus:

---

## Main menu

### Home
- The first page showing recent work and highlighting new features
- Has quick links to various parts of the web

### Explore
- **What it is:** the Public Gallery (a gallery open for everyone to view) of the Midjourney community
- See images created by users worldwide in Real-time
- **Click an image** to see the Prompt used to create it — the best way to learn
- Has Filters by style, such as Top, New, Hot
- You can Like or Save images you like

### Create
- **Your main image-creation area**
- Has a Prompt bar at the top
- Shows your Job Queue (the list of jobs waiting to be created)
- See images that just finished immediately

### Archive
- **Your personal gallery** — stores every image you've created
- Search images by Prompt or date
- Sort by Created, Liked, or Saved
- Download images from here

---

## Important components on the Create page

### Prompt Bar
- At the top of the Create page
- Type the description of the image you want in English
- Press **Enter** or click the **Generate** button to create the image

### Settings Panel
- Adjust the Aspect Ratio (e.g. 16:9 or 1:1)
- Choose the Model Version (the AI version used to create)
- Set various options like Stylize, Weird, Raw Mode

### Image Grid
- Shows 4 images at once after creation
- Click an image to enlarge it and access various options

---

## Options after creating an image

When you click a finished image, you'll see options:

| Button | Meaning |
|------|----------|
| **Upscale** | increase the image's resolution |
| **Vary** | create the same kind of image but adjust the details slightly |
| **Zoom Out** | expand the image's boundaries outward |
| **Pan** | shift the image's view in various directions |
| **Edit** | open the Editor to edit the image |
| **Download** | save the image to your device |
| **Share** | share the image link |

---

## Account settings

Click the profile picture in the top-right to access:

- **Account Settings** — set the email, password, notifications
- **Billing** — see the current plan, payment history
- **Subscription** — upgrade or cancel the plan
- **Visibility** — set the privacy of your work (Public/Private)

---

## Additional left-side Navigation

- **Folders** — folders to categorize images (you must create them yourself)
- **Liked** — images you liked from Explore
- **Moodboards** — boards collecting images for project planning
- **Style Creator** — a tool to create a personal style

---

## Tips for using the web

1. **Bookmark the Create page** — easy access, no need to travel through several pages
2. **Use Explore for Inspiration** — click an image you like and look at the Prompt to adapt it
3. **Save in Folders** — organize your work from the start; it'll be easier to find in the future
4. **Set Visibility** — if you want privacy, check whether your plan supports Stealth Mode

---

## Summary

The Midjourney website has a straightforward design. The most frequently used main pages are **Create** and **Archive**, while **Explore** is the best learning resource for beginners.
