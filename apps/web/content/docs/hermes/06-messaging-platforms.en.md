# Messaging Platforms — reach Hermes from chat apps

> Compiled from the official docs at [hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs/), the Messaging Platforms section

Besides the Terminal UI, Hermes runs a **Gateway** so you can talk to it from the chat apps you use daily — supporting **20+ platforms** from one gateway.

## 💬 Supported platforms (examples)

- **Telegram**
- **Discord**
- **Slack**
- **WhatsApp**
- **Signal**
- **Email**
- and more, over 20 platforms total

## 🔌 How connecting works (overview)

1. Run Hermes's **Gateway**
2. Configure/enter the credentials of the platform you want (e.g. a bot token)
3. Message Hermes in that app — and use the same **slash commands** as the Terminal UI

## 💡 Benefits

- Talk to the same assistant (same memory + skills) from anywhere
- Great for instructing/checking status during the day without opening the terminal

> See setup details for each platform in the official docs, and see model connections in the **Integrations** section
