# Extend และ Crop — ขยายและตัดเพลง

หนึ่งในปัญหาที่พบบ่อยที่สุดคือ "เพลงสั้นเกินไป" Suno มีสองฟีเจอร์สำคัญที่ช่วยจัดการเรื่องนี้: **Extend** (ขยายเพลง) และ **Crop** (ตัดเพลง)

---

## เพลง Suno ยาวแค่ไหน?

เพลงที่สร้างจาก Suno มีความยาวตามรุ่น:

| Model (โมเดล) | ความยาวเริ่มต้น | ความยาวสูงสุดหลัง Extend |
|-------------|--------------|----------------------|
| **v4** | ~2–4 นาที | ~8 นาที |
| **v4.5** | ~2–4 นาที | ~8 นาที |
| **v5** | ~2–4 นาที | ~8 นาที |

> เพลงหนึ่งเพลงสามารถ Extend ได้หลายรอบจนถึงความยาวสูงสุดประมาณ 8 นาที

---

## Extend (ขยายเพลง)

**Extend** คือฟีเจอร์ที่ช่วยต่อเพลงให้ยาวขึ้นจากจุดที่หยุด โดย AI จะสร้างส่วนต่อเนื่องให้ฟังดูสมูท (ต่อเนื่องกันได้ดี)

### วิธีใช้ Extend

1. เปิดเพลงที่ต้องการขยาย
2. คลิกปุ่ม **"..."** (จุดสามจุด) หรือเมนู Options
3. เลือก **"Extend"** (ขยาย)
4. Suno จะสร้างส่วนต่อใหม่ต่อจากเพลงเดิม
5. ตรวจสอบผลและทำซ้ำได้หากต้องการยาวขึ้น

### Extend Options (ตัวเลือกการขยาย)

เมื่อคลิก Extend คุณสามารถ:

- **ปล่อยให้ AI ตัดสินใจ** — AI จะต่อเพลงตามสไตล์เดิม
- **กำหนด Lyrics ใหม่** — ใส่เนื้อเพลงสำหรับท่อนต่อไป
- **กำหนด Style ใหม่** — เปลี่ยนสไตล์เล็กน้อยสำหรับ Bridge หรือ Outro
- **เลือกจุดเริ่มต้น** — กำหนดว่าให้ต่อจากวินาทีที่เท่าไร

### ใช้ Extend เพื่อสร้างโครงสร้างเพลงสมบูรณ์

วิธีที่มือโปรนิยมใช้:

```
ขั้นที่ 1: สร้างเพลง (Verse + Chorus)
ขั้นที่ 2: Extend เพิ่ม Bridge
ขั้นที่ 3: Extend เพิ่ม Chorus ซ้ำ
ขั้นที่ 4: Extend เพิ่ม Outro
```

ผลลัพธ์ = เพลงสมบูรณ์แบบมีโครงสร้างครบ

## Crop (ตัดเพลง)

**Crop** (ตัด — ตัดส่วนที่ไม่ต้องการออกจากเพลง) ช่วยให้คุณเลือกเฉพาะส่วนที่ดีที่สุดของเพลงได้

> **หมายเหตุ:** Crop เป็นฟีเจอร์สำหรับผู้ใช้ **Pro** และ **Premier** เท่านั้น

### วิธีใช้ Crop

1. เปิดเพลงที่ต้องการตัด
2. คลิกปุ่ม **"..."** แล้วเลือก **"Crop"**
3. ลาก Handle (จุดจับ) บน Timeline (เส้นเวลา) เพื่อเลือกช่วงที่ต้องการ
4. คลิก **"Confirm"** หรือ **"Save"**

### ใช้ Crop เมื่อ:

- เพลงมีส่วนเริ่มต้นที่ไม่ดี ต้องการตัดทิ้ง
- ส่วนท้ายเพลงยาวเกินไป
- ต้องการเฉพาะท่อน Chorus สำหรับนำไปใช้งาน

---

## Replace Section (เปลี่ยนส่วนเพลง)

**Replace Section** (เปลี่ยนส่วน — แทนที่ส่วนที่ไม่ถูกใจด้วยส่วนใหม่) เป็นฟีเจอร์ที่ช่วยแก้ไขเฉพาะจุดได้โดยไม่ต้องสร้างเพลงใหม่ทั้งหมด

### วิธีใช้ Replace Section

1. เปิดเพลงในโหมดแก้ไข
2. เลือกส่วนที่ต้องการเปลี่ยน (ลากบน Timeline)
3. คลิก **"Replace Section"**
4. ระบุ Lyrics หรือ Style ใหม่สำหรับส่วนนั้น
5. AI จะสร้างส่วนใหม่แทนส่วนเดิม

### ตัวอย่างการใช้ Replace Section

- เสียงร้องท่อนที่ 2 ไม่ดี → ใช้ Replace Section เฉพาะท่อนนั้น
- Bridge ฟังดูไม่เข้ากับเพลง → เปลี่ยน Bridge โดยไม่กระทบส่วนอื่น
- ต้องการเนื้อเพลงต่างออกไปในท่อนเดิม → แทนที่เฉพาะ Lyrics

## เคล็ดลับการใช้ Extend อย่างมีประสิทธิภาพ

### 1. วางแผนโครงสร้างล่วงหน้า

ก่อนสร้างเพลง วางแผนว่าต้องการกี่ท่อน:
```
Intro (4 bars) → Verse 1 → Pre-Chorus → Chorus → Verse 2 → Chorus → Bridge → Chorus → Outro
```

### 2. Extend ทีละขั้น

อย่า Extend ยาวเกินไปในครั้งเดียว ให้ทำทีละ 1–2 นาที เพื่อตรวจสอบคุณภาพ

### 3. ใส่ Lyrics ใน Extend

ถ้าใส่ Lyrics สำหรับส่วนต่อ เพลงจะดูต่อเนื่องมากกว่าให้ AI คิดเอง:
```
[Bridge]
บางวันมันยาก บางวันมันเจ็บ
แต่ฉันก็ยังสู้ ไม่ยอมแพ้ง่าย ๆ
```

### 4. ระวังการเปลี่ยนสไตล์กะทันหัน

ถ้า Extend และเปลี่ยน Style ไปเลย อาจทำให้เพลงฟังดูสะดุด ควรค่อย ๆ เปลี่ยน

## FAQ เกี่ยวกับ Extend

**Q: ขยายได้กี่ครั้ง?**
A: ขยายได้หลายครั้งจนถึงความยาวรวมประมาณ 8 นาที

**Q: เพลงที่ Extend แล้วจะฟังดูต่อเนื่องไหม?**
A: AI ออกแบบมาให้ต่อเนื่องได้ดี แต่บางครั้งอาจสะดุดเล็กน้อย ลองสร้างใหม่หากไม่พอใจ

**Q: Extend ได้กับเพลงทุกเพลงไหม?**
A: ได้กับเพลงทุกเพลงที่สร้างใน Suno แต่เพลงเก่า ๆ ที่สร้างด้วยโมเดลเก่าอาจมีข้อจำกัด

**Q: ถ้า Extend แล้วไม่ดี ลบได้ไหม?**
A: ส่วนที่ Extend จะเป็นเพลงใหม่ ลบทิ้งได้โดยไม่กระทบเพลงต้นฉบับ
