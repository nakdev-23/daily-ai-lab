# Image Generation — create images with AI

> Primary reference: [OpenAI Help Center — ChatGPT](https://help.openai.com/en/collections/3742473-chatgpt)

---

## What is Image Generation

ChatGPT can create images directly from a text prompt (a description typed as text to instruct the AI to create an image) using OpenAI's image models (the trained AI program):

- **DALL-E 3** (October 2023): the 3rd-generation image model that understands natural-language prompts better than before
- **GPT Image (gpt-image-1)** (March 2025): the latest model that creates more realistic and detailed images

---

## How to create an image

### Creating an image from text

Just type a description of the image you want in the chat:

**Simple command example:**
> *"Draw an orange cat sitting on a house roof in the evening"*

**Detailed command example:**
> *"A cinematic-style photo (movie style — with quality lighting, shadow, and camera angles) of a futuristic city at night, with purple and blue neon lights, light rain reflecting on the road, no people in the frame"*

### How to turn it on

1. Start a new chat
2. Click the **"+"** icon or "View tools"
3. Choose **"Create image"** or **"DALL-E"**
4. Or just type an image-creation command — ChatGPT enables it automatically

## Supported styles and formats

### Art styles

| Style | Keywords to use |
|---|---|
| Photorealistic (realistic like a photo) | "photo realistic", "DSLR photo", "8K" |
| Oil Painting | "oil painting", "impasto style" |
| Watercolor | "watercolor", "soft watercolor" |
| Digital Art | "digital art", "concept art" |
| Anime / Manga | "anime style", "manga", "Studio Ghibli" |
| Cartoon | "cartoon", "illustration", "flat design" |
| Pixel Art (an old-game style) | "pixel art", "16-bit", "retro game" |
| Sketch | "pencil sketch", "charcoal drawing" |
| 3D Render (a 3D image made with a computer) | "3D render", "Unreal Engine", "Blender" |
| Minimalist (simple design, cutting everything unnecessary) | "minimalist", "simple", "clean design" |

### Size and aspect ratio (the ratio between an image's width and height)

- **1:1 (Square)**: good for social media, profile pictures
- **16:9 (Landscape)**: good for wallpaper, YouTube thumbnails
- **9:16 (Portrait)**: good for Stories, TikTok, mobile posters
- **2:3 / 3:2**: good for print

## Editing and improving images

### Iterative editing (editing step by step — keep improving the image without starting over)
After creating an image, you can ask for edits in the same conversation:
> *"Great, but make the tree on the left look more lush"*
> *"Change the background color from blue to sunset orange"*

### Image-to-Image (editing an existing image — feed an image in and have the AI modify it)
Upload an image you have and ask the AI to edit it:
- Add or remove elements in the image
- Change the background
- Adjust color, light, or atmosphere
- Convert the image's style (e.g. turn a photo into anime)

## Tips for writing a good prompt

### The SDAC principle
- **Subject**: what it is — "an orange cat"
- **Detail**: characteristics — "curled up, eyes half-closed"
- **Action/Atmosphere**: the mood — "evening, golden light, warm"
- **Context/Style**: the format — "realistic photo style, f/1.8"

### Good vs bad prompt examples

| Bad | Better |
|---|---|
| "Draw a house" | "A two-story wooden Japanese-style house, with a cherry-blossom garden in front, shot in a wide angle, in the morning" |
| "A pretty person" | "A 25-year-old Thai woman, a sweet smile, wearing a gold Thai dress, with an ancient Thai temple in the background" |
| "Stars" | "The Milky Way galaxy in a clear night sky, with a mountain range below, in 4K astrophotography style" |

## Limits and what ChatGPT refuses

ChatGPT will **not create images** with the following content:
- Images of real people that could be misleading (deepfakes — faking faces or voices with AI)
- Violent, pornographic, or harmful content
- Images that infringe copyright or directly imitate an artist
- Content that is political or could create hatred
