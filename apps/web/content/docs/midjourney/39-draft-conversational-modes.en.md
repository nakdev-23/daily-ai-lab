# Draft and Conversational Modes

> Main reference: [Draft Conversational Modes](https://docs.midjourney.com/hc/en-us/articles/35577175650957-Draft-Conversational-Modes)

---

## Draft Mode

Draft Mode (a fast image-creation mode using fewer resources, good for testing a Prompt before creating a real image) lets you test a Prompt quickly using less GPU Time.

### Characteristics of Draft Mode
- Creates images **faster** than normal mode
- Uses **less GPU Time** (saves about 50%)
- Slightly **lower** resolution
- Good for a **Prototype** (a test image before creating for real)

### How to use Draft Mode
- On the website: choose **"Draft"** in Settings before creating
- Or find it in the options before Generate

### When to use Draft Mode
- Testing a new Prompt you're not sure about
- Creating many options to choose from
- Work needing frequent Iteration
- When GPU Fast Time is running low

---

## Conversational Mode

Conversational Mode (a mode that lets you interact with Midjourney like chatting with an assistant, where the AI remembers the previous conversation context and adjusts the image per your request) makes a Workflow needing repeated image adjustments easier.

### How it works
1. Create the first image with a Prompt
2. Tell the AI what you want to adjust, in natural spoken language
3. The AI remembers the context and creates a new image as requested

**Example:**
```
First Prompt: "a cozy living room"
You: "make it more minimalist and add plants"
AI: creates a Minimalist living room with plants
You: "add a cat on the sofa"
AI: creates the same room but adds a cat on the sofa
```

### Advantages of Conversational Mode
- No need to write a whole new Prompt each time
- The AI understands the previous conversation context
- Good for quick Iteration
- You can use natural spoken language

### Limitations
- Usable only on the website (not in Discord)
- The context resets when you start a new Session

---

## Using Draft + Conversational together

An efficient strategy:
1. Enable **Draft Mode** to test the Concept quickly
2. Once satisfied with the direction, turn off Draft Mode
3. Use **Conversational Mode** to Fine-tune the details
4. Create a full-quality Final image and Upscale

---

## Summary

Draft Mode saves GPU Time during testing, while Conversational Mode makes adjusting images easier through natural conversation. Both modes are used only on the Midjourney website.
