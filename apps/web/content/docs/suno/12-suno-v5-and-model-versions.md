# โมเดล Suno — v4, v4.5, v5 และ v5.5

Suno พัฒนาโมเดล AI สำหรับสร้างเพลงอย่างต่อเนื่อง แต่ละรุ่นมีความสามารถที่ดีขึ้นและฟีเจอร์ใหม่ ๆ ที่เพิ่มมา ส่วนนี้จะอธิบายประวัติและความแตกต่างของแต่ละโมเดล

---

## Suno Model Timeline (ไทม์ไลน์โมเดล)

```
2024:
├── v3     — มีนาคม 2024 (รุ่นแรกที่โด่งดัง)
├── v4     — พฤศจิกายน 2024 (กระโดดครั้งใหญ่)
└── v4.5   — พฤษภาคม 2025 (Artist Update)

2025-2026:
├── v5     — กันยายน 2025 (ก้าวกระโดดครั้งสำคัญที่สุด)
└── v5.5   — มีนาคม 2026 (Voices + Custom Models + My Taste)
```

---

## Suno v4 — What's New?

**v4** (พฤศจิกายน 2024) เปิดตัวพร้อมกับ:

- **ความยาวเพลงสูงสุด 4 นาที** (เพิ่มขึ้นจาก v3)
- **คุณภาพเสียงที่ดีขึ้นมาก** — ฟังดูเป็นธรรมชาติมากขึ้น
- **Vocal Clarity** (ความชัดเจนของเสียงร้อง) ที่ปรับปรุงแล้ว
- **Instrumental Detail** (รายละเอียดดนตรี) ที่ซับซ้อนขึ้น

---

## Suno v4.5 — Artist Update

**v4.5** (พฤษภาคม 2025) เน้นให้ผู้ใช้ควบคุมได้มากขึ้น:

### ฟีเจอร์ใหม่ใน v4.5

| ฟีเจอร์ | คำอธิบาย |
|--------|---------|
| **Creative Sliders** (สไลเดอร์ความสร้างสรรค์) | ปรับระดับ Randomness และ Creativity ของ AI |
| **Better Prompts in Lyrics** | ใส่คำสั่งในเนื้อเพลงได้ละเอียดขึ้น |
| **Audio Uploads** (อัปโหลดเสียง) | นำเสียงของคุณเข้ามาใช้ได้ |
| **Song Editor** | แก้ไขส่วนต่าง ๆ ของเพลงได้ง่ายขึ้น |
| **Stem Extraction** | แยกเสียงร้องออกจากดนตรี |
| **Add Vocals** | เพิ่มเสียงร้องเข้าไปในเพลง Instrumental |
| **Inspire** | ปุ่มสำหรับสร้างแรงบันดาลใจ Prompt ใหม่ |
| **Detailed Style Instructions** | ระบุ Style ได้ละเอียดกว่าเดิม |

### Creative Sliders (สไลเดอร์ความสร้างสรรค์)

**Creative Sliders** มีสองแกน:

```
Creativity (ความสร้างสรรค์):
Conservative ◄──────────────────► Experimental
(อนุรักษ์นิยม)                  (ทดลองสร้างสรรค์)

Intensity (ความเข้ม):
Subtle ◄──────────────────► Intense
(เบาบาง)                   (เข้มข้น)
```

## Suno v5 — ก้าวกระโดดครั้งสำคัญ

**v5** (กันยายน 2025) Suno เรียกว่า "Intelligent Composition" (การแต่งเพลงอัจฉริยะ) เปิดตัวครั้งแรกสำหรับ Pro และ Premier

### ความสามารถใหม่ใน v5

- **Intelligent Composition** — AI เข้าใจโครงสร้างดนตรีในระดับลึกกว่าเดิม
- **เพลงยาวได้ถึง 8 นาที** โดยตรง (ไม่ต้อง Extend หลายรอบ)
- **Better Vocal Emotion** (อารมณ์เสียงร้องที่ดีขึ้น) — AI ร้องแสดงความรู้สึกได้แนบเนียนมากขึ้น
- **Multi-genre Blending** (ผสมแนวเพลงได้ดีขึ้น) — เพลงที่ผสมหลาย Genre ฟังดูเป็นธรรมชาติ
- **Improved Lyrics Alignment** — เนื้อเพลงตรงกับดนตรีได้ดีกว่าเดิม

### Remaster ใน v5

**Remaster** (รีมาสเตอร์ — การสร้างเพลงเวอร์ชันปรับปรุงจากเพลงเดิม) ใน v5 ช่วยให้คุณ:

- นำเพลงเก่า (v3 หรือ v4) มา Remaster ด้วยโมเดลใหม่
- ได้เสียงที่คุณภาพดีขึ้นโดยไม่ต้องสร้างใหม่ทั้งหมด
- สร้าง "Variation" (เวอร์ชันเล็กน้อยแตกต่าง) ของเพลงเดิม

## Suno v5.5 — Voices, Custom Models, My Taste

**v5.5** (มีนาคม 2026) เพิ่มความ Personalized มากขึ้น:

### Voices — ใช้เสียงของคุณ

**Voices** (เสียง) ช่วยให้คุณ:

- บันทึกเสียงของตัวเองและนำมาใช้ใน Suno
- สร้างเพลงที่ AI ร้องด้วยเสียงที่ Inspired โดยเสียงคุณ
- ปรับ Vocal Tone และ Character ตามต้องการ

> **สำคัญ:** Suno มีมาตรการป้องกันการใช้เสียงผู้อื่นโดยไม่ได้รับอนุญาต

### Custom Models (โมเดลกำหนดเอง)

**Custom Models** ใน v5.5 ช่วยให้คุณ:

- "Train" (ฝึก — สอน AI ให้เรียนรู้สไตล์เพลงของคุณ) โมเดลของตัวเอง
- บันทึก Sonic Identity (เอกลักษณ์เสียง) ของคุณ
- สร้างเพลงที่มี "เสียงแบบฉัน" ได้อย่างสม่ำเสมอ

### My Taste (รสนิยมของฉัน)

**My Taste** เป็นระบบที่:

- เรียนรู้จากเพลงที่คุณกด Like หรือสร้างบ่อย
- ปรับ Recommendation (การแนะนำ) ให้ตรงกับความชอบ
- ช่วยให้ Create Page แนะนำ Style ที่คุณน่าจะชอบ

## วิธีเลือกโมเดล

ใน Create Page คุณสามารถเลือก Model ได้ (สำหรับแผน Pro+):

1. คลิกที่ปุ่ม **Model** หรือ **Version** บนหน้า Create
2. เลือกโมเดลที่ต้องการ
3. โมเดลล่าสุด (v5.5) จะเป็น Default (ค่าเริ่มต้น)

### เมื่อไหร่ควรใช้โมเดลเก่า?

- **v4** — เมื่อต้องการเสียงแบบ "Classic Suno" ที่ผู้ใช้เก่าคุ้นเคย
- **v4.5** — เมื่อต้องการ Audio Upload แต่ไม่ต้องการ v5's Complexity
- **v5** — สำหรับงานคุณภาพสูงและเพลงที่ยาวขึ้น
- **v5.5** — เมื่อต้องการ Personalization สูงสุด

## Model Availability Update

ตาม Suno Model Availability Update (กันยายน 2025):

- **v3** ถูกปลดออกจาก Create และยังคงเข้าถึงได้ผ่านเพลงเก่า
- **v4 และ v4.5** ยังคงใช้งานได้
- **v5** เปิดให้ Pro/Premier ก่อน แล้วจึงเปิดให้ทุกคน
- **v5.5** เปิดตัว มีนาคม 2026
