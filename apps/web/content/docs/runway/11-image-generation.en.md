## How to create images with Runway

### Step 1: Choose a model

1. Go to the **"Image"** or **"Text to Image"** menu
2. Choose the model you want from the list

### Step 2: Write a Prompt

A good **Text-to-Image Prompt** should have:

```
[Subject] + [Description] + [Style] + [Lighting] + [Composition]
```

**Examples of good Prompts:**

For a Portrait:
```
A young Japanese woman with short black hair, wearing a red kimono, 
standing in a bamboo forest, soft morning light, 
photography style, shallow depth of field, 
highly detailed, 8K
```

For a Landscape:
```
Ancient temple ruins in a tropical jungle, 
golden sunset light filtering through trees, 
atmospheric fog, painterly style, 
reminiscent of Studio Ghibli, highly detailed
```

For a Product:
```
Minimalist perfume bottle on white marble surface, 
soft studio lighting, commercial photography style, 
ultra detailed, photorealistic
```

### Step 3: Choose the Aspect Ratio and Resolution

Supported **Aspect Ratios**:
- **1:1** (Square) — Instagram, Profile pictures
- **4:3** — the digital camera standard
- **16:9** (Landscape) — YouTube, Desktop wallpaper
- **9:16** (Portrait) — TikTok, Instagram Stories

### Step 4: Generate and Refine

1. Click **"Generate"**
2. View the result
3. If unsatisfied, edit the Prompt and Generate again
4. Or use **"Variations"** to create similar but slightly different images

## Using Reference Images

**Reference Images** (images used to define a style or characteristic) help the AI understand what style you want.

### In Gen4 Image:

**Method 1: Tagged Reference**
- Upload a Reference Image
- Tag the image with `@name`, e.g. `@mycharacter`
- Use the Tag in the Prompt: `"A character like @mycharacter in a forest"`

**Method 2: Untagged Reference (for style)**
- Upload a Reference Image without tagging
- The AI uses it as style inspiration without copying directly

## Image-creation tips

### 1. Specify proportions and size
```
full body portrait
head and shoulders
landscape shot
extreme close-up
```

### 2. Specify the number of objects
The AI often gets confused creating multiple objects; specify clearly:
```
One person standing alone
Two people facing each other
```

### 3. Avoid contradictory words
```
Bad: "dark but bright"
Better: "moody dark background with single bright spotlight"
```
