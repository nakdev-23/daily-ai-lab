# 09 — Canvas — สร้างเอกสาร, แอป, สไลด์

อ้างอิง: [Create docs, apps & more with Canvas](https://support.google.com/gemini/answer/16047321) | [Quizzes & Flashcards](https://support.google.com/gemini/answer/16275879)

---

## Canvas คืออะไร

**Canvas** คือพื้นที่ทำงานร่วมกับ Gemini แบบ real-time ที่แสดงผลข้างๆ แชท คุณสามารถสร้างหรือแก้ไข:

- **เอกสาร (Docs)** — บทความ รายงาน จดหมาย
- **สไลด์ (Presentations)** — slide deck พร้อมดีไซน์
- **แอปและเว็บเพจ** — แอปง่ายๆ, เว็บเพจ, เครื่องมือโต้ตอบ
- **โค้ด (Code)** — เขียนและรัน Python, JavaScript ฯลฯ
- **Quiz และสื่อการเรียนรู้** — ทดสอบความรู้แบบ interactive
- **Infographic** — ภาพ infographic จากข้อมูล

---

## วิธีเริ่มใช้ Canvas

1. ไปที่ [gemini.google.com](https://gemini.google.com)
2. คลิก **Add Files** → **Canvas**
3. พิมพ์ prompt อธิบายสิ่งที่ต้องการสร้าง
4. คลิก Submit

**ตัวอย่าง Prompt:**
```
"Create a slide presentation about climate change with 5 slides"

"Make a quiz to test me on Python basics"

"Write a professional cover letter for a software engineer position"

"สร้าง web app คำนวณ BMI ง่ายๆ"

"ทำ infographic แสดงข้อดีของการออกกำลังกาย"
```

## ทำอะไรกับ Doc ใน Canvas ได้บ้าง

### แก้ไขข้อความโดยตรง
คลิกในพื้นที่ Canvas แล้วพิมพ์แก้ไขได้เลย การเปลี่ยนแปลงบันทึกอัตโนมัติ

### ขอให้ Gemini แก้ไขบางส่วน
1. เลือกข้อความที่ต้องการแก้ใน Canvas
2. พิมพ์ prompt ในช่องข้อความว่าต้องการเปลี่ยนอะไร
3. กด Enter

หรือเลือกข้อความแล้วคลิก **Suggest edits** ให้ Gemini แนะนำการแก้ไข

### ปรับความยาวและโทน (Quick Edits)
ในแผง Canvas ด้านขวา:
- **Change length** — ปรับให้สั้นลงหรือยาวขึ้น
- **Change tone** — ปรับให้เป็นทางการมากขึ้น หรือเป็นกันเองมากขึ้น

### จัดรูปแบบข้อความ (Toolbar)
เลือกข้อความแล้วใช้ toolbar ด้านบน:
- หัวข้อ (Headings)
- ตัวหนา (**Bold**)
- ตัวเอียง (*Italic*)
- รายการ Bullet/Numbered

### เพิ่ม LaTeX (สูตรคณิตศาสตร์)
1. คลิก **Create** ในแผง Canvas → **LaTeX**
2. คลิกสูตรใน Canvas เพื่อแก้ไข

> LaTeX ที่ export เป็น PDF จะแสดงสูตรได้อย่างถูกต้อง

## ทำอะไรกับ App/Code ใน Canvas ได้บ้าง

### แก้ไขโค้ดโดยตรง
คลิก **Code** (มุมบนขวาของ Canvas) เพื่อดูและแก้ไขโค้ดได้เลย

### ดู Console Logs
คลิก **Show console** เพื่อดู error และ log จากการรันแอป

### ดู Recent Changes
คลิก **Code** → **Show recent changes** เพื่อดูสิ่งที่เปลี่ยนแปลงล่าสุด

### เพิ่มฟีเจอร์ AI ในแอป
1. คลิก **Add Gemini features** ในแผง Canvas
2. Gemini จะเพิ่มความสามารถ AI เข้าไปในแอป เช่น text generation, image generation

### Export Python ไป Colab
1. เปิดแชทที่มี Python code
2. คลิก **Export to Colab** ที่ด้านบน Canvas

## สร้างอะไรต่อจาก Doc ใน Canvas

จาก Document ที่สร้างในแผง Canvas คุณสามารถสร้างต่อเนื่องได้:

1. คลิก **Create** ในแผง Canvas
2. เลือกสิ่งที่ต้องการสร้าง:
   - **สไลด์** — พิมพ์ prompt อธิบาย
   - **Audio Overview** — ฟังรายงานแบบ Podcast
   - **Quiz** — ทดสอบความรู้จากเนื้อหา
   - **Infographic** — ภาพสรุปข้อมูล
   - **Web page** — แปลงเนื้อหาเป็นหน้าเว็บ

> ฟีเจอร์นี้ต้องอายุ 18 ปีขึ้นไป

## แชร์, Copy, และ Export จาก Canvas

### แชร์ Canvas
1. คลิก **Share & export** → **Share**
2. คัดลอกลิงก์ g.co/gemini/share แล้วส่งให้ใคร
3. หรือแชร์ผ่าน Social Media ที่รองรับ

> **ข้อสำคัญ:** เมื่อแชร์แอป ทุกคนที่มีลิงก์สามารถดูและโต้ตอบกับข้อมูลได้

### Export เอกสาร
- **Export to Docs** — เปิดใน Google Docs
- **Export to Slides** — เปิดใน Google Slides (หรือ PDF)
- **Copy Contents** — คัดลอกข้อความ

### Copy & Edit เนื้อหาที่แชร์มา
เมื่อเปิดลิงก์ Canvas ของคนอื่น:
1. คลิก **Copy Canvas** ที่ด้านล่าง
2. แก้ไขต่อใน Canvas ของตัวเอง

## Quiz, Flashcards, Storybook และเครื่องมือการเรียน

Gemini รองรับการสร้างสื่อการเรียนรู้หลายแบบผ่าน Canvas:

### Quiz
- สร้างข้อสอบจากหัวข้อหรือเอกสารที่อัปโหลด
- ทดสอบตัวเองแบบ interactive
- prompt: `"Create a quiz to test me on [หัวข้อ]"`

### Flashcards
- สร้างบัตรคำสำหรับท่องจำ
- prompt: `"Make flashcards for [หัวข้อ]"`

### Illustrated Storybook
- สร้างหนังสือนิทานพร้อมภาพประกอบ AI
- prompt: `"Create an illustrated storybook about [เรื่อง]"`
