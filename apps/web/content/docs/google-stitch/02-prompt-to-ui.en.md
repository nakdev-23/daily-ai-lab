# Prompt to UI — type and get a screen 🎨

> Adapted from the official documentation at [stitch.withgoogle.com](https://stitch.withgoogle.com/)

The heart of Stitch is **turning a description into a UI screen** that's beautiful and usable.

## ✍️ Write an effective prompt

State all of these:
- **App/page type** — e.g. "a coffee-ordering app page"
- **Elements** — e.g. "a menu, product images, an add-to-cart button"
- **Style/mood** — e.g. "warm tone, minimal, rounded type"
- **Platform** — mobile or desktop

Example:
> "A hotel-booking app page on mobile, with a search field, check-in date, hotel cards with prices, a clean blue color tone"

## 🖼️ Attach reference images

Besides text, attach a **sketch/example image** to set the design direction — Stitch bases the style on that image.

## ⚡ Standard vs Experimental mode

| Mode | Good for |
|---|---|
| **Standard** | Fast, consistent results, general use |
| **Experimental** | More creative/varied, trying new ideas |

## ▶️ Steps

1. Go to [stitch.withgoogle.com](https://stitch.withgoogle.com/) and log in
2. Type a prompt (you can attach an image)
3. Choose a mode and have Stitch create the screen
4. See the result, then keep adjusting
