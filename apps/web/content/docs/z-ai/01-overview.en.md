# Z.ai — the GLM model platform 🧠

> Compiled in English from the official docs at [docs.z.ai](https://docs.z.ai/) and [z.ai](https://z.ai/)

**Z.ai** is a world-class AI platform from **Zhipu AI**, the developer of the **GLM** model family — usable both as a free chat on the web and via an API for developers, covering text, reasoning, coding, image reading (vision), video generation, and image generation. Its highlight is **models good at code/agent work at an economical price**, with an API compatible with both the OpenAI and Anthropic formats.

## 📖 Terms worth knowing

| Term | Plain meaning |
|---|---|
| **GLM** | Zhipu AI's model family (e.g. GLM-4.6) |
| **Zhipu AI** | The developing company (z.ai is the international brand) |
| **API key** | The key for calling models from code |
| **OpenAI/Anthropic-compatible** | Uses the same API format as OpenAI/Anthropic; change the URL and it works |
| **Thinking / Reasoning** | A mode where the model thinks step by step before answering |
| **GLM Coding Plan** | A monthly package for coders |

## ⭐ What you can use it for (per the official docs menu)

- **Chat / reasoning / code** — the GLM-4.6, GLM-4.5 series models
- **Vision** — read and understand images (GLM-4.5V)
- **Video generation** — CogVideoX
- **Image generation** — CogView
- **Tools** — Function/Tool calling, Web Search, Structured Output
- **Agents** — multi-step agent work
- **Coding Plan** — use with Claude Code/Cline, etc.
