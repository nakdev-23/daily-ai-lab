# Create video from text and from frames 🎥

> Adapted from the official documentation at [labs.google/flow](https://labs.google/flow/about)

Flow creates video in two main ways — starting from pure text, or starting from an image.

## ✍️ Text-to-Video

Type a scene description and Veo creates the clip. State all the elements:
- **Subject** — who/what
- **Action** — what they're doing
- **Setting/lighting** — where, what atmosphere
- **Camera** — angle and movement
- **Style** — realistic/cartoon/film

Example:
> "An astronaut walking on Mars, a dust storm blowing gently, the camera tracking from the side, cinematic tone"

## 🖼️ Frames-to-Video

Define a **starting frame image** (and an end frame), then have Flow create a video moving from one frame to the other — more precise control of the result, good when you already have an image in mind.

## 💡 Tips

- Describe it visually (color, light, mood), not abstractly
- One clip should have one main event; don't cram several scenes
- Try several times and pick the best take
