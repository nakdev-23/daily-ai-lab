# Moodboards

> Main reference: [Moodboards](https://docs.midjourney.com/hc/en-us/articles/39193335040013-Moodboards)

---

## What is a Moodboard

A Moodboard (a board collecting images that show the direction, style, color, and Aesthetic wanted for a project) is a tool designers have long used to plan and communicate the Visual Direction.

In Midjourney, a Moodboard is a feature that lets you:
- Gather Reference images from both Explore and the Archive
- Plan the Prompt before creating for real
- Share the Concept with the team or client
- Use it as a Style Reference for continuing work

---

## How to create a Moodboard

1. Go to the **"Moodboards"** menu in the left bar
2. Click **"New Moodboard"** or the **"+"** button
3. Name the Moodboard
4. Add images from various sources

---

## How to add images to a Moodboard

### From Explore
1. Click an image you like in Explore
2. Choose **"Save to Moodboard"**
3. Choose the Moodboard you want

### From the Archive
1. Right-click an image in the Archive
2. Choose **"Add to Moodboard"**

### From a just-created image
- After creating an image → click the image → "Add to Moodboard"

---

## Using a Moodboard as a Reference

### View Prompts from the Moodboard
Click an image in the Moodboard to see the Prompt used to create it, helping you learn the style you like.

### Use an image in the Moodboard as a Style Reference
Use the URL of an image in the Moodboard with `--sref`:
```
a new scene --sref [URL from an image in the Moodboard]
```

```
📋 Brand Identity - Modern Luxury

  → Product Photography Styles
  → Color Palette Examples
```

```
📋 Summer Campaign 2025
  → Summer Vibes fashion images
  → outdoor natural-light photos
  → Color Story: Warm Coral, Sand, Sky Blue
```

### Concept Art
```
📋 Sci-Fi Environment - Project X
  → References of various planets
  → Futuristic Architecture References
  → Lighting References
```

---

## Tips

1. **Create a Moodboard before starting a project** — helps set the direction clearly
2. **Gather many References** — the more images, the clearer the Pattern you like becomes
3. **Share with the client** — confirm the Aesthetic before starting to create for real
4. **Update the Moodboard** — add new images when you find new Inspiration

---

## Summary

Moodboards are an effective planning tool that help you have a clear direction before creating images, and communicate the Visual Direction with the team easily.
