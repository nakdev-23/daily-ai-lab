## Gemini Agent — an assistant that works for you

### What is Gemini Agent

**Gemini Agent** is an experimental feature that lets Gemini do multi-step work for you. You just say what you want, and Gemini plans and carries it out, while you oversee and approve at key steps.

**Examples of work the Agent can do:**
- Categorize emails and write replies for you
- Summarize what needs doing that day
- Adjust your work/meeting schedule in Calendar
- Research live on the web, including sites that require login
- Book a restaurant or accommodation

### What you need

- Age **18+** and in the **United States** (currently country-limited)
- A **personal Google** account (work/school accounts not supported)
- A **Google AI Ultra** plan
- Turn on **Keep Activity**

### How to use Gemini Agent

1. Open the Gemini app or go to gemini.google.com
2. In the message box, click **Tools** → **Agent**
3. Describe the work you want
4. Click Submit
5. **Review the plan** Gemini laid out, then click **Decline** or **Confirm** at each step
6. Gemini carries it out — usually takes a moment

### Example prompts for the Agent

```
"Every morning at 7, look at unread emails, summarize the important ones, create tasks for things to follow up, and archive unimportant emails"

"Monday–Friday at 8, send me a summary document of the day's readiness"

"Order an Iced Vanilla Latte from the shop near my house — pre-fill the order for me to confirm myself"
```

### Controlling Gemini's browser

When the Agent uses the web, you can "take control" anytime:
1. In the chat, under "Using browser" → click **Open** → **Take control**
2. Do the steps you want yourself (e.g. enter a password, confirm payment)
3. Click **End control** → **Resume** to return control to Gemini

### Agent limits

| Plan | Limit |
|---|---|
| Ultra | 200 requests/day, 3 tasks at once |

## Cautions for using Gemini Agent

**On safety:**
- ❌ Don't type passwords or credit-card data in the chat — enter them yourself on the web page via Take Control
- ❌ Don't schedule automation for very important or sensitive work
- ⚠️ **Prompt Injection:** websites Gemini visits may have hidden commands to trick Gemini into doing something you don't want — supervise closely for important work

**Gemini will ask for confirmation before:**
- Sending an email, sending a message
- Editing data, buying something
- Filling out an online form

## Schedule Actions — schedule automated work

**Schedule Actions** is setting Gemini to do repetitive work at set times, e.g. sending a daily summary every morning.

### How to set a Scheduled Action

1. In Agent mode, type the task with a time:
   ```
   "Every day at 8 AM, send me a summary of what I need to do today"
   ```
2. Gemini creates the Scheduled Action automatically

### View and manage Scheduled Actions

Go to Settings → Scheduled Actions to view, edit, or delete the actions you've set.

**Limit:**
- Plus, Pro, Ultra: up to 10 active actions at once

> **Caution:** If an action runs while you're offline, you may not be able to stop it in time, so don't set actions for sensitive or very important work.

Reference: [Schedule Actions](https://support.google.com/gemini/answer/16316416)

## Deep Think — a deep-thinking mode for complex problems

### What is Deep Think

**Deep Think** is a special mode that lets Gemini "think longer" than usual before answering, good for problems needing deep reasoning, e.g.:
- Advanced math problems
- Complex logic problems
- Software architecture design
- Strategic analysis

### What you need

- A **Google AI Ultra** plan only
- Limit: **10 prompts per day** with a **192K-token** context window

### How to use Deep Think

1. In Gemini, choose the **Thinking** model or turn on **Deep Think** in settings
2. Type a prompt you want it to think deeply about

Reference: [Deep Think](https://support.google.com/gemini/answer/16345172)

## Screen Automation — control apps on Android

**Screen Automation** is a feature that lets Gemini do multi-step work in apps on Android for you, e.g. filling out a form, sending a message, opening an app and following steps.

| Plan | Limit/day |
|---|---|
| Free | 5 requests |
| Plus | 12 requests |
| Pro | 20 requests |
| Ultra | 120 requests |

Reference: [Screen Automation](https://support.google.com/gemini/answer/16940971)

## Dynamic View — Gemini's visual view

**Dynamic View** is a display mode where Gemini arranges the answer to be easier to read, e.g. separating topics, adding icons, formatting nicely.

| Plan | Number of prompts |
|---|---|
| Free, Plus | 25/day |
| Pro, Ultra | 250/day |

## Summary

Gemini Agent, Schedule Actions, and Deep Think are advanced features that make Gemini more than a chatbot — an assistant that can "really work" for you. However, these features are still "experimental" and always require user oversight.
