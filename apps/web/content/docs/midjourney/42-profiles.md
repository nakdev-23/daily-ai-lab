# Profiles — โปรไฟล์และชุมชน

> อ้างอิงหลัก: [Profiles](https://docs.midjourney.com/hc/en-us/articles/41117938447629-Profiles)

---

## Profile คืออะไร

Profile (โปรไฟล์ — หน้าตัวตนสาธารณะของคุณในชุมชน Midjourney) แสดงงานที่คุณสร้างให้คนอื่นเห็นและให้คุณติดตามนักสร้างสรรค์คนอื่น

---

## ส่วนประกอบของ Profile

### ข้อมูลส่วนตัว
- รูปโปรไฟล์
- ชื่อ Username
- Bio (ประวัติสั้นๆ)

### Portfolio สาธารณะ
- แสดงงานที่คุณ "Public" ไว้
- ผู้อื่นสามารถ Like และ Follow ได้

### งานของคุณ
- ภาพที่คุณสร้างและเลือกแชร์สาธารณะ

---

## การตั้งค่า Visibility (การมองเห็น)

ควบคุมว่างานไหนจะถูกเห็นโดยสาธารณะ:

- **Public** — งานปรากฏใน Explore และ Profile
- **Private** (ต้องการ Stealth Mode) — งานไม่ปรากฏสาธารณะ

### เปลี่ยน Visibility ของงาน
1. คลิกที่ภาพใน Archive
2. เลือก "Make Public" หรือ "Make Private"

---

## ติดตามและ Explore

### ติดตามนักสร้างสรรค์
- ไปที่ Explore → คลิกที่งาน
- คลิกชื่อผู้สร้าง → "Follow"
- งานใหม่จากคนที่ติดตามจะปรากฏใน Feed ของคุณ

### Discover
- ใช้ Explore เพื่อค้นหานักสร้างสรรค์ที่มีสไตล์ที่ชอบ
- หาแรงบันดาลใจจาก Prompt ของงานที่ชอบ

---

## การแชร์งานผ่าน Profile

### แชร์ลิงก์ Profile
- ไปที่ Profile → Copy Link
- แชร์ให้ลูกค้าหรือเพื่อนเพื่อดู Portfolio ของคุณ

### แชร์งานแต่ละชิ้น
- คลิกที่ภาพ → "Share"
- ได้ลิงก์ตรงไปยังภาพนั้น

---

## Portfolio ดิจิทัล

Profile ใน Midjourney สามารถใช้เป็น Portfolio ดิจิทัล (แฟ้มผลงาน — คอลเลกชันงานที่แสดงความสามารถ) ได้:

- เลือกงานที่ดีที่สุดให้เป็น Public
- งานจัดเรียงตามวันที่ล่าสุด
- ผู้ชมสามารถ Like งานของคุณได้

### เคล็ดลับการสร้าง Portfolio
1. เลือกเฉพาะงานที่ดีที่สุดเป็น Public
2. ครอบคลุมหลาย Style เพื่อแสดงความหลากหลาย
3. อัปเดตสม่ำเสมอด้วยงานใหม่

---

## Stats และ Analytics

ใน Profile คุณสามารถเห็น:
- จำนวน Likes ที่ได้รับ
- จำนวน Followers
- งานที่ได้รับความนิยมสูงสุด

---

## สรุป

Profile ช่วยให้คุณเป็นส่วนหนึ่งของชุมชน Midjourney แชร์งาน ติดตามนักสร้างสรรค์คนอื่น และสร้าง Portfolio ดิจิทัลสาธารณะ ตั้งค่า Visibility ให้เหมาะกับความต้องการด้านความเป็นส่วนตัว และใช้ Profile เป็นช่องทางแสดงผลงานให้ลูกค้าหรือเพื่อนร่วมงาน
