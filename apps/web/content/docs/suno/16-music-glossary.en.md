# Music Glossary for Suno

This **Music Glossary** gathers the terms essential for using Suno most effectively, organized by category.

---

## A — Song Structure

| Term | Meaning |
|----|---------|
| **Arrangement** | the layout of the whole song's structure — which instrument plays when |
| **Bridge** | the middle section of a song that changes the mood or perspective before returning to the Chorus |
| **Chorus** (Hook) | the most memorable section, usually sung several times |
| **Hook** | the "catchy" part of a song, may be the Chorus or a short Riff |
| **Intro** | the opening section of a song |
| **Interlude** | a section between parts, usually purely instrumental |
| **Outro** | the closing section of a song |
| **Pre-Chorus** | a short section before the Chorus, building anticipation |
| **Refrain** | a repeated section, similar to a Chorus |
| **Verse** | the narrative section, usually changing content each round |

---

## B — Rhythm and Tempo

| Term | Meaning |
|----|---------|
| **Bar** | a unit measuring music length, also called a "Measure" — usually 4 beats per bar |
| **Beat** | one musical beat |
| **BPM — Beats Per Minute** | the number of beats per minute — the more, the faster (60 BPM slow, 140 BPM fast) |
| **Downbeat** | beat 1 of each bar — the main beat |
| **Groove** | the "locked-in" feel in the rhythm that makes you want to move |
| **Meter** | the rhythmic pattern, e.g. 4/4 (four beats per bar) or 3/4 (waltz) |
| **Rhythm** | the rhythmic pattern of the music or lyrics |
| **Syncopation** | emphasizing unexpected beats, creating a "jumpy" feel |
| **Tempo** | the overall speed of the song — slow or fast |
| **Time Signature** | the number of beats per bar, e.g. 4/4, 3/4, 6/8 |

## C — Instruments

### String instruments

| Term | Meaning |
|----|---------|
| **Acoustic Guitar** | a plain hollow-body guitar that doesn't need an amp |
| **Electric Guitar** | a guitar that needs an amp, loud, highly adjustable |
| **Bass Guitar** | a low-sounding guitar that handles Rhythm together with the drums |
| **Violin** | a high string instrument in the orchestra |
| **Cello** | a string instrument lower than the violin, with a warm sound |
| **Banjo** | an American Country/Folk string instrument |
| **Ukulele** | a small Hawaiian guitar with a cute sound |

### Keyboard instruments

| Term | Meaning |
|----|---------|
| **Piano** | the main keyboard instrument, 88 keys |
| **Synthesizer / Synth** | an electronic sound-synthesis instrument |
| **Organ** | a Church/Gospel keyboard with air pipes |
| **Pad** | a floating Synth sound used to create atmosphere |

### Wind instruments

| Term | Meaning |
|----|---------|
| **Trumpet** | a brass instrument, high and loud |
| **Saxophone** | a golden wind instrument, popular in Jazz |
| **Flute** | a wind instrument with a thin, high sound |
| **French Horn** | a brass instrument in the Orchestra with a warm sound |

### Percussion

| Term | Meaning |
|----|---------|
| **Drums** | a Rock/Pop/Jazz drum kit with several pieces |
| **Hi-hat** | the paired cymbals in a kit, giving a Tick-Tick rhythm |
| **Kick Drum** | the big drum kicked with the foot, giving a Boom sound |
| **Snare** | the side drum, giving a Crack sound |
| **808** | the bass drum sound from the Roland TR-808, used in Trap/Hip-Hop |

---

## D — Sound and Production

| Term | Meaning |
|----|---------|
| **A cappella** | singing with no accompanying music |
| **Chord** | playing several notes at once |
| **Distortion** | an effect that distorts the guitar sound to be sharp and heavy, used in Rock/Metal |
| **Dynamic** | the range of loud-to-soft in a song — the difference between the quietest and loudest points |
| **EQ — Equalizer** | a tool to adjust the loudness of each sound frequency |
| **Falsetto** | singing in an extra-high voice beyond the singer's normal range |
| **Harmonic** | harmonized sounds sung together in multiple voices |
| **Key** | the group of notes a song uses, e.g. Key of C major |
| **Melody** | the main tune of a song, the clearly audible line of sound |
| **Mix** | the process of blending multiple Tracks into balance |
| **Reverb** | the echo effect of sound in a room or space |

---

## E — Genre and music styles

| Term | Meaning |
|----|---------|
| **Ambient** | atmospheric music, emphasizing mood, with no clear structure |
| **Ballad** | a slow song with strong emotion, usually about love or loss |
| **Chillout** | relaxing music, midway between Electronic and Ambient |
| **Folk** | traditional music, telling stories, simple |
| **Fusion** | mixing two or more genres, e.g. Jazz-Rock, Indo-Pop |
| **Genre** | the main type of music, e.g. Pop, Rock, Jazz, Classical |
| **Indie** | independently produced music, not backed by a major label |
| **Orchestral** | music using a full orchestra |

---

## F — Terms for AI Music

| Term | Meaning |
|----|---------|
| **Base** | the original audio file used as the foundation for the AI |
| **Generation** | the process of the AI creating content |
| **Generative AI** | AI that can create new content, such as music, images |
| **Hallucination** | when the AI creates content that is incorrect or doesn't make sense |
| **Inference** | when the AI uses a trained model to create a new result |
| **Model** | an AI program trained on data to create results |
| **Prompt** | the command or description fed to the AI to work |
| **Stem** | a separated-track audio file, such as separate vocals, separate music |
| **Token** | a unit of data the AI processes (in Text AI) |
| **Training Data** | the data used to train the AI to learn |

---

## G — Terms about audio files

| Term | Meaning |
|----|---------|
| **Bit Depth** | the resolution of the sound, e.g. 16-bit, 24-bit — the higher, the better |
| **Codec** | an audio compression standard, e.g. MP3, AAC |
| **Lossless** | an audio file with no data loss, e.g. WAV, FLAC |
| **Lossy** | an audio file that is compressed and loses some data, e.g. MP3 |
| **MP3** | the most popular compressed audio file, small size, good quality |
| **Sample Rate** | the number of times sound is recorded per second, e.g. 44,100 Hz (CD quality) |
| **WAV** | an uncompressed audio file, highest quality, large size |

---

## H — Vocal Terms

| Term | Meaning |
|----|---------|
| **A cappella** | singing with no music |
| **Ad-lib** | free, unscripted singing with a natural pattern |
| **Baritone** | a mid-range male voice, lower than Tenor |
| **Belt** | singing out loud with emotion, a powerful voice |
| **Breath Control** | a singer's skill in using their breath |
| **Choir** | a group of many singers singing in harmony |
| **Falsetto** | an extra-high voice beyond the normal range |
| **Harmony** | harmonized sound — singing multiple voices together to blend |
| **Melisma** | singing one syllable across many notes, sounding like R&B/Gospel |
| **Soprano** | the highest female voice |
| **Tenor** | a high male voice |
| **Vibrato** | a gentle waver in the voice, creating depth and emotion |
| **Whisper** | singing in a whisper, soft and nearly inaudible |

## Summary: the most-used words in Suno

```
Genre = music style
Lyrics = the song's words
Instrumental = an instrumental song (no vocals)
BPM = the rhythm speed
Verse = the narrative section
Chorus = the hook section
Bridge = the mood-changing section
Stem = a separated-track audio file
Mix = blending the sound
Prompt = the command for the AI to create a song
```
