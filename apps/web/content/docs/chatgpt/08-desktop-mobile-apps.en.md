# Desktop App & Mobile App

> Primary reference: [OpenAI Help Center — ChatGPT](https://help.openai.com/en/collections/3742473-chatgpt)

---

## Desktop App

OpenAI launched the ChatGPT Desktop App (a computer application — a program installed and run on the machine directly) for **macOS** (May 2024) and **Windows** (October 2024), free to download on the Mac App Store and Microsoft Store respectively.

### Standout features of the Desktop App

#### Keyboard Shortcut (press a hotkey to call up the program instantly)
Call up ChatGPT instantly without opening a browser:
- **macOS**: `Option + Space` — opens a Quick Input bar over the current screen
- **Windows**: set the shortcut in the app's Settings

Benefit: you can ask ChatGPT while working in another program, e.g. Word, Excel, VS Code.

#### Screenshot Analysis (capture what's on screen and send it for the AI to see)
- Capture the screen and send it straight to ChatGPT to analyze
- Use it to ask about error messages, graphs, or content on screen
- No need to save a file and upload (send a file from your machine to an online system) step by step

#### Working with other programs
- Analyze Excel or CSV files (tabular data files — a file format storing data in rows and columns, openable in spreadsheet programs) straight from the desktop
- Read a PDF document and summarize it for you
- Take a photo with the laptop camera and have the AI analyze the objects or text in it

#### Menu Bar Integration (macOS)
- The ChatGPT icon appears in the Menu Bar (the bar at the top of the Mac screen)
- Open/close the app quickly
- Shows the processing status

#### No browser needed
The Desktop app works as a native app (an app built specifically for that operating system, running faster and more stably), which is usually faster and uses less RAM (temporary memory — where data the program is currently using is held) than opening many tabs in a browser.

### Installation

**macOS:**
1. Go to [chatgpt.com](https://chatgpt.com) and click "Download the app"
2. Or search "ChatGPT" in the Mac App Store
3. Requires macOS 14 Sonoma or higher

**Windows:**
1. Search "ChatGPT" in the Microsoft Store
2. Or download from the OpenAI website
3. Requires Windows 10 (Build 17763) or higher

## Mobile App (iOS & Android)

ChatGPT has a mobile app on both **iOS** (May 2023) and **Android** (July 2023) — free to download.

### Mobile-specific features

#### Voice Mode in hand
- Tap the microphone button to speak instead of type
- Supports Advanced Voice Mode on iOS and Android
- Good for asking short questions or hands-free use (used without holding or touching the device)

#### Camera & Image Input
- Take a photo or pick from your Photo Library to send for analysis
- **Live Camera Mode (GPT-5.5)**: point the camera at an object or document and just ask
- Use it to: analyze food, read foreign-language signs, solve a math problem from a photo

#### Home Screen Widget (iOS)
- Add a ChatGPT widget (a small element on the home screen showing info or giving direct access to features) on the Home Screen
- Type or speak a question right from the widget
- No need to open the app first

#### Siri Integration (iOS)
- Set Siri to pass questions on to ChatGPT
- Use Siri Shortcuts (voice-command shortcuts) to command ChatGPT by voice

#### Android Default Assistant
- Set ChatGPT as the Default Digital Assistant (the main digital assistant — the AI the system calls when you press the assistant button) on Android
- Long-press the Home button or use a gesture (a special swipe or tap) to call ChatGPT instead of Google Assistant

#### Haptic Feedback (the phone vibrates to let you know something happened)
- The phone vibrates when the AI starts answering or when Voice Mode is ready to listen

## Mobile app settings

### Notification Settings
- Turn on notifications for when the AI finishes a long-running task
- Turn off general notifications in the app's Settings

### Haptics & Sound
- Turn Haptic Feedback on/off
- Choose the sound effect when the AI answers

### Speech Settings
- Choose ChatGPT's voice (6 voices to choose from)
- Choose the language for Speech-to-Text (turning spoken voice into text)

### Data & Privacy
- Choose whether to save your chat history
- Opt out (choose not to consent) of having your data used to train the AI

## Desktop & Mobile tips

### For Desktop
- **Use the shortcut**: deliberately memorize the keyboard shortcut to call up ChatGPT faster
- **Screenshot before asking**: instead of typing to describe an error, capture the screen and send it
- **Use multiple windows**: keep the Desktop App open on the side while working in another program

### For Mobile
- **Live Camera**: point the camera and ask about what you see, without taking a photo and uploading
- **Voice while walking**: use Voice Mode to brainstorm or take notes while walking
- **Widget**: add a widget to reach ChatGPT faster on the Home Screen
