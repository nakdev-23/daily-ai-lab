# Plans, Credits, and billing

Suno has a **Credits** system (the unit exchanged to create songs, like coins in a game) to control AI usage each month. The higher the plan, the more credits you get = the more songs you can create.

---

## All the plans

### Free Plan

| Detail | Value |
|-----------|-----|
| **Price** | $0 / month |
| **Credits per month** | 50 credits |
| **Songs you can create** | ~10 songs (you get 2 versions per time) |
| **Privacy** | Songs are Public |
| **Usage rights** | Non-commercial only |
| **Download** | Downloadable, but no WAV |

### Pro Plan

| Detail | Value |
|-----------|-----|
| **Price** | ~$8 / month (annual) or ~$10 / month |
| **Credits per month** | 2,500 credits |
| **Songs you can create** | ~500 songs |
| **Privacy** | Can set Private |
| **Usage rights** | Commercial use |
| **Download** | MP3 + MP4 (video) |
| **Special features** | Crop, Priority Generation |

### Premier Plan

| Detail | Value |
|-----------|-----|
| **Price** | ~$24 / month (annual) or ~$30 / month |
| **Credits per month** | 10,000 credits |
| **Songs you can create** | ~2,000 songs |
| **Privacy** | Can set Private |
| **Usage rights** | Full Commercial use |
| **Download** | MP3 + MP4 + WAV (high quality) |
| **Special features** | Crop, Priority Generation, Studio Access, Stem Extraction |

## What are Credits?

**Credits** are the unit used to create songs and various features in Suno.

### Credit usage rates

| Action | Credits used |
|---------|-------------|
| Create a new song (2 versions) | 10 credits |
| Extend, each time | 5 credits |
| Remaster | 5 credits |
| Stem Extraction | 5–10 credits |
| Add Vocals | 5 credits |
| Upload Audio + Create | 10 credits |

### Credits Reset

- **Free Plan:** gets new Credits every day (50 credits cycling daily)

> **Note:** Credits left over from the previous month **don't carry over** (no Rollover — they aren't added to the next month).

### Check remaining Credits

1. Click **Profile** or **Settings**
2. Look at the **"Credits"** or **"Usage"** section
3. It shows the remaining Credits and the reset date

---

## How to buy more Credits

If you run out of Credits before the end of the month, you can buy more:

1. Go to **Settings > Billing**
2. Choose **"Buy More Credits"**
3. Choose the package you want
4. Pay

> These purchased Credits **don't expire** and can be used continuously.

## Payment methods

Suno supports payment via:

| Method | Detail |
|--------|---------|
| **Credit/Debit Card** | Visa, Mastercard, American Express |
| **PayPal** | a PayPal account |
| **Apple Pay** | for iOS/Mac users |
| **Google Pay** | for Android users |

> **Note:** Suno doesn't accept Bitcoin or other Cryptocurrencies.

### VAT

If you're in a country with VAT (such as EU countries or some Asian countries), the displayed price may not include VAT. Suno adds VAT at your country's rate at checkout.

## Managing your Subscription

### Change plans

1. Go to **Settings > Billing**
2. Click **"Change Plan"**
3. Choose the new plan

### Cancel the subscription

1. Go to **Settings > Billing**
2. Click **"Cancel Subscription"**
3. Confirm the cancellation

> **After cancellation:** You can still use it until the end of the billing cycle; the remaining Credits can be used until the cycle ends.

### View payment information after cancellation

If you've canceled the plan but want to see payment history:
1. Go to [suno.com](https://suno.com)
2. Log in with the same email
3. Go to **Settings > Billing History**

## Refund Policy

Suno has a limited refund policy:

- **No refunds** for a month already used
- **Special cases** such as a system problem or a double charge — you can contact Support
- **Try before you buy** — use the free plan before deciding to sign up for Pro

## Free Plan vs Paid Plan, which to choose?

### Use the Free Plan if:
- You're just starting and want to experiment
- You create songs as a personal hobby
- You don't want to use the songs commercially

### Upgrade to Pro if:
- You want to create more than 10 songs per month
- You want to use songs on YouTube, in ads, or to sell
- You want privacy (Private Songs)

### Upgrade to Premier if:
- You work at a professional or business level
- You want WAV Files (high-quality files)
- You want to use Studio and Stem Extraction
- You create more than 500 songs per month

## Frequently asked questions

**Q: My Credits ran out this month, what do I do?**
A: You can buy more Credits, or wait for next month's reset.

**Q: After canceling, will the songs I created disappear?**
A: The songs you created stay in your account, but you may not be able to access some features.

**Q: Can I change plans mid-month?**
A: Yes, Suno calculates the difference proportionally.

**Q: If I sign up for Pro, will the songs I made on the Free plan also get Commercial rights?**
A: No — Commercial rights apply only to songs created while you have the Pro/Premier plan.
