# ElevenLabs — the most human-sounding AI speech 🎙️

> Adapted from the official documentation at [elevenlabs.io/docs](https://elevenlabs.io/docs)

**ElevenLabs** is an audio AI platform known for **natural, human-sounding speech** — turning text into speech (Text to Speech), cloning your own voice, dubbing videos into other languages, creating sound effects, and even building voice conversational assistants. It supports dozens of languages, including Thai.

## 📖 Terms worth knowing

| Term | In plain words |
|---|---|
| **TTS (Text to Speech)** | Turning text into speech |
| **Voice cloning** | Creating an AI voice that mimics a real person |
| **Voice Library** | A library of ready-made voices to choose from |
| **Dubbing** | Translating + dubbing a video's audio into another language |
| **Credits** | The usage unit (counted by characters/seconds) |
| **Conversational AI** | An agent that listens, thinks, and speaks back in real time |

## ⭐ Main abilities (per the official docs menu)

- **Text to Speech** — read text as speech in many languages, many emotions
- **Voices & Voice Cloning** — choose a voice from the library or clone your own
- **Dubbing** — dub videos across languages while keeping the original tone
- **Sound Effects** — create sound effects from a description
- **Speech to Text (Scribe)** — transcribe audio into text
- **Conversational AI (Agents)** — build an interactive voice assistant
- **API** — use every feature via code

## 🚀 Getting started

1. Sign up for a free account at [elevenlabs.io](https://elevenlabs.io/)
2. Go to **Text to Speech** and pick a voice from the Voice Library
3. Type/paste text, hit generate — listen and download the audio file
4. Want a unique voice? Try **Voice Cloning** or call it via the **API**
