# Blend — ผสมภาพหลายรูป

> อ้างอิงหลัก: [Blend Images in Discord](https://docs.midjourney.com/hc/en-us/articles/32635189884557-Blend-Images-in-Discord)

---

## Blend คืออะไร

คำสั่ง `/blend` (การผสมภาพ — ใช้ภาพหลายรูปเป็น Input แล้วให้ Midjourney สร้างภาพใหม่ที่ผสมผสาน Essence สไตล์ และองค์ประกอบจากทุกภาพ) ทำงานคล้ายกับ Image Prompt หลายรูป แต่ออกแบบมาเพื่อการผสมภาพโดยเฉพาะ

---

## วิธีใช้

### บน Discord
1. พิมพ์ `/blend`
2. กล่องอัปโหลดจะปรากฏ — อัปโหลดภาพ 2 รูป (บังคับ)
3. สามารถเพิ่มภาพที่ 3, 4, 5 เป็นตัวเลือก
4. กด Enter

### บนเว็บไซต์
1. ในช่อง Prompt คลิกไอคอนอัปโหลดภาพ
2. อัปโหลดหลายรูป
3. Midjourney จะผสมโดยอัตโนมัติ

---

## รายละเอียดสำคัญ

- รองรับภาพ **2-5 รูป** พร้อมกัน
- ไม่มี Text Prompt — ใช้แค่ภาพ
- ถ้าต้องการ Text Prompt ด้วย ใช้ `/imagine` + Image URL แทน

---

## ตัวอย่างการใช้งาน

### ผสม 2 สไตล์ศิลปะ
```
ภาพ 1: ภาพ Watercolor ดอกไม้
ภาพ 2: ภาพ Oil Painting ทิวทัศน์
ผล: ทิวทัศน์ดอกไม้ในสไตล์ผสมระหว่าง Watercolor กับ Oil Painting
```

### ผสม 2 ตัวละคร
```
ภาพ 1: ตัวละครแมว
ภาพ 2: ตัวละครมังกร
ผล: ตัวละครที่มีลักษณะของแมวและมังกรผสมกัน
```

### ผสมสภาพแวดล้อม
```
ภาพ 1: ป่าทึบ
ภาพ 2: เมืองในอนาคต
ผล: ป่าที่มีองค์ประกอบเมือง Cyberpunk หรือเมืองที่มีต้นไม้ปกคลุม
```

---

## เปรียบเทียบ Blend กับ Image Prompt

| วิธี | ใช้เมื่อ |
|------|---------|
| `/blend` | ต้องการผสมภาพโดยไม่มี Text Prompt |
| `/imagine` + Image URLs | ต้องการผสมภาพ + ควบคุมด้วย Text Prompt |

---

## เคล็ดลับ

1. **ภาพที่ Contrast กัน** — ให้ผลที่น่าสนใจกว่าภาพที่คล้ายกัน
2. **ใช้ Aspect Ratio ที่สม่ำเสมอ** — ภาพที่มีขนาดและสัดส่วนใกล้เคียงกันผสมได้ดีกว่า
3. **ทดลองลำดับ** — ภาพที่อยู่ก่อนอาจมีน้ำหนักมากกว่า

---

## ตัวอย่างผลลัพธ์ที่น่าสนใจ

### Style Transfer (ถ่ายทอดสไตล์)
```
ภาพ 1: ภาพถ่ายทิวทัศน์ทะเล
ภาพ 2: ภาพวาดสีน้ำมันแบบ Van Gogh
ผล: ทะเลที่วาดในสไตล์ Post-Impressionist
```

### Character Fusion (ผสมตัวละคร)
```
ภาพ 1: ภาพหมาป่า
ภาพ 2: ภาพอัศวิน
ผล: อัศวินหมาป่าหรือหมาป่าในชุดเกราะ
```

### Environment Mashup (ผสมสภาพแวดล้อม)
```
ภาพ 1: ภาพใต้น้ำ
ภาพ 2: ภาพป่าทึบ
ผล: ป่าใต้น้ำหรือสภาพแวดล้อมแฟนตาซีผสม
```

---

## Blend vs Image Prompt — เลือกใช้แบบไหน

### ใช้ /blend เมื่อ:
- ต้องการผสมภาพอย่างง่ายโดยไม่มี Text Prompt
- ต้องการให้ AI ตัดสินใจว่าจะผสมอย่างไร
- ทดลองผสมสไตล์ต่างๆ อย่างรวดเร็ว

### ใช้ /imagine + Image URLs เมื่อ:
- ต้องการควบคุมผลลัพธ์ด้วย Text Prompt
- ต้องการปรับ Image Weight ด้วย `--iw`
- ต้องการเพิ่มรายละเอียดเฉพาะเจาะจง

---

## ลำดับภาพมีผลต่อผลลัพธ์

ลำดับที่อัปโหลดภาพอาจส่งผลต่อผลลัพธ์:
- ภาพแรกอาจมีน้ำหนักมากกว่า
- ทดลองสลับลำดับถ้าผลลัพธ์ไม่ตรงใจ

---

## สรุป

`/blend` เป็นวิธีที่เร็วและง่ายในการผสมสไตล์และองค์ประกอบจากหลายภาพ รองรับภาพ 2-5 รูป ไม่ต้องเขียน Prompt ซับซ้อน เหมาะสำหรับการทดลองผสม Concept หรือ Style อย่างรวดเร็ว ถ้าต้องการควบคุมมากขึ้นให้ใช้ `/imagine` พร้อม Image URLs แทน
