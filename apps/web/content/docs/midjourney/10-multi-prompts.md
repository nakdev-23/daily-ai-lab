# Multi-Prompts และ Prompt Weights

> อ้างอิงหลัก: [Multi-Prompts Weights](https://docs.midjourney.com/hc/en-us/articles/32658968492557-Multi-Prompts-Weights)

---

## Multi-Prompts คืออะไร

ปกติเมื่อคุณพิมพ์ `hot dog` Midjourney จะมองว่าเป็น Phrase เดียวและสร้างภาพ "ฮอทด็อก" (อาหาร)

แต่ถ้าคุณต้องการภาพ "สุนัขร้อน" (dog ที่ร้อน) ล่ะ?

นี่คือจุดที่ Multi-Prompts (การแยก Prompt — เทคนิคแบ่งคำสั่งเป็นส่วนๆ เพื่อให้ AI ประมวลผลแยกกัน) มีประโยชน์

### วิธีใช้ `::` (Double Colon)
เครื่องหมาย `::` แยก Prompt ออกเป็นส่วนๆ ที่ประมวลผลแยกกัน:

```
hot:: dog
```
ผลลัพธ์: สุนัขที่ดูร้อน (ไม่ใช่ฮอทด็อก)

```
hot dog
```
ผลลัพธ์: ฮอทด็อก (อาหาร)

---

## Prompt Weights (น้ำหนัก Prompt)

### หลักการ
หลังเครื่องหมาย `::` คุณสามารถระบุตัวเลขเพื่อกำหนดน้ำหนัก:

```
[Prompt A]::[น้ำหนัก A] [Prompt B]::[น้ำหนัก B]
```

**ตัวอย่าง:**
```
forest:: 2 waterfall:: 1
```
ความหมาย: เน้นป่าไม้มากกว่าน้ำตก 2 เท่า

### ค่าน้ำหนักเริ่มต้น
ถ้าไม่ระบุ ทุกส่วนมีน้ำหนักเท่ากันที่ `1`:
```
forest:: waterfall::
```
= เท่ากับ
```
forest:: 1 waterfall:: 1
```

### น้ำหนักเป็นทศนิยมได้
```
epic castle:: 1.5 surrounded by dragons:: 0.5
```
ความหมาย: เน้นปราสาทมาก มังกรเป็นรายละเอียดรอง

---

## ตัวอย่างการใช้งาน

### ตัวอย่างที่ 1 — ผสมแนวคิด
```
vibrant watercolor painting:: tropical jungle:: glowing neon lights::
```
ผลลัพธ์: ภาพสีน้ำสดใสของป่าเขตร้อนที่มีไฟนีออน

### ตัวอย่างที่ 2 — เน้นสิ่งสำคัญ
```
majestic lion:: 3 savanna landscape:: 1
```
ผลลัพธ์: สิงโตเป็นหัวข้อหลัก ทิวทัศน์ซาวันน่าเป็นฉากหลัง

### ตัวอย่างที่ 3 — แยกแนวคิดที่อาจสับสน
```
apple:: fruit:: 2 apple:: technology company:: 0.5
```
ผลลัพธ์: เน้นผลไม้แอปเปิ้ล ไม่ใช่โลโก้บริษัท

## Negative Weights (น้ำหนักลบ)

คุณสามารถใช้น้ำหนักลบเพื่อ "ลบ" บางอย่างออกจากภาพ:

```
beautiful forest:: colorful flowers::-1
```
ความหมาย: ต้องการป่าสวยงาม แต่ไม่ต้องการดอกไม้สีสันจัด

> **หมายเหตุ:** ผลรวมของน้ำหนักทั้งหมดต้องไม่เท่ากับ 0 หรือติดลบ ไม่เช่นนั้น Midjourney จะแสดง Error (ข้อผิดพลาด)

---

## ความแตกต่างระหว่าง Multi-Prompts และ --no

| วิธี | การทำงาน |
|------|---------|
| `flowers::-1` | ลดน้ำหนักดอกไม้ (อาจยังมีบ้าง) |
| `--no flowers` | พยายามกำจัดดอกไม้ออกให้หมด |

ใช้ `--no` เมื่อต้องการหลีกเลี่ยงสิ่งนั้นอย่างจริงจัง

---

## การรวม Multi-Prompts กับ Parameters

Multi-Prompts ทำงานร่วมกับ Parameters ได้:

```
epic dragon:: 2 ancient ruins:: 1 --ar 16:9 --stylize 500
```

Parameters จะใช้กับภาพทั้งหมด ไม่ใช่แค่ส่วนใดส่วนหนึ่ง

---

## กรณีใช้งานจริง

### สร้างภาพที่มีสองแนวคิดผสมกัน
```
ocean:: 1 sky:: 1 reflection:: 2
```
เน้น reflection (การสะท้อน) ทำให้ภาพมีความลึก

### ควบคุมสไตล์และเนื้อหาแยกกัน
```
a warrior in battle:: 2 oil painting technique:: 1 dramatic lighting:: 1
```

### ผสมสองยุคสมัย
```
ancient Egyptian architecture:: medieval European castle::
```

---

## เคล็ดลับ

1. **เริ่มจากน้ำหนักเท่ากัน** — ดูผลก่อน แล้วค่อยปรับน้ำหนัก
2. **ใช้จำนวนที่ง่าย** — ค่า 1, 2, 3 มักเพียงพอ ไม่ต้องละเอียดมาก
3. **ทดสอบกับ Prompt ธรรมดาก่อน** — เพื่อเข้าใจว่า Midjourney ตีความ Phrase อย่างไร
4. **ผสมกับ `--no`** — ใช้ Multi-Prompts เพื่อเน้น และ `--no` เพื่อหลีกเลี่ยง

---

## สรุป

Multi-Prompts ด้วย `::` ช่วยให้คุณควบคุมการผสมแนวคิดใน Prompt ได้อย่างแม่นยำ ใช้เมื่อต้องการแยกคำที่อาจสับสน หรือเมื่อต้องการเน้นส่วนใดส่วนหนึ่งมากกว่า Prompt Weights ช่วยให้คุณปรับสัดส่วนของแต่ละองค์ประกอบได้ตามต้องการ
