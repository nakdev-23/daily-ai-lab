# Creating images on the website

> Main reference: [Creating on Web](https://docs.midjourney.com/hc/en-us/articles/33390732264589-Creating-on-Web)

---

## Image-creation steps

Creating images on the Midjourney website is very easy:

### Step 1 — Go to the Create page
1. Log in at [midjourney.com](https://midjourney.com)
2. Click **"Create"** in the left menu
3. You'll see the Prompt bar at the very top

### Step 2 — Type a Prompt
The Prompt (the command you type for the AI to create an image — like telling it what kind of image you want) is the key.

**A simple Prompt example:**
```
a golden retriever puppy playing in autumn leaves
```

**A more detailed Prompt example:**
```
a golden retriever puppy playing in autumn leaves, soft sunlight, bokeh background, professional photography
```

### Step 3 — Adjust the settings (optional)
Before pressing Generate, you can adjust:
- **Aspect Ratio** — choose the format you want
- **Model** (the AI version) — choose the latest or a specific version
- **Stylize** — adjust the level of artistic beauty

### Step 4 — Generate and wait for the result
- Click **"Generate"** or press **Enter**
- Wait about 30-60 seconds
- The system creates **4 images at once** to choose from

---

## Understanding the result

When finished, you'll see a 2x2 grid of 4 image variations:

```
[Image 1] [Image 2]
[Image 3] [Image 4]
```

Each image differs slightly in detail. You can:
- **Click to enlarge** any image to see it more clearly
- **Upscale** (increase the image's resolution) the one you like
- **Vary** (recreate with slight adjustments) if it's close but not quite satisfying
- **Re-run** to create an entirely new set of images from the same Prompt

---

## Options after creation

### Upscale
- **Upscale (Subtle)** — increase quality slightly, keeping the original style
- **Upscale (Creative)** — increase quality while adding new detail

### Vary
- **Vary (Subtle)** — adjust slightly, the main structure stays the same
- **Vary (Strong)** — adjust a lot, get a new image but keep the main concept
- **Vary (Region)** — select a specific area and recreate only that part

### Editing images
- **Edit** — open the full Editor to edit the image
- **Zoom Out** — expand the image's boundaries all around
- **Pan** — shift the image in various directions (up, down, left, right)

---

## Image Prompts (using images as a Prompt)

You can attach an image to use as inspiration:
1. Click the **image** icon in the Prompt bar
2. Upload or paste the image's URL
3. Midjourney creates a new image referencing the style or content from the image you provide

---

## Draft Mode and Conversational Mode

### Draft Mode
- Creates images faster and uses less GPU Time
- Lower resolution than normal
- Good for testing a Prompt before creating for real

### Conversational Mode
- Interact with the AI in natural conversation
- Tell it what you want to adjust, and the AI understands the context of the previous conversation
- Good for Iterating until you get the image you want

---

## Settings before creating

### Aspect Ratio
Choose from preset options or set your own:

| Ratio | Use |
|----------|----------|
| 1:1 | a square Instagram post |
| 16:9 | a landscape image, computer wallpaper |
| 9:16 | a vertical image, mobile Story |
| 4:3 | a general image |
| 3:2 | a standard photo size |

### Model Version
- Choose the latest version (recommended), or an older version if you want a specific style

---

## Tips for creating images

1. **Start simple and add** — type a short Prompt first, see the result, then add detail
2. **Specify the style** — e.g. "oil painting", "watercolor", "photorealistic", "anime style"
3. **State the atmosphere** — e.g. "dramatic lighting", "soft light", "golden hour"
4. **Specify the camera angle** — e.g. "close-up", "aerial view", "eye level"
5. **Use Re-run** — if you don't like any image, try Generating again from the same Prompt

---

## Summary

Creating images on the Midjourney website is very easy: go to the Create page → type a Prompt → wait for the result → choose or refine. Start simple, then gradually learn additional parameters as needed.
