# Google Jules — a coding agent that works for you in the background 🤖

> Adapted from the official documentation at [jules.google](https://jules.google/)

**Google Jules** is Google's autonomous coding agent that works **asynchronously** — you assign a task (e.g. fix a bug, add a feature), and Jules goes off to work in its own cloud virtual machine, writes code, runs tests, then opens a **Pull Request** on GitHub for you to review. Like a teammate who quietly takes the work and does it, powered by Gemini.

## 📖 Terms worth knowing

| Term | In plain words |
|---|---|
| **Asynchronous** | Assign work and let it run on its own, no need to watch |
| **Task** | The work you assign Jules to do |
| **Pull Request (PR)** | The set of code changes Jules proposes for review/merge |
| **VM / Environment** | The cloud virtual machine Jules uses to run code |
| **Plan** | The plan Jules lays out before starting, which you can approve |

## ⭐ Highlights

- **Works in the background async** — assign it and go do something else
- **Connects to GitHub directly** — the work comes out as a PR ready for review
- **Plans before doing** — see the plan then approve
- **Runs in the cloud** — doesn't use your machine's resources
- **Uses the power of Gemini** to understand and fix code

## 🚀 Getting started

1. Go to [jules.google](https://jules.google/) and log in with a Google account
2. Connect your repository on GitHub
3. Assign a task, e.g. "Fix the login page bug where the button doesn't respond when pressed"
4. Review the plan → approve → wait for Jules to open a PR, then review it
