# Export — put the design to use 📤

> Adapted from the official documentation at [stitch.withgoogle.com](https://stitch.withgoogle.com/)

The design from Stitch doesn't end as just an image — you can export it to keep working.

## 🎯 Two main export paths

| Destination | Good for |
|---|---|
| **Figma** | Designers refining it / building a design system |
| **Code (HTML/CSS)** | Developers taking the look into a real site |

## 🎨 To Figma

- Copy the design into Figma to edit details, arrange components, and hand it to the team
- Good when the team already has a design process in Figma

## 💻 Use the code

- Pull the screen's front-end code as a starting point
- Saves time on the "convert design to code" step
- Continue in your existing editor/framework

## 💡 Tips

- Tidy the screen before exporting for a cleaner result
- Stitch is good as a "fast starting point," then polish in Figma/code
- Re-check responsiveness and details after using it
