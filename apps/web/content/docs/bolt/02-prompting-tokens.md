# Prompting & Tokens ⚡

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [support.bolt.new](https://support.bolt.new/)

## ✍️ สั่งงาน Bolt ให้ได้ผลดี

- **เริ่มจากโครงใหญ่** แล้วค่อยเพิ่มฟีเจอร์ทีละอย่าง
- **เจาะจง** — บอกหน้าตา ข้อมูล และพฤติกรรมที่ต้องการ
- **ทีละก้อน** — แก้/เพิ่มทีละเรื่อง ตรวจว่าทำงานก่อนไปต่อ
- ถ้าเจอ error ให้บอก Bolt ว่า error อะไร มันจะช่วยแก้

ตัวอย่าง:
> "สร้างเว็บ to-do list ด้วย React เพิ่ม/ลบ/ติ๊กเสร็จได้ บันทึกใน localStorage"

## 🪙 Tokens คืออะไร

**Tokens** คือหน่วยการใช้งาน AI ของ Bolt — ทุกครั้งที่สั่งให้ AI เขียน/แก้โค้ด จะใช้โทเคนตามปริมาณงาน (แต่ละแพ็กเกจมีโควตาต่อเดือน)

## 💰 เคล็ดลับประหยัด Tokens

- **สั่งงานชัดเจนครั้งเดียว** ดีกว่าสั่งคลุมเครือแล้วแก้หลายรอบ
- **แก้เฉพาะจุด** เมื่อปรับรายละเอียดเล็ก ๆ แทนการสั่งสร้างใหม่ทั้งหน้า
- รวมหลายคำขอเล็ก ๆ เป็นคำสั่งเดียวที่ชัด
- ตรวจผลก่อนสั่งต่อ เพื่อไม่ต้องย้อนแก้
