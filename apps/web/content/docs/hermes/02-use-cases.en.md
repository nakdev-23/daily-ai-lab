# What you can use Hermes for

> Compiled from the official docs at [hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs/), the User Stories & Use Cases section

Because Hermes is an agent that actually does work + learns and remembers across sessions, it's great for repetitive tasks that need continuous context.

## 🧑‍💻 Usage examples

- **A cross-platform personal assistant** — chat to instruct it via Telegram/Discord/Slack/WhatsApp from one place
- **Research and summarize** — search the web, read web pages/documents, then summarize for you
- **Routine automation** — instruct it on repeated tasks, and have Hermes build a "skill" that remembers how to do it next time
- **An assistant that "knows you"** — remembers your preferences/context across conversations, making answers more on-target over time
- **Multi-tool work** — search the web + control a browser + generate images + text-to-speech in one workflow

## 💡 What makes it different from a regular chatbot

- It has a **learning loop** — gets better from real use
- It has **persistent memory** — doesn't forget when you close and reopen
- Runs anywhere (your machine/the cloud) and is reachable via chat on 20+ platforms
