# Getting started with Windsurf 🏄

> Compiled in English from the official docs at [windsurf.com/docs](https://docs.windsurf.com/), the Getting Started section

The **Windsurf Editor** is a code editor with built-in AI (built on the VS Code base). If you've used VS Code before, it'll feel familiar right away.

## 🧭 Installation steps

1. Download from [windsurf.com](https://windsurf.com/) (available for Windows, macOS, Linux)
2. Install and open the program
3. Log in/sign up for a Windsurf account
4. If you've used VS Code: choose **import settings** to bring over your themes, keyboard shortcuts, and extensions

## 🗂️ Key parts of the screen

| Part | What it does |
|---|---|
| **Editor** | The main code-writing area (like VS Code) |
| **Cascade** | The agent-style AI assistant (right panel) |
| **Tab** | The auto-complete system as you type |
| **Command Palette** | Press `Ctrl/Cmd + Shift + P` to call all commands |

## ▶️ Try it for the first time

1. Open your project folder (File → Open Folder)
2. Open **Cascade** and type instructions in plain language, e.g. "Explain what this file does"
3. Type normal code and watch **Tab** suggest completions — press `Tab` to accept
