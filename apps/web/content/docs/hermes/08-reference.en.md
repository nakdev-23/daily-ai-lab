# Reference — commands and developer info

> Compiled from the official docs at [hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs/), the Reference / Developer Guide section

## ⌨️ CLI Commands

Hermes has command-line commands and **slash commands** (starting with `/`) for controlling its behavior — usable in both the Terminal UI and via the Gateway.

The main kinds of commands available:
- Open/manage conversations and sessions
- View/edit **memory** and **skills**
- Configure the model/behavior
- Call specific tools (web, vision, image, TTS, etc.)

> See the full list of commands and parameters in the official docs (the CLI Commands page)

## 🛠️ Developer Guide / Contributing

Hermes is open source (MIT License) — developers can contribute:
- The source code is on GitHub: https://github.com/nousresearch/hermes-agent
- There's a guide for setting up the development environment and submitting contributions
