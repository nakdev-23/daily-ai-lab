# Image Prompts — ใช้ภาพเป็นคำสั่ง

> อ้างอิงหลัก: [Image Prompts](https://docs.midjourney.com/hc/en-us/articles/32040250122381-Image-Prompts)

---

## Image Prompt คืออะไร

Image Prompt (การใช้ภาพเป็นคำสั่ง — การให้รูปภาพเป็นแรงบันดาลใจแก่ AI แทนการพิมพ์คำอธิบาย) ช่วยให้คุณนำภาพที่มีอยู่มาใช้เป็นส่วนหนึ่งของ Prompt แทนหรือเพิ่มเติมจากคำอธิบายข้อความ

Midjourney จะวิเคราะห์ภาพที่ให้ แล้วสร้างภาพใหม่โดยอ้างอิง:
- สไตล์ทางศิลปะ
- สีและบรรยากาศ
- องค์ประกอบและโครงสร้าง
- เนื้อหาในภาพ

---

## วิธีใช้ Image Prompt

### บนเว็บไซต์
1. คลิกไอคอน **รูปภาพ** (Image icon) ในช่อง Prompt
2. เลือก **"Upload from device"** หรือ **"Paste URL"**
3. เพิ่มคำอธิบายข้อความ (ถ้าต้องการ) ต่อจากภาพ
4. คลิก Generate

### บน Discord
ใช้ URL ของภาพนำหน้า Prompt:
```
/imagine prompt: https://example.com/your-image.jpg a beautiful landscape
```

> **สำคัญ:** URL ภาพต้องลงท้ายด้วย `.jpg`, `.png`, `.gif`, `.webp` และเป็นลิงก์ที่เข้าถึงได้สาธารณะ

### วิธีอัปโหลดภาพบน Discord
1. ลาก (Drag) ภาพไปวางในช่องแชต Discord ก่อน
2. Discord จะอัปโหลดและสร้างลิงก์ให้
3. คัดลอก URL แล้วใช้ใน `/imagine`

---

## Image Weight (น้ำหนักภาพ)

Parameter `--iw` (Image Weight — น้ำหนักที่ให้กับภาพต้นแบบ) ควบคุมว่าภาพต้นแบบมีอิทธิพลมากน้อยแค่ไหน:

| ค่า `--iw` | ความหมาย |
|-----------|---------|
| 0.5 | ภาพใหม่แตกต่างจากต้นแบบมาก |
| 1.0 | ค่าเริ่มต้น — ผสมผสานสมดุล |
| 2.0 | ภาพใหม่คล้ายต้นแบบมากขึ้น |

**ตัวอย่าง:**
```
/imagine prompt: https://example.com/photo.jpg cyberpunk city --iw 1.5
```

---

## การรวมหลาย Image Prompts

คุณสามารถใช้ภาพหลายรูปพร้อมกัน:
```
/imagine prompt: [URL ภาพ 1] [URL ภาพ 2] blend these two styles together
```

Midjourney จะผสมผสานสไตล์และองค์ประกอบจากทั้งสองภาพ

---

## Blend Command

สำหรับการผสมภาพโดยเฉพาะ ใช้คำสั่ง `/blend` (ทั้งบนเว็บและ Discord):

```
/blend
```

แล้วอัปโหลดภาพ 2-5 รูป ระบบจะผสมผสานทุกภาพเข้าด้วยกัน

> ดูรายละเอียดเพิ่มเติมในหัวข้อ "Blend Images"

---

## การโฮสต์ภาพบน Discord

หากต้องการลิงก์ภาพที่เสถียร:
1. ลากภาพไปในช่องแชต Discord (ไม่ต้องส่ง)
2. คลิกขวาที่ภาพที่อัปโหลด → Copy Link
3. ใช้ลิงก์นี้ใน Image Prompt

> **หมายเหตุ:** ลิงก์ Discord อาจหมดอายุ ควรใช้บริการโฮสต์รูปภาพถาวร เช่น Imgur หรือ Google Drive สำหรับงานระยะยาว

---

## ตัวอย่างการใช้งานจริง

### ถ่ายทอดสไตล์ศิลปิน
```
/imagine prompt: [URL ภาพวาดในสไตล์ที่ชอบ] a portrait of a woman --iw 1.0
```
ผลลัพธ์: ภาพบุคคลในสไตล์เดียวกับภาพต้นแบบ

### รีดีไซน์ผลิตภัณฑ์
```
/imagine prompt: [URL รูปผลิตภัณฑ์เดิม] futuristic redesign, product photography
```
ผลลัพธ์: ภาพผลิตภัณฑ์เดิมที่ออกแบบใหม่ในสไตล์อนาคต

### สร้างภาพในธีมเดียวกัน
```
/imagine prompt: [URL ภาพต้นแบบ] autumn forest version --iw 0.8
```
ผลลัพธ์: ภาพใหม่ที่มีองค์ประกอบคล้ายกันแต่ในบรรยากาศฤดูใบไม้ร่วง

---

## ข้อจำกัดและข้อควรระวัง

1. **ลิขสิทธิ์** — อย่าใช้ภาพที่มีลิขสิทธิ์เป็น Prompt โดยไม่ได้รับอนุญาต
2. **รูปคน** — ระวังการใช้ภาพคนจริงเพื่อสร้างภาพใหม่ อาจละเมิด Privacy (ความเป็นส่วนตัว)
3. **ภาพต้องเข้าถึงได้** — ลิงก์ต้องเป็นสาธารณะ ไม่ใช่ลิงก์ที่ต้องล็อกอินก่อน

---

## เคล็ดลับ

1. **ลองใส่ภาพโดยไม่มีข้อความ** — เพื่อดูว่า Midjourney ตีความภาพของคุณอย่างไร
2. **รวมกับ Style Reference** — ใช้ร่วมกับ `--sref` เพื่อควบคุมสไตล์แบบละเอียด
3. **ปรับ --iw ก่อน** — ก่อนเพิ่มรายละเอียดใน Prompt ลองปรับค่า Image Weight ก่อน
4. **ใช้ภาพคุณภาพสูง** — ภาพต้นแบบที่ชัดและมีรายละเอียดดีจะให้ผลลัพธ์ดีกว่า

---

## สรุป

Image Prompt เป็นเครื่องมือทรงพลังสำหรับการถ่ายทอดสไตล์หรือองค์ประกอบจากภาพหนึ่งไปยังภาพใหม่ ใช้ร่วมกับ Text Prompt เพื่อควบคุมผลลัพธ์ได้แม่นยำยิ่งขึ้น และปรับ `--iw` เพื่อกำหนดว่าต้องการให้ภาพต้นแบบมีอิทธิพลมากน้อยแค่ไหน
