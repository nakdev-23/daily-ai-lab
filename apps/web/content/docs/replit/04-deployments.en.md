# Deployments & Database — take your app live 🚀

> Compiled in English from the official docs at [docs.replit.com](https://docs.replit.com/)

## 🌐 Deployments (publishing)

When your app is ready, publish it for people to use online:

1. Click **Deploy** in your project
2. Choose the deploy type that suits your app:
   - **Autoscale** — scales with users (general websites)
   - **Static** — static-file websites (fast, cheap)
   - **Reserved VM** — a dedicated server that runs continuously (e.g. bots)
3. Get a public URL and continuous hosting

## 🗄️ Database

Replit has a built-in database to use:
- Store the app's data (e.g. users, posts, orders)
- Connect to it directly from your code
- Suitable for both small projects and real work

## 🔐 Auth (membership system)

There's a helper to build a **login system** for users to sign up/log in without writing it all yourself.

## 💡 Tips

- Choose the deploy type that matches your work (a static site is cheaper with Static)
- Check the database and permissions before going public
- Use Replit Agent to help configure the deploy
