# Simple Mode vs Custom Mode — the two song-creation modes

Suno has two main modes for creating songs: **Simple Mode** and **Custom Mode**. Each mode suits a different purpose.

---

## Simple Mode

Simple Mode is the mode where Suno handles everything for you. You just say what kind of song you want, and the AI creates it all.

### How to use Simple Mode

1. Go to the **Create** page
2. Check that the Toggle is on **"Simple"** (not Custom)
3. Type the song description in the **"Song Description"** box
4. Choose whether you want it **Instrumental** (no vocals) or not
5. Click **"Create"**

### What the AI handles in Simple Mode

| What the AI creates | Description |
|--------------------|---------|
| **Lyrics** | The AI writes all the lyrics |
| **Style** | The AI chooses the Genre and music sound |
| **Structure** | The AI sets the Verse, Chorus, Bridge itself |
| **Vocals** | The AI chooses a suitable singer's voice |

### Example Prompts in Simple Mode

```
A fun Pop song about going to the beach with friends
```

```
Upbeat jazz song about a busy city morning
```

```
Melancholic indie folk, feeling lost in life
```

---

## Custom Mode

Custom Mode lets you control every part of the song yourself. It's good for those who want a precise result.

### How to open Custom Mode

1. On the **Create** page, click the **"Custom"** button in the top-right corner of the song-creation box
2. Three new fields appear:
   - **Lyrics** — enter your own lyrics
   - **Style of Music** — specify the genre and sound characteristics
   - **Title** — name the song

### The fields in Custom Mode

#### 1. Lyrics

Enter lyrics you write yourself, using **Metatags** (special tags) to tell the AI what each section is:

```
[Verse] (the narrative section)
The sky is bright this morning
The sunlight shines beautifully

[Chorus] (the part people remember)
Today's a good day
Everything is bright and lovely
```

#### 2. Style of Music

Type words describing the music sound you want, such as:

```
upbeat pop, female vocals, guitar, summer vibes
```

```
dark hip-hop, trap beats, 808 bass, male rap
```

```
cinematic orchestral, strings, epic, emotional
```

#### 3. Title

Name the song however you like.

---

## Comparing Simple Mode vs Custom Mode

| Property | Simple Mode | Custom Mode |
|----------|------------|-------------|
| **Difficulty** | Very easy | Moderate |
| **Lyrics** | AI creates them | You write them |
| **Music style** | AI chooses | You specify |
| **Flexibility** | Low | Very high |
| **Time taken** | Fast | Takes longer |
| **Good for** | Beginners / experimenting | Those with a clear vision |

---

## When should you use which mode?

### Use Simple Mode when:
- You want to experiment with how Suno works
- You don't have lyrics you want to use
- You want inspiration from the AI
- You're in a hurry to create a song quickly

### Use Custom Mode when:
- You already have your own written lyrics
- You want a specific music style
- You're working at a Professional level
- You want detailed control over the song's structure

---

## Tips

> **Tip:** If you use Custom Mode but don't have lyrics yet, type `[Instrumental]` in the Lyrics field to create an instrumental song with no vocals.

> **Tip:** In Custom Mode, you can leave the Lyrics field empty and enter only the Style, so the AI creates the lyrics itself but uses the style you specified.

> **Tip:** Try mixing both modes — start with Simple Mode to find a genre you like, then refine in Custom Mode.
