# 11 — Connected Apps — เชื่อมต่อ Gemini กับแอปต่างๆ

อ้างอิง: [Use & Manage Connected Apps](https://support.google.com/gemini/answer/13695044) | [Google Workspace](https://support.google.com/gemini/answer/15229592)

---

## Connected Apps คืออะไร

**Connected Apps** คือฟีเจอร์ที่เชื่อมต่อ Gemini กับแอปและบริการต่างๆ ทั้งของ Google และบุคคลที่สาม เพื่อให้ Gemini ช่วยทำงานในแอปเหล่านั้นได้โดยตรง

เมื่อเชื่อมต่อแล้ว Gemini สามารถ:
- อ่านและสรุป Email ใน Gmail
- เพิ่มนัดหมายใน Google Calendar
- สร้างเอกสารใน Google Docs
- ค้นหาไฟล์ใน Google Drive
- และอีกมากมาย

---

## วิธีเชื่อมต่อแอป

1. ไปที่ [gemini.google.com](https://gemini.google.com)
2. คลิกเมนู (☰) → **Settings** → **Connected apps**
3. หรือเมื่อใช้งาน Gemini แล้วถามเกี่ยวกับข้อมูลในแอป Gemini จะแจ้งให้เชื่อมต่อ
4. คลิก **Connect** สำหรับแอปที่ต้องการ
5. ทำตามขั้นตอนอนุญาตการเข้าถึง

**วิธียกเลิกการเชื่อมต่อ:**
1. ไปที่ Settings → Connected apps
2. หาแอปที่ต้องการยกเลิก → คลิก **Disconnect**

## เชื่อมต่อ Google Workspace

**Google Workspace** เชื่อมต่อ Gmail, Drive, Docs, Sheets, Calendar ทั้งหมดในครั้งเดียว

**วิธีเชื่อมต่อ:**
1. ไปที่ gemini.google.com
2. เมนู (☰) → **Settings** → **Connected apps** → **Google Workspace**
3. คลิก **Connect** และอนุญาตการเข้าถึง

**ต้องเปิด Keep Activity** เพื่อให้ Gemini เข้าถึงข้อมูลใน Google Workspace

---

## Personalization ผ่าน Connected Apps

เมื่อเชื่อมต่อแอปแล้ว Gemini สามารถปรับคำตอบให้เหมาะกับคุณโดยอิงจาก:
- ข้อมูลใน Gmail — รู้ว่าคุณกำลังคุยกับใคร งานอะไร
- ข้อมูลใน Calendar — รู้กำหนดการของคุณ
- ข้อมูลใน Drive — รู้ว่าคุณมีเอกสารอะไร

อ้างอิง: [About Personalization with Connected Apps](https://support.google.com/gemini/answer/16836988)

---

## นำเข้า GitHub Repository

นอกจาก Connected Apps ทั่วไป คุณยังสามารถ import โค้ดจาก GitHub มาให้ Gemini วิเคราะห์ได้:

1. คลิก **Add files** → **More Uploads** → **Import Code**
2. วาง URL ของ GitHub repository
3. Gemini จะดึงโค้ดมาวิเคราะห์ทันที

อ้างอิง: [Import GitHub Repository](https://support.google.com/gemini/answer/16176929)

---

## การใช้ Connected Apps กับบัญชีงาน/โรงเรียน

สำหรับผู้ใช้บัญชีงานหรือโรงเรียน:
- ผู้ดูแลระบบ (Admin) ต้องเปิดสิทธิ์ให้ก่อน
- บางแอปอาจไม่พร้อมใช้งานขึ้นอยู่กับนโยบายองค์กร

อ้างอิง: [Connected Apps for Work/School](https://support.google.com/gemini/answer/14959807)

## ควบคุมสมาร์ทโฮม

เชื่อมต่อ **Google Home** กับ Gemini เพื่อควบคุมอุปกรณ์ในบ้านด้วยเสียงหรือข้อความ เช่น:
```
"ปิดไฟในห้องนอน"
"ตั้งอุณหภูมิแอร์ที่ 25 องศา"
"เปิดทีวีในห้องนั่งเล่น"
```

อ้างอิง: [Smart Home with Gemini](https://support.google.com/gemini/answer/15335456)

---

## จัดการนัดหมายและปฏิทิน

เมื่อเชื่อมต่อ Google Calendar แล้ว:
```
"มีนัดอะไรพรุ่งนี้บ้าง?"
"เพิ่มประชุมทีมวันจันทร์ 10 โมง"
"ยกเลิกนัดหมายวันศุกร์บ่าย 2"
```

อ้างอิง: [Calendar with Gemini](https://support.google.com/gemini/answer/15305236)

## สรุป

Connected Apps ทำให้ Gemini กลายเป็น "ศูนย์กลาง" ที่เชื่อมต่อทุกแอปของคุณ แทนที่จะต้องสลับไปมาระหว่างแอปหลายตัว คุณสามารถถาม Gemini ที่เดียวแล้วให้มันทำงานใน Gmail, Calendar, Drive หรือแอปอื่นๆ แทนได้
