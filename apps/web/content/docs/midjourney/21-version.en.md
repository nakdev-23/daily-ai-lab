# Version — the AI model version

> Main reference: [Version](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version)

---

## What is Version

Midjourney has several versions of its AI model (an artificial intelligence system — a program trained to create images), each with a different style and capabilities.

Use the `--version` or `--v` Parameter to choose a version:

```
a landscape --v 6.1
a portrait --version 7
```

---

## Main versions

### Midjourney V7 (2025)
- The latest version as of 2025
- The best capabilities for detail, faces, and anatomy
- Understands complex Prompts better
- Use: `--v 7`

### Midjourney V6.1
- Improved from V6 with better detail
- A balance between quality and speed
- Use: `--v 6.1`

### Midjourney V6
- A significant leap in quality
- Understands Natural Language better than previous versions
- Better support for Text in images
- Use: `--v 6`

### Midjourney V5.2
- A very popular version during 2023-2024
- A beautiful Aesthetic, prominent colors
- Use: `--v 5.2`

### Midjourney V5.1
- Use: `--v 5.1`

---

## Niji Model — the Anime style

`--niji` (a special model for Anime — creating images in the Japanese cartoon style) is a model developed together with Spellbrush.

```
a samurai warrior --niji 6
a magical girl --niji 6
```

| Niji version | Style |
|--------------|-------|
| `--niji 5` | classic Anime |
| `--niji 6` | modern Anime, high detail |

---

## How to choose a version

### Use the latest version when:
- You want the best quality
- You want accurate facial detail and anatomy
- Commercial or Professional work

### Use an older version when:
- You like that version's specific style
- You want results consistent with previous work
- V5 has a Painterly style some people prefer

---

## Setting the default version

Instead of typing `--v 6` every time, you can set the default version in Settings:

- On Discord: type `/settings` and choose the version
- On the web: go to Settings → Default Model

## Summary

Use `--v 7` or the latest version for general work for the highest quality, use `--niji 6` for the Anime style, and try an older version if you want a specific Aesthetic.
