# 04 — การอัปโหลดและวิเคราะห์ไฟล์

อ้างอิง: [Upload & Analyze Files](https://support.google.com/gemini/answer/14903178) | [GitHub Repos](https://support.google.com/gemini/answer/16176929)

---

## ทำอะไรได้บ้างกับการอัปโหลดไฟล์

คุณสามารถอัปโหลดเอกสาร สเปรดชีต รูปภาพ วิดีโอ เสียง โค้ด และ Notebook จาก NotebookLM เพื่อให้ Gemini:
- **วิเคราะห์** และสรุปเนื้อหา
- **ตอบคำถาม** เกี่ยวกับข้อมูลในไฟล์
- **เปรียบเทียบ** หลายไฟล์พร้อมกัน
- **สร้างกราฟ** หรือ visualization จากข้อมูล

---

## วิธีอัปโหลดไฟล์

### อัปโหลดจากเครื่อง
1. ไปที่ [gemini.google.com](https://gemini.google.com)
2. คลิกไอคอน **Add files** (📎) ในช่องพิมพ์ข้อความ
3. คลิก **Upload Files** → เลือกไฟล์จากเครื่อง
4. พิมพ์ prompt แล้วคลิก Submit

### อัปโหลดโฟลเดอร์โค้ด
1. คลิก **Add files** → **More Uploads** → **Import Code** → **Upload folder**
2. เลือกโฟลเดอร์โค้ดจากเครื่อง

### เชื่อมต่อ GitHub Repository
1. คลิก **Add files** → **More Uploads** → **Import Code**
2. วาง URL ของ GitHub repository หรือ branch
3. Gemini จะดึงโค้ดมาวิเคราะห์

> **ข้อจำกัด GitHub:** รองรับสูงสุด 5,000 ไฟล์ต่อ repo และขนาดรวมไม่เกิน 100 MB

### อัปโหลดจาก Google Drive
1. คลิก **Add files** → **Add from Drive** (ไอคอน Drive)
2. ต้องเปิด **Keep Activity** และเชื่อมต่อ Google Workspace ก่อน

### อัปโหลดจาก NotebookLM
1. คลิก **Add files** → **More Uploads** → **Notebooks** (ไอคอน Notebook)
2. เลือก Notebook ที่ต้องการ

## ขีดจำกัดการอัปโหลด

| ประเภท | ขีดจำกัด |
|---|---|
| **จำนวนไฟล์ต่อ prompt** | สูงสุด 10 ไฟล์ (อาจเปลี่ยนแปลงได้) |
| **ขนาดวิดีโอ** | สูงสุด 2 GB ต่อไฟล์ |
| **ขนาดไฟล์อื่นๆ** | สูงสุด 100 MB ต่อไฟล์ |
| **ความยาววิดีโอรวม** | 5 นาที (ฟรี) / 1 ชั่วโมง (Pro/Ultra) |
| **ความยาวเสียงรวม** | 10 นาที (ฟรี) / 3 ชั่วโมง (Pro/Ultra) |
| **โฟลเดอร์/GitHub repo** | สูงสุด 5,000 ไฟล์, ไม่เกิน 100 MB |
| **ZIP file** | สูงสุด 10 ไฟล์ภายใน, ไม่เกิน 100 MB (ไม่รองรับวิดีโอ/เสียงใน ZIP) |

---

## ประเภทไฟล์ที่รองรับ

Gemini รองรับไฟล์ส่วนใหญ่ รวมถึง:

**เอกสาร:** PDF, DOCX, TXT, XLSX, CSV, PPTX, RTF, Markdown

**รูปภาพ:** JPEG, PNG, GIF, WebP, HEIC/HEIF

**วิดีโอ:** MP4, MOV, AVI, MKV, WebM และอื่นๆ

**เสียง:** MP3, WAV, FLAC, AAC, OGG, OPUS

**โค้ด:** ไฟล์โค้ดทุกประเภท, ZIP

## Error Messages ที่อาจพบ

### "Delete data to upload file"
**สาเหตุ:** พื้นที่จัดเก็บข้อมูลใน Gemini Apps เต็ม (แยกจาก Google Drive)

**วิธีแก้:**
1. ไปที่ gemini.google.com
2. คลิก **Settings & help** → **Activity**
3. ลบกิจกรรมหรือแชทที่ไม่ต้องการ
4. รอสักครู่แล้วลองอีกครั้ง

> **ทิป:** แชทที่มีวิดีโอ รูปภาพ หรือไฟล์จาก Drive จะกินพื้นที่มากกว่าแชทปกติ

### "You've reached your limit for chats with files"
**สาเหตุ:** ใช้งานเกินโควต้าการอัปโหลดในช่วงเวลานั้น

**วิธีแก้:** รอให้โควต้ารีเซ็ต หรืออัปเกรดเป็น Google AI Pro/Ultra

### "Your uploads may be too large for the best results"
**สาเหตุ:** ไฟล์ใหญ่เกินกว่า Context Window จะรับได้ครบ

**วิธีแก้:** แบ่งไฟล์ให้เล็กลง หรืออัปเกรดเป็นแผนที่มี Context Window 1 ล้าน tokens

---

## Context Window กับการอัปโหลดไฟล์

**Context Window** กำหนดว่า Gemini จะ "อ่าน" ข้อมูลได้แค่ไหน:

- **32K tokens (ฟรี):** เหมาะสำหรับเอกสารสั้นๆ
- **128K tokens (Plus):** รับข้อมูลได้มากขึ้น
- **1M tokens (Pro/Ultra):** อ่านได้ถึง 1,500 หน้า หรือโค้ด 30,000 บรรทัด

> หากเนื้อหาในไฟล์เกิน Context Window Gemini อาจ "พลาด" รายละเอียดบางส่วน โดยเฉพาะในไฟล์ที่มีข้อมูลกระจายทั่วทั้งเอกสาร

## สรุป

การอัปโหลดไฟล์ทำให้ Gemini กลายเป็นเครื่องมือวิเคราะห์ข้อมูลที่ทรงพลัง รองรับไฟล์เกือบทุกประเภท ทั้งเอกสาร รูปภาพ วิดีโอ และโค้ด สำหรับงานที่ต้องวิเคราะห์ไฟล์ใหญ่หรือหลายไฟล์พร้อมกัน ควรอัปเกรดเป็น Pro/Ultra เพื่อได้ Context Window ที่ใหญ่ขึ้น
