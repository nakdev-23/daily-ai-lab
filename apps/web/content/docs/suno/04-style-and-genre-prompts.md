# Style Prompts และการกำหนด Genre เพลง

**Style Prompt** (คำสั่งสไตล์) คือหัวใจสำคัญที่สุดใน Custom Mode ช่องนี้บอก Suno ว่าเพลงของคุณควรฟังดูอย่างไร ตั้งแต่ Genre (แนวเพลง) ไปจนถึงเสียงเครื่องดนตรีและอารมณ์โดยรวม

---

## Style of Music Field คืออะไร?

**Style of Music** (สไตล์เพลง) คือช่องที่คุณพิมพ์คำอธิบายเกี่ยวกับเสียงดนตรีที่ต้องการ Suno จะนำคำเหล่านี้ไปใช้กำหนด:

- **Genre** (แนวเพลง) — เช่น Pop, Rock, Jazz, Hip-Hop
- **Mood** (อารมณ์) — เช่น Happy, Sad, Dark, Energetic
- **Instruments** (เครื่องดนตรี) — เช่น Guitar, Piano, Drums
- **Tempo** (จังหวะความเร็ว) — เช่น Slow, Upbeat, Fast
- **Vocal Style** (สไตล์เสียงร้อง) — เช่น Male Vocals, Female Vocals, Choir

---

## Genre (แนวเพลง) ที่ Suno รองรับ

### Pop & Electronic

| Genre | ความหมาย | ลักษณะ |
|-------|----------|-------|
| **Pop** | เพลงป็อป | สดใส จำง่าย กว้างขวาง |
| **Synth-Pop** | ป็อปผสมซินธ์ | ใช้ Synthesizer เป็นหลัก |
| **EDM** — Electronic Dance Music | ดนตรีอิเล็กทรอนิกส์สำหรับเต้น | เบสหนัก จังหวะเร็ว |
| **House** | เฮาส์ (แนว Electronic) | จังหวะ 4/4 เบต ๆ สม่ำเสมอ |
| **Techno** | เทคโน | มืด ซ้ำ ๆ เร็ว |
| **Trap** | แทร็พ | Hi-hat เร็ว เบส 808 |
| **Lo-fi** | โลไฟ (คุณภาพเสียงต่ำโดยตั้งใจ) | ฟังดูเก่า นุ่ม ผ่อนคลาย |

### Rock & Alternative

| Genre | ความหมาย | ลักษณะ |
|-------|----------|-------|
| **Rock** | ร็อค | กีตาร์ไฟฟ้า กลอง เบส |
| **Hard Rock** | ฮาร์ดร็อค | หนัก ดัง พลังสูง |
| **Metal** | เมทัล (โลหะ) | กีตาร์ Distortion หนักมาก |
| **Punk** | พังก์ | เร็ว สั้น พลังก้าวร้าว |
| **Indie Rock** | อินดี้ร็อค | ทางเลือก ไม่กระแสหลัก |
| **Alternative** | อัลเทอร์เนทีฟ | ผสมหลายแนว |
| **Grunge** | กรันจ์ | หนัก มืด ยุค 90s |

### R&B, Soul & Hip-Hop

| Genre | ความหมาย | ลักษณะ |
|-------|----------|-------|
| **R&B** — Rhythm and Blues | อาร์แอนด์บี | นุ่ม โรแมนติก มีจังหวะ |
| **Soul** | โซล | อารมณ์ลึก เสียงร้องพลัง |
| **Hip-Hop** | ฮิปฮอป | Beat + Rap + Sample |
| **Rap** | แร็พ | พูดเป็นจังหวะ เร็วหรือช้า |
| **Neo-Soul** | นีโอโซล | โซลสมัยใหม่ ผสม Jazz |
| **Funk** | ฟังก์ | จังหวะติดหู เบสเด่น |

### Jazz & Classical

| Genre | ความหมาย | ลักษณะ |
|-------|----------|-------|
| **Jazz** | แจ๊ส | Improvisation สุ่มสร้างสรรค์ |
| **Blues** | บลูส์ | อารมณ์เศร้า กีตาร์ดิบ |
| **Classical** | คลาสสิก | ออเคสตรา ไม่มีเนื้อร้อง |
| **Orchestral** | ออร์เคสตรัล — วงออร์เคสตรา | เพลงประกอบหนังหรืองานยิ่งใหญ่ |
| **Cinematic** | ซีนีแมติก — สไตล์หนัง | อารมณ์แบบหนัง Epic |

### Folk & Country

| Genre | ความหมาย | ลักษณะ |
|-------|----------|-------|
| **Folk** | โฟล์ค | เรียบง่าย กีตาร์อะคูสติก |
| **Country** | คันทรี | สไตล์อเมริกัน กีตาร์ Pedal Steel |
| **Indie Folk** | อินดี้โฟล์ค | โฟล์คแบบอิสระ |
| **Bluegrass** | บลูแกรส | กีตาร์ Banjo ชนบทอเมริกัน |

### World & Ethnic

| Genre | ความหมาย | ลักษณะ |
|-------|----------|-------|
| **Bossa Nova** | บอสซาโนวา | แจ๊สบราซิล นุ่มเบา |
| **Reggae** | เรกเก้ | จังหวะ Offbeat จาเมกา |
| **Afrobeat** | อาโฟรบีต | แอฟริกัน จังหวะซับซ้อน |
| **Latin** | ลาติน | สเปน/ลาตินอเมริกา สนุก |
| **K-Pop** | เคป็อป | เกาหลี ป็อปสมัยใหม่ |

## วิธีเขียน Style Prompt ที่ดี

### สูตรพื้นฐาน

```
[Genre] + [อารมณ์] + [เครื่องดนตรีหลัก] + [ลักษณะเสียงร้อง] + [ยุคสมัย/อ้างอิง]
```

### ตัวอย่างที่ดี

```
upbeat pop, female vocals, acoustic guitar, piano, summer vibes, 2020s
```

```
dark trap, male rap, 808 bass, hi-hats, atmospheric synths, cinematic
```

```
romantic jazz ballad, soft female vocals, piano, saxophone, late night
```

```
epic cinematic orchestral, no vocals, strings, brass, drums, heroic
```

```
indie folk, warm acoustic, storytelling, gentle male vocals, introspective
```

### คำที่ใช้บ่อยสำหรับ Mood (อารมณ์)

| คำ | ความหมาย |
|----|---------|
| `upbeat` | สดใส มีพลัง |
| `melancholic` | เศร้าเล็กน้อย คิดถึง |
| `dark` | มืด หนัก |
| `ethereal` | เหมือนอยู่ในฝัน ลอย ๆ |
| `aggressive` | ก้าวร้าว รุนแรง |
| `chill` | ผ่อนคลาย สบาย |
| `nostalgic` | หวนคิดถึงอดีต |
| `epic` | ยิ่งใหญ่ สุดอลังการ |
| `romantic` | โรแมนติก หวาน |
| `groovy` | ติดหู ขยับตัวตาม |

### คำสำหรับ Tempo (จังหวะ)

| คำ | BPM โดยประมาณ | ความหมาย |
|----|-------------|---------|
| `slow` | 60–80 BPM | ช้า |
| `mid-tempo` | 90–110 BPM | ปานกลาง |
| `upbeat` | 110–130 BPM | เร็วพอประมาณ |
| `fast` | 130–160 BPM | เร็ว |
| `frantic` | 160+ BPM | เร็วมากจนวุ่นวาย |

> **BPM — Beats Per Minute** (จำนวนจังหวะต่อนาที — ยิ่งมาก ยิ่งเร็ว)

## Creative Prompt Boosting (การเพิ่มพลังคำสั่ง)

ใน Suno v4.5 มีฟีเจอร์ **Creative Prompt Boosting** (การเพิ่มความสร้างสรรค์ของ Prompt) ที่ช่วยให้ AI เข้าใจ Style Prompt ได้ดีขึ้น โดยใช้ภาษาที่หลากหลายและละเอียดมากขึ้น

### คำสั่งสไตล์แบบละเอียด

แทนที่จะพิมพ์:
```
sad pop song
```

ลองพิมพ์ว่า:
```
tender melancholic indie pop, fingerpicked acoustic guitar with gentle strings,
breathy female vocals with emotional vibrato, slow tempo, bittersweet lyrics
about longing and loss, reminiscent of Phoebe Bridgers or Bon Iver
```

## ตัวอย่างสไตล์สำหรับแต่ละอารมณ์

### สำหรับเพลงผ่อนคลาย/นอนหลับ
```
lo-fi hip-hop, chill beats, soft piano, rain sounds, no vocals, 70 BPM
```

### สำหรับเพลงออกกำลังกาย
```
high energy EDM, aggressive synths, fast tempo, 140 BPM, power drop, motivational
```

### สำหรับเพลงเด็ก
```
cheerful children's song, ukulele, light percussion, happy female vocals, simple melody
```

### สำหรับเพลงประกอบ Podcast หรือ Video
```
background ambient music, no vocals, soft piano, minimal, corporate, professional
```

## สิ่งที่ไม่ควรทำ

- **อย่าใส่ชื่อศิลปิน** เช่น "เพลงแบบ Taylor Swift" — Suno จะไม่ทำตามและอาจไม่ได้ผลที่ต้องการ
- **อย่าใส่ชื่อเพลงที่มีลิขสิทธิ์** เช่น "ทำนองแบบ Shape of You" — ถือเป็นการละเมิดลิขสิทธิ์
- **อย่า Prompt ยาวเกิน 120 ตัวอักษร** — Suno อาจตัดทอนหรือมองข้ามส่วนท้าย
- **อย่าใช้คำสั่งขัดแย้งกัน** เช่น "slow fast tempo" — จะทำให้ AI สับสน
