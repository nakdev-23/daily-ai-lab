# Scenebuilder — string shots into a film 🎞️

> Adapted from the official documentation at [labs.google/flow](https://labs.google/flow/about)

Most AI clips are short, single shots. **Scenebuilder** lets you **join several shots into a long continuous story**, like editing a film.

## ⭐ What it can do

- Order several shots into a timeline
- Continue from the previous shot's last frame, for continuity
- Reuse the same Ingredients across shots so characters/scenes stay consistent
- Adjust/create new shots to insert

## ▶️ Steps (overview)

1. Create the first shot (from text or an image)
2. Add the next shot — continuing the story / continuing from the previous frame
3. Order them in Scenebuilder
4. Preview the whole story, then export

## 💡 Storytelling tips

- Lay out a short story structure first (beginning-middle-end)
- Use one set of Ingredients throughout for cohesion
- Match the camera to the story's rhythm
