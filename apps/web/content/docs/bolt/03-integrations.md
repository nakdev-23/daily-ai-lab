# Integrations — ต่อบริการภายนอก 🔌

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [support.bolt.new](https://support.bolt.new/)

Bolt ต่อกับบริการยอดนิยมเพื่อทำแอปให้ครบวงจร

## 🗄️ Supabase (ฐานข้อมูล + Auth)

- เก็บข้อมูลแอปจริง และทำระบบล็อกอิน
- เชื่อมในโปรเจกต์ แล้วสั่ง Bolt ให้เพิ่มฟีเจอร์ที่ใช้ข้อมูล
- เหมาะเมื่อแอปต้องบันทึกข้อมูลถาวร/มีผู้ใช้หลายคน

## 🎨 Figma

- นำดีไซน์จาก Figma มาเป็นจุดเริ่มของหน้าตาแอป
- ช่วยให้แอปตรงกับแบบที่ออกแบบไว้

## 📱 Expo (แอปมือถือ)

- ต่อกับ **Expo** เพื่อทำแอปมือถือ (iOS/Android) จาก Bolt
- เหมาะเมื่ออยากได้แอปข้ามแพลตฟอร์ม ไม่ใช่แค่เว็บ

## ▶️ แนวทางใช้งาน

1. เปิดเมนู Integrations ในโปรเจกต์
2. เลือกบริการที่ต้องการแล้วเชื่อมต่อ
3. สั่ง Bolt ใช้บริการนั้น เช่น "บันทึกข้อมูลผู้ใช้ลง Supabase"

## 💡 เคล็ดลับ

- ต่อ Supabase ตั้งแต่เริ่มเก็บข้อมูลจริง
- ตรวจสิทธิ์การเข้าถึงข้อมูลให้รัดกุม
