# Deploy & GitHub — get your app on the web 🚀

> Adapted from the official documentation at [support.bolt.new](https://support.bolt.new/)

## 🌐 Deploy online

Bolt publishes apps via **Netlify** in a few clicks:

1. Hit the **Deploy** button in the project
2. Bolt builds and pushes it to Netlify for you
3. You get a **public link** to share right away

Whenever you make changes and want to update the live site, just Deploy again.

## 🐙 Sync with GitHub

Connect GitHub to:
- **Store your code** in a repository (backup)
- Edit the code outside Bolt and sync
- Collaborate with other developers

## 💡 Tips

- Test the app in the preview before you Deploy
- Use GitHub as an exit path if you want to continue developing on your own later
- If you've connected Supabase, make sure the production settings are complete before going public
