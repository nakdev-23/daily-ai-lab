# 09 — Canvas — create documents, apps, slides

Reference: [Create docs, apps & more with Canvas](https://support.google.com/gemini/answer/16047321) | [Quizzes & Flashcards](https://support.google.com/gemini/answer/16275879)

---

## What is Canvas

**Canvas** is a real-time workspace with Gemini that displays beside the chat. You can create or edit:

- **Documents (Docs)** — articles, reports, letters
- **Presentations** — a slide deck with design
- **Apps and web pages** — simple apps, web pages, interactive tools
- **Code** — write and run Python, JavaScript, etc.
- **Quizzes and learning materials** — interactive knowledge tests
- **Infographics** — infographic images from data

---

## How to start using Canvas

1. Go to [gemini.google.com](https://gemini.google.com)
2. Click **Add Files** → **Canvas**
3. Type a prompt describing what you want to create
4. Click Submit

**Example prompts:**
```
"Create a slide presentation about climate change with 5 slides"

"Make a quiz to test me on Python basics"

"Write a professional cover letter for a software engineer position"

"Create a simple web app to calculate BMI"

"Make an infographic showing the benefits of exercise"
```

## What you can do with a Doc in Canvas

### Edit text directly
Click in the Canvas area and type your edits. Changes are saved automatically.

### Ask Gemini to edit a part
1. Select the text you want to change in Canvas
2. Type a prompt in the message box for what you want changed
3. Press Enter

Or select text and click **Suggest edits** to have Gemini suggest changes.

### Adjust length and tone (Quick Edits)
In the Canvas panel on the right:
- **Change length** — make it shorter or longer
- **Change tone** — make it more formal, or more casual

### Format text (Toolbar)
Select text and use the toolbar at the top:
- Headings
- **Bold**
- *Italic*
- Bullet/Numbered lists

### Add LaTeX (math formulas)
1. Click **Create** in the Canvas panel → **LaTeX**
2. Click a formula in Canvas to edit it

> LaTeX exported to PDF displays formulas correctly.

---

## What you can do with an App/Code in Canvas

### Edit code directly
Click **Code** (top-right of Canvas) to view and edit the code.

### View console logs
Click **Show console** to see errors and logs from running the app.

### View recent changes
Click **Code** → **Show recent changes** to see what changed most recently.

### Add AI features to the app
1. Click **Add Gemini features** in the Canvas panel
2. Gemini adds AI abilities to the app, e.g. text generation, image generation

### Export Python to Colab
1. Open the chat with Python code
2. Click **Export to Colab** at the top of Canvas

---

## Create something from a Doc in Canvas

From a document created in the Canvas panel, you can create more:

1. Click **Create** in the Canvas panel
2. Choose what to create:
   - **Slides** — type a prompt to describe it
   - **Audio Overview** — listen to the report podcast-style
   - **Quiz** — test knowledge from the content
   - **Infographic** — a visual data summary
   - **Web page** — convert the content into a web page

> This feature requires being 18+.

---

## Share, copy, and export from Canvas

### Share Canvas
1. Click **Share & export** → **Share**
2. Copy the g.co/gemini/share link and send it to someone
3. Or share via supported social media

> **Important:** When you share an app, everyone with the link can view and interact with the data.

### Export documents
- **Export to Docs** — open in Google Docs
- **Export to Slides** — open in Google Slides (or PDF)
- **Copy Contents** — copy the text

### Copy & edit shared content
When you open someone else's Canvas link:
1. Click **Copy Canvas** at the bottom
2. Continue editing in your own Canvas

## Quiz, Flashcards, Storybook, and learning tools

Gemini supports creating various learning materials through Canvas:

### Quiz
- Create a quiz from a topic or an uploaded document
- Test yourself interactively
- prompt: `"Create a quiz to test me on [topic]"`

### Flashcards
- Create memorization cards
- prompt: `"Make flashcards for [topic]"`

### Illustrated Storybook
- Create a storybook with AI illustrations
- prompt: `"Create an illustrated storybook about [subject]"`

## Cautions

- You can only share public Canvas links on the web app, not on mobile
- Users under 18 can't create or view some types of shared content
- Safety in Canvas: [Canvas Safety](https://support.google.com/gemini/answer/16419134)
