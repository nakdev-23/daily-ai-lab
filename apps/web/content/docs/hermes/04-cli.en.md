# Use Hermes via the CLI

> Compiled from the official docs at [hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs/), the Using Hermes section

## 💻 Terminal UI

Run `hermes` to open the usage screen in the terminal — type to chat with the agent like a chat, but it runs on your machine and can access tools/files.

## ⌨️ Slash Commands

Within a conversation, there are commands starting with `/` that control its behavior — and these commands **work in both the Terminal UI and via the Gateway** (chat from various platforms).

Examples of the kinds of commands usually available:
- Manage conversations/sessions
- View/manage **memory** and **skills**
- Configure the model/behavior
- Call specific tools

> See the full list of commands in the **Reference (CLI Commands)** section

## 🔁 Working continuously

Because Hermes has persistent memory and a learning loop, using it via the CLI repeatedly gradually makes it understand your work style and build skills to help the next time.
