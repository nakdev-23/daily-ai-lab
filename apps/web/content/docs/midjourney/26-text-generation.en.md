# Text Generation — create text in images

> Main reference: [Text Generation](https://docs.midjourney.com/hc/en-us/articles/32502277092109-Text-Generation)

---

## What is Text Generation

Text Generation (Midjourney's ability to create readable text within an image) is a feature added in Midjourney version 6 and up. Previously, Midjourney often created blurry or unreadable text.

---

## How to put text in an image

Use double quotation marks (`"`) around the text you want:

```
a poster with the text "Hello World"
a shop sign reading "Coffee Shop"
```

**Example:**
```
a vintage travel poster for Paris, text reading "Discover Paris"
a warning sign in a dark forest that says "Beware"
```

---

## What you can do

### Signs and symbols
```
a neon sign glowing in the dark saying "Open 24 Hours"
a wooden sign on a trail reading "Summit - 2 miles"
```

### Logos and Branding
```
a minimalist logo design with the text "NOVA" on white background
a coffee brand logo with script font saying "Morning Brew"
```

### Posters and cards
```
a motivational poster with mountains and text "Keep Going"
a birthday card design with "Happy Birthday" in bubble letters
```

### Book Cover
```
a fantasy book cover titled "The Last Dragon" 
```

---

## Tips for creating text

1. **Use English only** — Midjourney creates English text best
2. **Short text** — 1-5 words usually works best
3. **Specify the Font style** — e.g. "in bold serif font", "handwritten style", "neon glowing"
4. **State the position** — "at the top", "centered", "at the bottom"

**A good Prompt example:**
```
a luxury perfume advertisement, elegant white bottle, gold text "ESSENCE" in serif font, minimalist background
```

---

## Limitations

- The text may not be perfect every time; try Re-running if not satisfied
- Long text often gives a poor result
- Thai and other non-Latin Script languages may not work

---

## Edit text with the Editor

If the text in the image is wrong, use the Editor:
1. Click **Edit** on the created image
2. Surround the text area
3. Type a new Prompt specifying the text you want
4. Generate that part again

---

## Summary

Midjourney V6+'s Text Generation makes creating images with readable text much better. Use `"..."` marks around the text in the Prompt and specify the Font style for the best result.
