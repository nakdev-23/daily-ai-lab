# Memories & Rules — teach Windsurf to know your project 🧠

> Compiled in English from the official docs at [windsurf.com/docs](https://docs.windsurf.com/), the Memories section

When working on the same project repeatedly, you don't want to tell the AI "use TypeScript" or "name things this way" every time — **Memories** and **Rules** let Cascade remember these things itself.

## 📖 How are these two different?

| What you use | What it is |
|---|---|
| **Rules** | Rules "you write yourself" for the AI to always follow (e.g. code style, language used) |
| **Memories** | Things Cascade "remembers itself" while working, to use later |

## ⭐ What it's for

- Set coding standards (e.g. "use 2 spaces", "comment in English")
- State the project context (e.g. "this is a Next.js + Supabase site")
- Have the AI remember agreed-upon things without repeating them

## ▶️ How to set up Rules

1. Create the project's rules file (e.g. via the Rules menu in Windsurf)
2. Write the guidelines as bullet points, e.g.
   ```
   - Always use TypeScript
   - Name components in PascalCase
   - Write explanatory comments in English
   ```
3. Cascade references these rules every time it works
