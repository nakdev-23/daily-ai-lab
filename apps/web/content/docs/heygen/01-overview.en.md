# HeyGen — AI avatar videos that speak for you 🎬

> Compiled in English from the official docs at [docs.heygen.com](https://docs.heygen.com/)

**HeyGen** is a platform for creating videos with an **AI avatar** — type a script, and an AI character speaks it out like a real person, without you setting up a camera to film. It's great for tutorial videos, marketing, presentations, or multilingual content, supporting speech in dozens of languages, including Thai.

## 📖 Terms worth knowing

| Term | Plain meaning |
|---|---|
| **Avatar** | An AI character that speaks and moves its lips to the script |
| **Instant Avatar** | Create an avatar from a short video recording of yourself |
| **Photo Avatar** | Create an avatar from a photo |
| **Script** | The lines the avatar will speak |
| **Template** | A ready-made video template to adapt |
| **Video Translation** | Translate + dub a video into another language |

## ⭐ Main capabilities (per the official docs menu)

- **AI Avatars** — pick a ready-made avatar, or create your own
- **Create video from a script** — type text, the avatar speaks it
- **Templates** — start from beautiful templates quickly
- **Video Translation** — make one clip speak many languages
- **Interactive / Streaming Avatar** — an avatar that responds in real time
- **API** — generate videos automatically from code

## 🚀 Getting started

1. Sign up for an account at [heygen.com](https://www.heygen.com/)
2. Choose **Create Video** → pick an avatar and voice
3. Type the script (Thai/English), then click generate
4. Wait for it to render, then download/share the video
