# แผนบริการ Credits และการชำระเงิน

Suno มีระบบ **Credits** (เครดิต — หน่วยที่ใช้แลกสร้างเพลง คล้ายเหรียญในเกม) เพื่อควบคุมการใช้งาน AI ในแต่ละเดือน ยิ่งใช้แผนสูง ยิ่งได้เครดิตมาก = สร้างเพลงได้มากขึ้น

---

## แผนบริการทั้งหมด

### Free Plan (แผนฟรี)

| รายละเอียด | ค่า |
|-----------|-----|
| **ราคา** | $0 / เดือน |
| **Credits ต่อเดือน** | 50 credits |
| **เพลงที่สร้างได้** | ~10 เพลง (ได้ 2 เวอร์ชันต่อครั้ง) |
| **ความเป็นส่วนตัว** | เพลงจะเป็น Public (สาธารณะ) |
| **สิทธิ์การใช้งาน** | Non-commercial เท่านั้น |
| **ดาวน์โหลด** | ดาวน์โหลดได้ แต่ไม่มี WAV |

### Pro Plan (แผนโปร)

| รายละเอียด | ค่า |
|-----------|-----|
| **ราคา** | ~$8 / เดือน (รายปี) หรือ ~$10 / เดือน |
| **Credits ต่อเดือน** | 2,500 credits |
| **เพลงที่สร้างได้** | ~500 เพลง |
| **ความเป็นส่วนตัว** | ตั้ง Private ได้ |
| **สิทธิ์การใช้งาน** | Commercial use (ใช้ในเชิงพาณิชย์ได้) |
| **ดาวน์โหลด** | MP3 + MP4 (วิดีโอ) |
| **ฟีเจอร์พิเศษ** | Crop, Priority Generation (สร้างก่อน) |

### Premier Plan (แผนพรีเมียร์)

| รายละเอียด | ค่า |
|-----------|-----|
| **ราคา** | ~$24 / เดือน (รายปี) หรือ ~$30 / เดือน |
| **Credits ต่อเดือน** | 10,000 credits |
| **เพลงที่สร้างได้** | ~2,000 เพลง |
| **ความเป็นส่วนตัว** | ตั้ง Private ได้ |
| **สิทธิ์การใช้งาน** | Full Commercial use |
| **ดาวน์โหลด** | MP3 + MP4 + WAV (คุณภาพสูง) |
| **ฟีเจอร์พิเศษ** | Crop, Priority Generation, Studio Access, Stem Extraction |

## Credits คืออะไร?

**Credits** (เครดิต) คือหน่วยที่ใช้สร้างเพลงและฟีเจอร์ต่าง ๆ ใน Suno

### อัตราการใช้ Credits

| การกระทำ | Credits ที่ใช้ |
|---------|-------------|
| สร้างเพลงใหม่ (2 เวอร์ชัน) | 10 credits |
| Extend ครั้งละ | 5 credits |
| Remaster | 5 credits |
| Stem Extraction | 5–10 credits |
| Add Vocals | 5 credits |
| Upload Audio + Create | 10 credits |

### Credits Reset (รีเซ็ตเครดิต)

- **Free Plan:** ได้ Credits ใหม่ทุกวัน (วันละ 50 credits หมุนเวียน)

> **หมายเหตุ:** Credits ที่เหลือจากเดือนก่อนจะ **ไม่สะสมต่อ** (ไม่ Rollover — ไม่นำไปรวมเดือนหน้า)

### ตรวจสอบ Credits ที่เหลือ

1. คลิกที่ **Profile** หรือ **Settings**
2. ดูส่วน **"Credits"** หรือ **"Usage"**
3. จะแสดง Credits ที่เหลือและวันที่รีเซ็ต

---

## วิธีซื้อ Credits เพิ่ม

หากใช้ Credits หมดก่อนสิ้นเดือน สามารถซื้อเพิ่มได้:

1. ไปที่ **Settings > Billing** (การตั้งค่า > การชำระเงิน)
2. เลือก **"Buy More Credits"** (ซื้อ Credits เพิ่ม)
3. เลือกแพ็คเกจที่ต้องการ
4. ชำระเงิน

> Credits ที่ซื้อเพิ่มเหล่านี้จะ **ไม่หมดอายุ** และใช้ได้ต่อเนื่อง

## ช่องทางการชำระเงิน

Suno รองรับการชำระเงินผ่าน:

| ช่องทาง | รายละเอียด |
|--------|---------|
| **Credit/Debit Card** (บัตรเครดิต/เดบิต) | Visa, Mastercard, American Express |
| **PayPal** | บัญชี PayPal |
| **Apple Pay** | สำหรับผู้ใช้ iOS/Mac |
| **Google Pay** | สำหรับผู้ใช้ Android |

> **หมายเหตุ:** Suno ไม่รับ Bitcoin หรือ Cryptocurrency อื่น ๆ

### VAT (ภาษีมูลค่าเพิ่ม)

หากคุณอยู่ในประเทศที่มี VAT (เช่น ประเทศในสหภาพยุโรป หรือบางประเทศในเอเชีย) ราคาที่แสดงอาจยังไม่รวม VAT Suno จะเพิ่ม VAT ตามอัตราของประเทศคุณเมื่อชำระเงิน

## การจัดการ Subscription (สมาชิก)

### เปลี่ยนแผน

1. ไปที่ **Settings > Billing**
2. คลิก **"Change Plan"** (เปลี่ยนแผน)
3. เลือกแผนใหม่

### ยกเลิกสมาชิก

1. ไปที่ **Settings > Billing**
2. คลิก **"Cancel Subscription"** (ยกเลิกสมาชิก)
3. ยืนยันการยกเลิก

> **หลังยกเลิก:** คุณยังใช้งานได้จนถึงวันสิ้นสุดรอบเรียกเก็บเงิน Credits ที่เหลืออยู่สามารถใช้งานได้จนกว่าจะหมดรอบ

### ดูข้อมูลการชำระเงินหลังยกเลิก

หากยกเลิกแผนแล้วแต่ต้องการดูประวัติการชำระเงิน:
1. ไปที่ [suno.com](https://suno.com)
2. เข้าสู่ระบบด้วยอีเมลเดิม
3. ไปที่ **Settings > Billing History** (ประวัติการชำระเงิน)

## Refund Policy (นโยบายการคืนเงิน)

Suno มีนโยบายการคืนเงินที่จำกัด:

- **ไม่มีการคืนเงิน** สำหรับเดือนที่ใช้งานไปแล้ว
- **กรณีพิเศษ** เช่น ระบบมีปัญหาหรือคิดเงินซ้ำ ติดต่อ Support ได้
- **ทดลองก่อนซื้อ** — ใช้แผนฟรีก่อนตัดสินใจสมัคร Pro

## Free Plan vs Paid Plan เลือกอะไรดี?

### ใช้ Free Plan ถ้า:
- เพิ่งเริ่มต้นและต้องการทดลอง
- สร้างเพลงเป็นงานอดิเรกส่วนตัว
- ไม่ต้องการนำเพลงไปใช้ในเชิงพาณิชย์

### อัปเกรดเป็น Pro ถ้า:
- ต้องการสร้างเพลงมากกว่า 10 ต่อเดือน
- ต้องการนำเพลงไปใช้ใน YouTube, โฆษณา, หรือขาย
- ต้องการความเป็นส่วนตัว (Private Songs)

### อัปเกรดเป็น Premier ถ้า:
- ใช้งานระดับมืออาชีพหรือธุรกิจ
- ต้องการ WAV Files (ไฟล์คุณภาพสูง)
- ต้องการใช้ Studio และ Stem Extraction
- สร้างเพลงมากกว่า 500 เพลงต่อเดือน

## คำถามที่พบบ่อย

**Q: Credits หมดในเดือนนี้ ทำอย่างไร?**
A: ซื้อ Credits เพิ่มได้ หรือรอรีเซ็ตเดือนหน้า

**Q: ยกเลิกแล้ว เพลงที่สร้างไว้จะหายไปไหม?**
A: เพลงที่สร้างไว้จะยังอยู่ในบัญชี แต่อาจเข้าถึงฟีเจอร์บางอย่างไม่ได้

**Q: เปลี่ยนแผนกลางเดือนได้ไหม?**
A: ได้ Suno จะคำนวณส่วนต่างให้ตามสัดส่วน

**Q: ถ้าสมัคร Pro แล้วเพลงที่ทำในแผน Free จะได้สิทธิ์ Commercial ด้วยไหม?**
A: ไม่ — สิทธิ์ Commercial ใช้กับเพลงที่สร้างในช่วงที่สมาชิก Pro/Premier เท่านั้น
