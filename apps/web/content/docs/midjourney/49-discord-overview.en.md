## The Midjourney Server on Discord

When you join the Midjourney Discord Server, you'll see these room categories:

---

## Server structure

### INFO category
- **#announcements** — announcements of updates and important news
- **#status** — system status (whether there's a problem)
- **#rules** — the Server's rules

### NEWCOMER ROOMS category
- **#newbies-1** to **#newbies-N** — rooms for beginners
- You can use `/imagine` here
- See others' work in Real-time

### GENERAL category
- **#general** — a general chat room
- **#prompt-craft** — share Prompts and techniques

### DAILY category
- **#daily-theme** — the daily image theme
- Challenge yourself with the set theme

### IMAGE CREATION category
- **#imagine** — the main image-creation room
- Rooms for creating specific image types

---

## Direct Messages with the Midjourney Bot

If you want more privacy:
1. Find the **Midjourney Bot** in the Server
2. Click "Message" to send a DM
3. Use `/imagine` in the DM

**Note:** Even using DM, work still appears publicly, unless you have Stealth Mode (Pro+ plan).

---

## Add the Midjourney Bot to a private Server

More convenient than using the central Server, because:
- No others' work interrupting
- You can organize rooms by project
- You can invite colleagues in

How to add:
1. Go to the Midjourney Server → click the Midjourney Bot
2. Choose "Add to Server"
3. Choose your Server → Authorize

---

## Creation Settings in Discord

Type `/settings` to open the settings panel with buttons:

- Choose the Model Version
- Choose the Mode (Fast/Relax/Turbo)
- Enable/disable Remix Mode
- Set the default Quality and Stylize

---

## The difference between the central Discord Server and a private Server

| | Central Server | Private Server |
|--|------------|---------------|
| See others' work | ✅ a lot | ❌ only your team |
| Learn from the community | ✅ very good | ❌ less |
| Privacy | ❌ low | ✅ higher |
| Organize work | ❌ hard | ✅ can separate rooms |

---

## Summary

Midjourney on Discord has both a central Server full of community for learning, and the option to use DM or a private Server for privacy. Choose per your needs.
