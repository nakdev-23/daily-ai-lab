# Dubbing — automatically dub videos into other languages 🌐

> Adapted from the official documentation at [elevenlabs.io/docs](https://elevenlabs.io/docs), the Dubbing section

**Dubbing** converts the speech in a video/audio into **another language** while trying to keep the original tone and voice identity. Good for making content accessible to people who speak other languages.

## ⚙️ How it works (overview)

1. **Transcribe** the original audio into text
2. **Translate** the text into the target language
3. **Generate new speech** in that language with a tone close to the original
4. **Time it** to match the video

## 📖 Adjustable settings

| Setting | Description |
|---|---|
| **Source language** | The original language (can be set to auto-detect) |
| **Target language** | The language to dub into |
| **Number of speakers** | The number of speakers in the clip (helps separate voices) |

## 💡 Tips

- Clear original audio that separates speech from music/noise gives a better result
- For clips with several people speaking, specify the number of speakers correctly
- There's a **Dubbing Studio** for finely editing the translation/timing before export

## ▶️ Steps

1. Go to the **Dubbing** menu and upload a video/audio file (or paste a link)
2. Choose the source and target languages and the number of speakers
3. Hit generate and wait for processing
4. Review/edit in the Dubbing Studio (if you want), then download
