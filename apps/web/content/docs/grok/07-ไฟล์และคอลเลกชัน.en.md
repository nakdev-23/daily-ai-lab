# Files & Collections

> Reference: [Files Overview](https://docs.x.ai/developers/files) | [Managing Files](https://docs.x.ai/developers/files/managing-files) | [Chat with Files](https://docs.x.ai/developers/model-capabilities/files/chat-with-files) | [Collections](https://docs.x.ai/developers/files/collections)

---

## Overview

xAI divides file management into 2 parts:

| Part | What it is | Used when |
|---|---|---|
| **Files** | Files uploaded and attached to a chat | You want to analyze/read files in the conversation |
| **Collections** | A set of files for searching (RAG) | You want the AI to search data from many documents |

---

## Upload files on Grok.com (general users)

Reference: [FAQ - Files](https://docs.x.ai/grok/faq#files--data)

### How to upload

1. Open a conversation on Grok.com
2. Hit the **+** button next to the message box
3. Choose a file from your device (or drag and drop on the web)
4. Send the file with your message

**Files you can upload at once:**
- Web: up to ~100 files
- Android: up to 20 files
- iOS: supports several files

### Supported file types

**Documents:**
- PDF, DOCX, TXT, CSV, XLSX, PPTX
- HTML, XML, JSON, Markdown (.md)
- LaTeX (.tex, .latex), ODT, RTF

**Code:**
- .py, .cpp, .java, .html, .css, and others

**Images:**
- JPEG/JPG, PNG, WebP, HEIC, BMP
- GIF and SVG partially supported

**Audio:**
- MP3, WAV, M4A, OGG, FLAC, AAC

**Video:**
- MP4, MOV

### Maximum file size
- Documents/images/code/audio: up to **150 MB per file**

### What can Grok do with files?

- **Analyze** — read and understand content, analyze data
- **Summarize** — summarize long documents, reports
- **Extract** — pull tables, specific data, key quotes
- **Transform** — rewrite, change style, make an outline
- **Compare** — compare several files
- **Run code** — debug and test code

**Example prompts:**
```
"Summarize this PDF and extract the key data tables"
"What trends are in this CSV file?"
"Compare these two DOCX files and how they differ"
```

### Usage tips

- Use high-resolution images (≥1000×1000 pixels) for good analysis
- For PDFs longer than 100 pages, specify the pages you want
- Very large documents may need to be split into pieces

### Manage file space
Go to [grok.com/files](https://grok.com/files) to delete files and free up space.

## Files API (developers)

Reference: [Files Overview](https://docs.x.ai/developers/files) | [Managing Files](https://docs.x.ai/developers/files/managing-files)

### Upload a file via API

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_XAI_API_KEY",
    base_url="https://api.x.ai/v1",
)

# Upload a file
with open("report.pdf", "rb") as f:
    file_response = client.files.create(
        file=f,
        purpose="assistants",
    )

file_id = file_response.id
print(f"File ID: {file_id}")
```

### Use a file in Chat

```python
response = client.responses.create(
    model="grok-4.3",
    input=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Summarize this report"},
                {"type": "file", "file_id": file_id},
            ],
        }
    ],
    tools=[{"type": "attachment_search"}],  # enable File Search
)

print(response.output_text)
```

### Manage files

```python
# List files
files = client.files.list()
for f in files.data:
    print(f"{f.id}: {f.filename}")

# Delete a file
client.files.delete(file_id)
```

## Collections — a document store for RAG

Reference: [Collections](https://docs.x.ai/developers/files/collections)

### What are Collections?
A Collection is a group of files xAI indexes so Grok can search data from many documents accurately. This principle is called **RAG (Retrieval-Augmented Generation)**.

### What is it used for?
- An organization's knowledge base
- An FAQ the AI answers from documents
- An internal data-search system
- A chatbot that knows the company's documents

### Create a Collection

```python
# Create a new Collection
collection = client.beta.vector_stores.create(
    name="Company product manual"
)

collection_id = collection.id
print(f"Collection ID: {collection_id}")
```

### Add files to a Collection

```python
# Upload the file first
with open("product_manual.pdf", "rb") as f:
    file = client.files.create(file=f, purpose="assistants")

# Add it to the Collection
client.beta.vector_stores.files.create(
    vector_store_id=collection_id,
    file_id=file.id,
)
```

### Search in a Collection

```python
response = client.responses.create(
    model="grok-4.3",
    input=[{"role": "user", "content": "How do I reset the device?"}],
    tools=[
        {
            "type": "collections_search",
            "vector_store_ids": [collection_id],
        }
    ],
)

print(response.output_text)
```

### Collections via API

Reference: [Collections via API](https://docs.x.ai/developers/files/collections/api)

List all Collections:
```python
collections = client.beta.vector_stores.list()
for c in collections.data:
    print(f"{c.id}: {c.name} ({c.file_counts.completed} files)")
```

### Collection Metadata

Reference: [Collection Metadata](https://docs.x.ai/developers/files/collections/metadata)

You can add metadata to files in a Collection to filter search results:

```python
client.beta.vector_stores.files.create(
    vector_store_id=collection_id,
    file_id=file.id,
    attributes={
        "department": "HR",
        "year": "2025",
        "document_type": "policy",
    }
)

# Search only HR files
response = client.responses.create(
    model="grok-4.3",
    input=[{"role": "user", "content": "The company's vacation policy?"}],
    tools=[
        {
            "type": "collections_search",
            "vector_store_ids": [collection_id],
            "filters": {"department": "HR"},
        }
    ],
)
```

## Chat with Files

Reference: [Chat with Files](https://docs.x.ai/developers/model-capabilities/files/chat-with-files)

### What is this topic?
Chatting with files directly — send a file with a message and Grok reads it and answers questions about it.

### Difference from Collections Search

| | Chat with Files | Collections Search (RAG) |
|---|---|---|
| Number of files | A few files | Hundreds or thousands of files |
| Search method | Reads the whole file | Searches only the relevant parts |
| Accuracy | Good for few files | Good for a large document store |
| Cost | By tokens | $2.50/1,000 calls + tokens |
