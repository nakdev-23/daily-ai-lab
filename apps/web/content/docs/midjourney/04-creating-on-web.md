# การสร้างภาพบนเว็บไซต์

> อ้างอิงหลัก: [Creating on Web](https://docs.midjourney.com/hc/en-us/articles/33390732264589-Creating-on-Web)

---

## ขั้นตอนการสร้างภาพ

การสร้างภาพบนเว็บ Midjourney มีขั้นตอนที่ง่ายมาก:

### ขั้นที่ 1 — เข้าหน้า Create
1. ล็อกอินที่ [midjourney.com](https://midjourney.com)
2. คลิก **"Create"** ในเมนูด้านซ้าย
3. คุณจะเห็นช่องพิมพ์ Prompt ด้านบนสุด

### ขั้นที่ 2 — พิมพ์ Prompt
Prompt (คำสั่งที่พิมพ์ให้ AI สร้างภาพ — เหมือนการบอกว่าอยากได้รูปแบบไหน) คือหัวใจสำคัญ

**ตัวอย่าง Prompt ง่ายๆ:**
```
a golden retriever puppy playing in autumn leaves
```

**ตัวอย่าง Prompt ละเอียดขึ้น:**
```
a golden retriever puppy playing in autumn leaves, soft sunlight, bokeh background, professional photography
```

### ขั้นที่ 3 — ปรับการตั้งค่า (ตัวเลือก)
ก่อนกด Generate คุณสามารถปรับ:
- **Aspect Ratio** (สัดส่วนภาพ) — เลือกรูปแบบที่ต้องการ
- **Model** (โมเดล — รุ่น AI) — เลือกเวอร์ชันล่าสุดหรือเวอร์ชันเฉพาะ
- **Stylize** — ปรับระดับความสวยงามทางศิลปะ

### ขั้นที่ 4 — Generate และรอผล
- คลิก **"Generate"** หรือกด **Enter**
- รอประมาณ 30-60 วินาที
- ระบบจะสร้าง **4 ภาพพร้อมกัน** ให้เลือก

---

## ทำความเข้าใจผลลัพธ์

เมื่อสร้างเสร็จ คุณจะเห็นตาราง 2x2 ของภาพ 4 แบบ:

```
[ภาพที่ 1] [ภาพที่ 2]
[ภาพที่ 3] [ภาพที่ 4]
```

แต่ละภาพมีรายละเอียดแตกต่างกันเล็กน้อย คุณสามารถ:
- **คลิกขยาย** ภาพใดก็ได้เพื่อดูชัดขึ้น
- **Upscale** (ขยายคุณภาพ — เพิ่มความละเอียดของภาพ) ภาพที่ถูกใจ
- **Vary** (สร้างใหม่แบบปรับเล็กน้อย) ถ้าใกล้เคียงแต่ยังไม่พอใจ
- **Re-run** สร้างชุดภาพใหม่ทั้งหมดจาก Prompt เดิม

---

## ตัวเลือกหลังการสร้าง

### Upscale
- **Upscale (Subtle)** — ขยายคุณภาพเล็กน้อย รักษาสไตล์เดิม
- **Upscale (Creative)** — ขยายคุณภาพพร้อมเพิ่มรายละเอียดใหม่

### Vary
- **Vary (Subtle)** — ปรับเล็กน้อย โครงสร้างหลักเหมือนเดิม
- **Vary (Strong)** — ปรับมาก ได้ภาพแบบใหม่แต่ยังคงแนวคิดหลัก
- **Vary (Region)** — เลือกพื้นที่เฉพาะแล้วสร้างใหม่แค่ส่วนนั้น

### การแก้ไขภาพ
- **Edit** — เปิด Editor เต็มรูปแบบเพื่อแก้ไขภาพ
- **Zoom Out** — ขยายขอบเขตภาพออกไปรอบๆ
- **Pan** — เลื่อนภาพไปทิศทางต่างๆ (ขึ้น ลง ซ้าย ขวา)

---

## Image Prompts (การใช้ภาพเป็น Prompt)

คุณสามารถแนบภาพเพื่อใช้เป็นแรงบันดาลใจ:
1. คลิกไอคอน **รูปภาพ** ในช่อง Prompt
2. อัปโหลด (Upload — นำไฟล์ขึ้นสู่ระบบ) หรือวาง URL ของภาพ
3. Midjourney จะสร้างภาพใหม่โดยอ้างอิงสไตล์หรือเนื้อหาจากภาพที่ให้

---

## Draft Mode และ Conversational Mode

### Draft Mode (โหมดร่าง)
- สร้างภาพเร็วขึ้นและใช้ GPU Time (เวลาประมวลผล) น้อยกว่า
- ความละเอียดต่ำกว่าปกติ
- เหมาะสำหรับทดสอบ Prompt ก่อนสร้างจริง

### Conversational Mode (โหมดสนทนา)
- โต้ตอบกับ AI แบบการสนทนาธรรมชาติ
- บอกว่าต้องการปรับอะไร AI จะเข้าใจบริบทของการสนทนาก่อนหน้า
- เหมาะสำหรับการ Iterate (ปรับปรุงซ้ำๆ) จนได้ภาพที่ต้องการ

---

## ตั้งค่าก่อนสร้าง

### Aspect Ratio (สัดส่วนภาพ)
เลือกได้จากตัวเลือกสำเร็จรูป หรือกำหนดเอง:

| อัตราส่วน | การใช้งาน |
|----------|----------|
| 1:1 | โพสต์ Instagram สี่เหลี่ยมจัตุรัส |
| 16:9 | ภาพวางนอน วอลเปเปอร์คอม |
| 9:16 | ภาพแนวตั้ง Story มือถือ |
| 4:3 | ภาพทั่วไป |
| 3:2 | ขนาดภาพถ่ายมาตรฐาน |

### Model Version
- เลือกเวอร์ชันล่าสุด (แนะนำ) หรือเวอร์ชันเก่าหากต้องการสไตล์เฉพาะ

---

## เคล็ดลับการสร้างภาพ

1. **เริ่มจากง่ายแล้วเพิ่ม** — พิมพ์ Prompt สั้นๆ ก่อน ดูผล แล้วค่อยเพิ่มรายละเอียด
2. **ระบุสไตล์** — เช่น "oil painting", "watercolor", "photorealistic", "anime style"
3. **บอกบรรยากาศ** — เช่น "dramatic lighting", "soft light", "golden hour"
4. **ระบุมุมกล้อง** — เช่น "close-up", "aerial view", "eye level"
5. **ใช้ Re-run** — ถ้าไม่ถูกใจทุกภาพ ลอง Generate ใหม่จาก Prompt เดิม

---

## สรุป

การสร้างภาพบนเว็บ Midjourney ทำได้ง่ายมาก: เข้าหน้า Create → พิมพ์ Prompt → รอผล → เลือกหรือปรับแต่ง เริ่มจากง่ายๆ แล้วค่อยเรียนรู้พารามิเตอร์เพิ่มเติมตามความต้องการ
