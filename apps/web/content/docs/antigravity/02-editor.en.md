# Editor — Antigravity's coding space ⌨️

> Adapted from the official documentation at [antigravity.google](https://antigravity.google/)

The **Editor** is Antigravity's code-editing window, with a familiar VS Code look but an AI agent working right beside you.

## 🗂️ Key parts

| Part | What it does |
|---|---|
| **Code editor** | Write/edit files as usual (with syntax highlighting and extensions) |
| **Agent panel** | Give the AI tasks and watch it work |
| **Terminal** | Run commands (the agent can run tests/installs itself) |
| **Diff view** | See what the agent changed before accepting |

## 🤝 Working with the agent

- Type code yourself and have the agent help at intervals
- Or hand off a whole task to the agent, then you review
- Every change can be viewed as a diff — accept/reject point by point

## ▶️ Getting started

1. Open your project folder
2. Write code, or open the agent panel to give a task
3. Review the diff the agent proposes, then Accept

## 💡 Tips

- If you're coming from VS Code, you'll adapt quickly
- Type small things yourself, hand big things to the agent, and focus on reviewing
