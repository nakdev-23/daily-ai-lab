# The art of writing Prompts

> Main reference: [Art of Prompting](https://docs.midjourney.com/hc/en-us/articles/32835253061645-Art-of-Prompting)

---

## The philosophy of the Prompt

Midjourney isn't a tool that wants only the "correct" command — it's an art of communicating with the AI effectively. The more you understand how Midjourney processes language, the more you can create images that match what you want.

### Key principles
- **Specificity** — clear details give a more accurate result
- **Simplicity** — it doesn't have to be very long; short and clear is enough
- **Iteration** (the process of experimenting and adjusting repeatedly until you get the result you want) — create repeatedly and adjust the Prompt until satisfied

---

## How to think about Prompts Visually

Instead of saying "what you want," try imagining "how this image was photographed or painted."

### Idea 1 — Think Like a Photographer
```
Questions: Where's the camera? Which direction is the light from? What lens?
Example: close-up macro shot, diffused natural light from left, shallow depth of field
```

### Idea 2 — Think Like a Director
```
Questions: What's the atmosphere? What mood do you want to convey?
Example: tense atmosphere, low key lighting, desaturated colors, noir aesthetic
```

### Idea 3 — Think Like an Art Director
```
Questions: Which style? Which era? Referencing which artist?
Example: art nouveau style, 1920s aesthetic, inspired by Alphonse Mucha
```

## Anatomy of a Master Prompt

```
[Type of image] of [Subject], [Environment/Background], [Lighting], [Style/Medium], [Mood/Atmosphere], [Technical details], [Quality modifiers]
```

**A full example:**
```
oil painting of an ancient samurai warrior standing on a misty mountain peak, 
dramatic stormy sky behind, golden hour side lighting, traditional Japanese art style 
blended with Western realism, contemplative melancholic mood, 
highly detailed armor with intricate engravings, masterpiece quality
```

---

## Powerful words in a Prompt

### Quality Boosters
These words help the image be more detailed and beautiful:
- `highly detailed`
- `masterpiece`
- `professional photography`
- `8k resolution`
- `award winning`
- `cinematic lighting`

### Style Anchors (words that clearly define the style)
- Artist names: `in the style of Van Gogh`, `inspired by Hayao Miyazaki`
- Magazines: `National Geographic photography`, `Vogue editorial`
- Eras: `Renaissance painting`, `80s retro`, `futuristic 2200s`
- Materials: `oil on canvas`, `pencil sketch`, `digital art`

## Iteration strategy

### Step 1 — Start from the core
```
a lighthouse at night
```

### Step 2 — Add the environment
```
a lighthouse at night, rocky coastline, stormy sea
```

### Step 3 — Add atmosphere and lighting
```
a lighthouse at night, rocky coastline, stormy sea, dramatic lightning in the sky
```

### Step 4 — Add the style
```
a lighthouse at night, rocky coastline, stormy sea, dramatic lightning, oil painting style, dramatic composition
```

### Step 5 — Add specific detail
```
a lighthouse at night, rocky coastline, churning stormy sea, dramatic lightning illuminating dark clouds, 
thick oil painting, impasto technique, reminiscent of J.M.W. Turner, masterpiece
```

## Troubleshooting when results don't match

### Problem: the image looks too plain
**Fix:** add Mood and Quality modifiers
```
Before: a forest
Adjusted: an enchanted ancient forest, magical atmosphere, golden light filtering through leaves, ethereal, breathtaking
```

### Problem: the image has unwanted things
**Fix:** use the `--no` Parameter to specify what you don't want
```
a beach scene --no people, umbrellas, buildings
```

### Problem: the proportions or Composition are bad
**Fix:** specify the Composition clearly
```
wide establishing shot, rule of thirds composition, subject on left third
```

### Problem: the colors don't match what you want
**Fix:** specify the color Palette
```
warm earth tones color palette: terracotta, amber, deep brown
cool blue and purple color scheme
```

## The difference between a good and a bad Prompt

| ❌ A weak Prompt | ✅ A strong Prompt |
|---------------------|----------------------|
| `a nice picture` | `a serene Japanese zen garden, cherry blossom tree, stone lantern, raked gravel` |
| `draw a cat` | `portrait of a regal persian cat, emerald eyes, soft studio lighting, oil painting` |
| `futuristic city` | `sprawling cyberpunk metropolis at night, neon reflections in rain-soaked streets, aerial view` |
| `beautiful woman` | `portrait of an elderly Thai woman, traditional silk dress, warm evening light, documentary photography` |

## Tips from experts

1. **Create a Prompt Template** — save Prompts that work well to reuse
2. **Test a Single Variable** — change one word at a time to learn its effect
3. **Use Permutations** — create several Variations at once using `{option1, option2}` in the Prompt
4. **Take notes** — keep Prompts that work well along with the results to build a personal Library

---

## Summary

Writing good Prompts is a skill that takes practice. There's no fixed formula, but the main principle is: **clear + detailed + specify the style**, then experiment repeatedly until satisfied. The more you create, the more you understand Midjourney's language.
