# Google Flow — an AI filmmaking tool 🎬

> Adapted from the official documentation at [labs.google/flow](https://labs.google/flow/about)

**Google Flow** is an AI video/short-film creation tool from Google Labs, powered by the **Veo** video model — just describe a scene in text and Flow creates a video clip, with tools to control camera angles, manage the scene's "ingredients," and string several shots into a continuous story.

## 📖 Terms worth knowing

| Term | In plain words |
|---|---|
| **Veo** | Google's AI video model behind Flow |
| **Text-to-video** | Create video from a text description |
| **Frames-to-video** | Provide start/end images and let the AI create the video connecting them |
| **Ingredients** | "Ingredients" like characters/objects/scenes reused for consistency |
| **Scenebuilder** | A tool to join several shots into a continuous story |
| **Camera controls** | Define the camera movement (pan, zoom, etc.) |

## ⭐ Highlights

- **Create video from text** with the power of Veo
- **Control angles and camera movement** like real directing
- **Ingredients** — keep characters/scenes looking the same across shots
- **Scenebuilder** — join shots into a long continuous story
- **Frames-to-video** — define the start/end frame yourself

## 🚀 Getting started

1. Go to [labs.google/flow](https://labs.google/flow) and log in with a Google account (depending on access/region availability)
2. Create a new project and describe the scene you want
3. Adjust the camera angles and Ingredients to taste
4. Use Scenebuilder to join several shots into a long clip, then export
