# Windsurf — an AI IDE that keeps you "in the flow" with Cascade 🏄

> Compiled in English from the official Windsurf/Cognition docs ([docs.windsurf.com](https://docs.windsurf.com/) — currently under Cognition/Devin)

**Windsurf** is an **AI code editor (AI IDE) built to keep you "in the flow of work"**. Originally developed by Codeium, it's now under **Cognition** (the same team as Devin). Its highlight is **Cascade** — an AI agent panel that chats, writes code, and runs code in one place, while understanding your codebase automatically.

---

## 📖 Terms worth knowing

| Term | Plain meaning |
|---|---|
| **Cascade** | The AI agent panel (on the right) that chats + writes code + runs code itself |
| **Tab / Autocomplete** | AI-powered code completion |
| **Command** | Instruct it in plain language via the command palette |
| **Context Awareness** | Windsurf understands your whole codebase to help on point |
| **MCP** | Connect external tools/data to the agent |
| **Memories & Rules** | Memory + rules that tune the AI's behavior to your project |

---

## ⭐ Main capabilities

- **Cascade — an agent that works on its own** chat to instruct it, and it writes/edits code across many files, runs commands, and works through fixes until done
- **Tab / Autocomplete** smart code completion as you type
- **Command** instruct it to edit/create code in plain language
- **Understands the codebase automatically (Context Awareness)** helps in context without lots of explaining
- **MCP** extend the agent's capabilities with external tools
- **Memories & Rules** tune the style/behavior to your team
- **Workflows & App Deploys** work as a set of steps and deploy apps

---

## 🚀 Getting started

1. Download Windsurf from [windsurf.com](https://windsurf.com/) (available for macOS / Windows / Linux)
2. Open your project folder (you can import from VS Code, including extensions/themes/keymaps)
3. Open **Cascade** (the right panel) and type instructions in plain language, e.g. "Add a login page with form validation"
4. Use **Tab** while typing to complete code, and set **Rules/Memories** so the AI follows your project's style
