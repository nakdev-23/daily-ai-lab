# Remix and Attribution

**Remix** (creating a new version of a song based on an existing one — changing the Style or adding new sections) is a social feature of Suno that lets the community create together.

---

## What is Remix?

In Suno, Remixing means taking another user's song (one with Remix permission enabled) and creating a new version. You can:

- Change the **Style** — e.g. change from Pop to Jazz
- Change the **Lyrics** — enter new lyrics
- Change the **Mood** — faster, slower, darker, brighter
- Experiment with other musical directions

---

## How to Remix

### Steps

1. Go to the song you want to Remix (it must be Public with Remix permission enabled)
2. Click the **"Remix"** or **"Use this sound"** button under the song
3. Suno loads the original song as the Base
4. Adjust the Style, Lyrics, or Options as you wish
5. Click **"Create"** to create the Remix

### What you can change in a Remix

| What you can change | How |
|----------------|-----|
| Style of Music | change the Genre, mood, instruments |
| Lyrics | enter new lyrics in place of the old |
| Vocal Style | change the singer's voice |
| Tempo | faster or slower than before |

## Attribution

**Attribution** (naming the original creator) is an important part of the Remix culture in Suno.

### Suno's Attribution system

When you Remix someone else's song:

- Your Remix song shows "Remix of [original song title] by [creator name]"
- The original creator receives a notification
- A link back to the original song appears under the Remix song

### Example

```
"Summer Vibes (Remix)" 
Remixed from "Summer Vibes" by @username_original
```

---

## Enabling/disabling Remix permission for your songs

You can control whether others can Remix your songs.

### How to set Remix Permission

1. Open the song you want to configure
2. Click **"..."** (three dots) and choose **"Settings"** or **"Edit"**
3. Find the **"Allow Remixes"** option
4. Toggle On or Off

### Default

- Most songs have **Remix permission enabled** by default
- You can disable it at any time

## Remix FAQ

**Q: Can I Remix a song commercially?**
A: No — even if you have the Pro plan, profiting from a Remix without permission from the original creator is something you shouldn't do.

**Q: Is a Remix considered my song?**
A: A Remix is your work, but it's linked to the original song — you don't have all the rights like a newly created song.

**Q: If someone Remixes my song, how will I know?**
A: Suno sends you a Notification, and your profile shows how many Remixes there are.

**Q: Can I Reuse Prompt with someone else's song?**
A: Yes — **Reuse Prompt** lets you take another song's Style Prompt to create a new song, but the result is an entirely new song, not a Remix.

---

## The difference between Remix and Reuse Prompt

| | **Remix** | **Reuse Prompt** |
|--|---------|----------------|
| **Base** | uses the original audio as the Base | uses only the Style Prompt |
| **Attribution** | required | not required |
| **Result** | sound similar to the original | an entirely new song |
| **Rights** | linked to the original | your own song |

## Personas and Remixing

**Personas** ("personalities" that capture the Vibe of a song) in Suno let you:

- Save the "voice style" from a song you like
- Use a Persona to create songs in the same style repeatedly
- Like a more flexible "Remix"

### How to create a Persona

1. Open the song whose Vibe you want to capture
2. Click **"Create Persona"** or in the Options menu
3. Name the Persona
4. Use that Persona when creating new songs

---

## Best practices for Remixing

1. **Always give credit** — even with the automatic system, you should mention the original in the song description
2. **Get permission for commercial use** — contact the creator before using a Remix for business
3. **Be creative, don't copy** — make your Remix different and add value
4. **Respect the Remix settings** — if a song has Remix permission disabled, respect that decision
