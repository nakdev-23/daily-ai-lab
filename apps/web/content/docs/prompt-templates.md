การเขียน **Prompt** ที่ดีคือกุญแจสำคัญที่ทำให้ AI ตอบได้ตรงใจ บทความนี้รวมเทมเพลตพร้อมใช้ที่คุณก็อปไปปรับใช้ได้ทันที

## โครงสร้าง Prompt ที่ดี

Prompt ที่ได้ผลมักประกอบด้วย 4 ส่วนนี้:

1. **บทบาท (Role)** — บอก AI ว่าให้สวมบทบาทเป็นใคร
2. **เป้าหมาย (Task)** — ต้องการให้ทำอะไร
3. **บริบท (Context)** — ข้อมูลเบื้องหลังที่จำเป็น
4. **รูปแบบผลลัพธ์ (Format)** — อยากได้คำตอบแบบไหน

> 💡 **เคล็ดลับ:** ยิ่งระบุชัดเจนเท่าไหร่ คำตอบยิ่งตรงใจเท่านั้น

## เทมเพลตที่ใช้บ่อย

### 1. เขียนอีเมล

```text
คุณคือผู้ช่วยเขียนอีเมลมืออาชีพ
ช่วยเขียนอีเมล[จุดประสงค์] ถึง[ผู้รับ]
โทน: [ทางการ/เป็นกันเอง]
ความยาว: [สั้น/ปานกลาง]
```

### 2. สรุปเนื้อหา

```text
สรุปข้อความต่อไปนี้เป็น 5 bullet points
โดยเน้นประเด็นที่นำไปใช้ได้จริง:

[วางเนื้อหาที่นี่]
```

## ตารางเปรียบเทียบโทนการเขียน

| โทน | เหมาะกับ | ตัวอย่างคำ |
|------|----------|------------|
| ทางการ | อีเมลธุรกิจ | เรียน, ด้วยความเคารพ |
| เป็นกันเอง | โซเชียล | สวัสดีจ้า, ฝากด้วยนะ |
| กระตือรือร้น | การตลาด | ห้ามพลาด!, พิเศษสุด |

## สรุป

- เริ่มจากโครงสร้าง 4 ส่วนเสมอ
- ระบุรูปแบบผลลัพธ์ให้ชัด
- ทดลองปรับแล้ววัดผล

พร้อมแล้วลองนำเทมเพลตไปปรับใช้กับงานของคุณได้เลย 🚀
