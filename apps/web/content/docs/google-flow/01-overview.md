# Google Flow — เครื่องมือทำหนังด้วย AI 🎬

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [labs.google/flow](https://labs.google/flow/about)

**Google Flow** คือเครื่องมือสร้างวิดีโอ/หนังสั้นด้วย AI จาก Google Labs ขับเคลื่อนด้วยโมเดลวิดีโอ **Veo** — แค่บรรยายฉากเป็นข้อความ Flow ก็สร้างคลิปวิดีโอให้ พร้อมเครื่องมือคุมมุมกล้อง จัดการ "ส่วนผสม" ของฉาก และร้อยหลายช็อตเป็นเรื่องราวต่อเนื่อง

## 📖 คำศัพท์ที่ควรรู้

| คำศัพท์ | ความหมายง่าย ๆ |
|---|---|
| **Veo** | โมเดล AI สร้างวิดีโอของ Google ที่อยู่เบื้องหลัง Flow |
| **Text-to-video** | สร้างวิดีโอจากคำบรรยายข้อความ |
| **Frames-to-video** | ใส่ภาพเริ่ม/จบ แล้วให้ AI สร้างวิดีโอเชื่อมให้ |
| **Ingredients** | "ส่วนผสม" เช่น ตัวละคร/วัตถุ/ฉาก ที่นำกลับมาใช้ซ้ำให้คงเส้นคงวา |
| **Scenebuilder** | ตัวต่อฉากหลายช็อตให้เป็นเรื่องราวต่อเนื่อง |
| **Camera controls** | กำหนดการเคลื่อนกล้อง (แพน ซูม ฯลฯ) |

## ⭐ จุดเด่น

- **สร้างวิดีโอจากข้อความ** ด้วยพลังของ Veo
- **คุมมุมและการเคลื่อนกล้อง** ได้เหมือนกำกับจริง
- **Ingredients** — รักษาให้ตัวละคร/ฉากหน้าตาเหมือนเดิมในทุกช็อต
- **Scenebuilder** — ต่อช็อตเป็นเรื่องราวยาวต่อเนื่อง
- **Frames-to-video** — กำหนดเฟรมเริ่ม/จบเองได้

## 🚀 เริ่มต้นใช้งาน

1. เข้า [labs.google/flow](https://labs.google/flow) แล้วล็อกอินด้วยบัญชี Google (ขึ้นกับสิทธิ์/ภูมิภาคที่เปิดให้ใช้)
2. สร้างโปรเจกต์ใหม่ แล้วพิมพ์บรรยายฉากที่อยากได้
3. ปรับมุมกล้องและ Ingredients ให้ตรงใจ
4. ใช้ Scenebuilder ต่อหลายช็อตเป็นคลิปยาว แล้วส่งออก
