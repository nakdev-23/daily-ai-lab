# Getting started with Runway

> Compiled from the [Runway Help Center](https://help.runwayml.com/) for beginners who want to use Runway to create videos with AI

---

## What is Runway?

**Runway** is an AI platform for creating and editing videos, images, and other media using Artificial Intelligence, usable without any prior video-editing knowledge.

Runway has several main tools, e.g.:

- **Gen-4 / Gen-4.5** (the latest video-generation models — very powerful and realistic)
- **Act-Two** (an AI system for character motion performance)
- **Image-to-Video** (turn a still image into a video)
- **Video-to-Video** (edit or change the style of an existing video)
- **Motion Brush** (a motion-control brush — paint on the part you want to move)

---

## Why use Runway?

| Benefit | Detail |
|---|---|
| No software to download | Works right in a web browser |
| Easy to use | Type a description and the AI creates the video |
| Many tools | From creating videos to removing backgrounds to adding audio |
| Professional-grade | Used in film, advertising, and by content creators |

## How to sign up for Runway

### Step 1: Go to the website

Go to [runwayml.com](https://runwayml.com) and click **"Get Started for Free"**

### Step 2: Create an account

You can sign up with:
- A **Google Account**
- **Email** and create your own password

### Step 3: Choose a plan

Runway has these plans:
- **Free** — get a certain number of Credits (a unit used to create videos) per month
- **Standard / Pro / Unlimited** (paid plans) — more Credits and additional unlocked features

> **Tip:** If you're just starting, use the Free Plan first to try out the various tools.

### Step 4: Enter the Workspace

After logging in, you enter the **Workspace** (Runway's main page) which shows all the available tools.

---

## Get to know the Workspace

Runway's **Workspace** consists of:

### The main Navigation Bar
- **Home** — the main page, view recent works and recommended tools
- **Assets** (media assets — uploaded image and video files) — manage your files
- **Projects** (created works) — organize work into projects
- **Tools** — the list of all AI Tools

### Dashboard (an overview page)
Shows key info, e.g.:
- Credits remaining
- Recently created works
- Frequently used tools

---

## What are Credits?

**Credits** (a resource unit for creating media) are the units used for creating videos and images in Runway.

- Creating 1 video clip uses different Credits depending on the model and length
- Credits are deducted every time you click Generate
- If your Credits run out, you must buy more or upgrade your plan

### Examples of Credit usage:
| Task | Credits used (approximate) |
|---|---|
| Create a 5-second video (Gen-4.5) | 60 credits |
| Create an image (Gen4 Image) | 5-8 credits |
| Text-to-Speech (turn text into speech) | 1 credit per 50 characters |

---

## First steps to do after signing up

1. **Try Text-to-Video** — type a description of the video you want and see what the AI creates
2. **Upload an image** — try Image-to-Video to make your photo move
3. **Look at Templates** (examples of ready-made works) — for inspiration
4. **Check Credits** — see how many you have before starting real work

---

## Tips for beginners

- Start with a short description, then gradually add detail
- If the result isn't right, try changing the description (Prompt) and Generate again
- Look at others' work in the Community to learn techniques
- Save the works you like in Projects to stay organized
