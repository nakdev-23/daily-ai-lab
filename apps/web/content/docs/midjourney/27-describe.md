# Describe — วิเคราะห์ภาพเป็น Prompt

> อ้างอิงหลัก: [Describe](https://docs.midjourney.com/hc/en-us/articles/32497889043981-Describe)

---

## Describe คืออะไร

คำสั่ง `/describe` (วิเคราะห์ภาพ — ฟีเจอร์ที่ให้ Midjourney ดูภาพแล้วสร้าง Prompt ที่คาดว่าจะสร้างภาพนั้น ทำงานตรงข้ามกับ /imagine) ช่วยให้คุณ "ย้อนกลับ" จากภาพไปสู่ Prompt

---

## วิธีใช้

### บน Discord
```
/describe [อัปโหลดภาพ]
```

1. พิมพ์ `/describe`
2. อัปโหลดภาพที่ต้องการ
3. Midjourney จะส่งกลับมา 4 Prompt ที่แตกต่างกัน
4. คลิก 1, 2, 3, หรือ 4 เพื่อสร้างภาพจาก Prompt นั้น

### บนเว็บไซต์
1. ไปที่หน้า Create
2. คลิกไอคอน Describe (หรือดูในเมนูเครื่องมือ)
3. อัปโหลดภาพ

---

## ประโยชน์ของ Describe

### 1. เรียนรู้การเขียน Prompt
- หาภาพที่ชอบจาก Internet
- ใช้ `/describe` เพื่อดูว่า Prompt แบบไหนสร้างภาพนั้น
- เรียนรู้คำศัพท์และรูปแบบ

### 2. สร้างภาพในสไตล์เดิม
- มีภาพที่ชอบแต่ไม่รู้ว่าใช้ Prompt อะไร
- ใช้ `/describe` เพื่อหา Prompt ที่ใกล้เคียง
- นำ Prompt ไปปรับและสร้างภาพใหม่

### 3. วิเคราะห์สไตล์ศิลปิน
- นำภาพของศิลปินที่ชอบมาวิเคราะห์
- ดูว่า Midjourney อธิบายสไตล์นั้นอย่างไร
- ใช้คำอธิบายเหล่านั้นใน Prompt ของคุณ

---

## ตัวอย่าง

**ภาพอินพุต:** ภาพถ่ายป่าในฤดูใบไม้ร่วงที่สวยงาม

**Prompts ที่ Midjourney สร้างกลับมา:**
1. *"autumn forest path, golden leaves carpeting the ground, misty morning light filtering through ancient trees, serene and atmospheric, nature photography"*
2. *"fall foliage in old-growth forest, dappled sunlight through canopy, warm orange and yellow tones, wide angle landscape, photorealistic"*
3. *"peaceful woodland trail in October, fallen maple leaves, soft bokeh background, golden hour, canon 5d photography"*
4. *"enchanted forest in autumn, mystical light rays, red and amber leaves, impressionist painting style"*

---

## ข้อสังเกต

- Prompt ที่ Midjourney สร้างกลับมาอาจไม่ได้ภาพเหมือนต้นแบบ 100%
- แต่ให้ Vocabulary (คลังคำ — ชุดคำศัพท์ที่ใช้ในการเขียน Prompt) ที่ดีมาก
- เหมาะสำหรับ Inspire (สร้างแรงบันดาลใจ) มากกว่าการ Copy

---

## เคล็ดลับ

1. **ลองทุก Prompt** — กด 1-4 เพื่อดูว่า Prompt ไหนให้ผลใกล้เคียงที่สุด
2. **ปรับแก้ Prompt** — นำ Prompt ที่ได้มาแก้ให้ตรงกับความต้องการ
3. **ผสม Prompt** — เอาส่วนดีจากหลาย Prompt มารวมกัน

---

## สรุป

`/describe` เป็นเครื่องมือเรียนรู้ที่ดีเยี่ยม ช่วยให้คุณเข้าใจว่า Midjourney มองภาพอย่างไร และ Vocabulary แบบไหนที่ได้ผลดี ใช้บ่อยๆ เพื่อพัฒนาทักษะการเขียน Prompt ของคุณ
