# Hugging Face Hub — the central hub for everything 🏛️

> Compiled in English from the official docs at [huggingface.co/docs/hub](https://huggingface.co/docs/hub)

The **Hub** is the heart of Hugging Face — the place where everyone shares and searches for 3 main things.

## 🗂️ Three main things on the Hub

| Type | What it is |
|---|---|
| **Models** | Pre-trained AI models, ready to use |
| **Datasets** | Datasets for training/testing |
| **Spaces** | AI demo apps that run in the browser instantly |

## 🔍 Searching for models

- Filter by **task** (e.g. text generation, image classification, speech)
- Filter by language, size, license
- Read the **Model Card** — the page describing the model (how to use it, limitations, examples)

## 📦 A Git-based Repository

Every model/dataset is a Git repository — with version history, downloadable, uploadable. It supports large files with Git LFS.

## ▶️ Getting started

1. Sign up for an account at [huggingface.co](https://huggingface.co/)
2. Search for a model in the **Models** tab, selecting by the task you want
3. Read the Model Card, then click "Use this model" to see how to call it
