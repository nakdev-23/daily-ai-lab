# เริ่มต้นใช้งาน Jules 🤖

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [jules.google](https://jules.google/docs)

## 🔗 ขั้นตอนเริ่มต้น

1. เข้า [jules.google](https://jules.google/) แล้วล็อกอินด้วยบัญชี Google
2. **เชื่อมต่อ GitHub** — อนุญาตให้ Jules เข้าถึง repository ที่ต้องการ
3. เลือก repo และ branch ที่จะให้ทำงาน
4. มอบหมายงานแรกเป็นภาษาคน

## 🐙 การเชื่อม GitHub

Jules ทำงานผ่าน GitHub เป็นหลัก:
- เลือกได้ว่าจะให้เข้าถึง repo ไหนบ้าง (เลือกเฉพาะที่ต้องการได้)
- Jules จะ clone โค้ดไปทำงานในเครื่องเสมือนของมันเอง
- ผลงานออกมาเป็น **Pull Request** ให้คุณรีวิว

## ✍️ มอบหมายงานแรก

เขียนงานให้ชัดเจน เช่น:
> "แก้บั๊กที่ปุ่ม submit ในหน้า contact ไม่ทำงาน และเพิ่มการตรวจสอบอีเมล"

Jules จะ:
1. **วางแผน** ขั้นตอนการแก้
2. ขอให้คุณยืนยันแผน (ถ้าตั้งไว้)
3. ลงมือแก้ + รันเทสต์
4. เปิด PR

## 💡 เคล็ดลับ

- งานที่ขอบเขตชัดเจน Jules ทำได้ดีกว่างานกว้าง ๆ
- ใส่บริบท (ไฟล์ที่เกี่ยว, เกณฑ์ความสำเร็จ) ช่วยให้ผลตรงขึ้น
