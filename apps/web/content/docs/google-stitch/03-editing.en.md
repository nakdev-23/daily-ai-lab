# Edit designs with words ✏️

> Adapted from the official documentation at [stitch.withgoogle.com](https://stitch.withgoogle.com/)

After Stitch creates a screen, you can **edit it by telling it in plain language** — no drag-and-drop yourself.

## 🗣️ Example edit commands

- "Change the primary button color to green"
- "Make the heading bigger and bolder"
- "Add a search bar at the top"
- "Move the menu to the bottom"
- "Make it more minimal, with more spacing"

Stitch adjusts the screen as you say and you see the result instantly.

## 🗂️ Multiple Screens

A real app has many screens — you can create several **Screens**, e.g. login, home, profile, to assemble the whole app flow.

## 💡 Tips

- Edit one thing clearly at a time for better control than commanding several at once
- If the result is off, try describing it more specifically (state size, color, position)
- Save a version you like before trying a big change
