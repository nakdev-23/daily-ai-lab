# Cascade — Windsurf's AI agent 🌊

> Compiled in English from the official docs at [windsurf.com/docs](https://docs.windsurf.com/), the Cascade section

**Cascade** is the agent-style AI assistant at the heart of Windsurf — not just a chat that answers questions, but one that **understands the whole project** and edits files, runs commands, and works through multi-step tasks to completion.

## 📖 Terms worth knowing

| Term | Plain meaning |
|---|---|
| **Agent** | An AI that does multi-step work on its own, not just answering one message at a time |
| **Context** | The surrounding info the AI uses to decide (open files, project structure) |
| **Write mode** | The mode where Cascade actually edits files |
| **Chat mode** | The Q&A mode without editing files |
| **Flows** | Continuous work where Cascade combines code edits + commands |

## ⭐ What it can do

- **Understands the whole codebase** — finds and references relevant files itself
- **Edits multiple files at once** from a single instruction
- **Runs commands in the terminal** for you (e.g. install packages, run tests)
- **Works continuously** — knows what it did earlier
- Choose between **Write mode** (actually edits) and **Chat mode** (just talks)

## ▶️ How to use it

1. Open the Cascade panel (on the right)
2. Type instructions in plain language, e.g. "Add a user profile page with an edit button"
3. Cascade proposes a plan + changes — click **Accept** or **Reject** per item
4. Have it run further commands, e.g. "Run the tests for me"

> 💡 The clearer you describe the goal and point to the relevant files/functions, the more on-target Cascade is
