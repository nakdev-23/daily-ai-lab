# Web vs Discord — which channel to use

> Main reference: [Midjourney Web vs Discord](https://docs.midjourney.com/hc/en-us/articles/33329300781837-Web-vs-Discord)

---

## Overview

Midjourney lets you create images through 2 main channels:
1. **The website** (midjourney.com) — an easy-to-use graphical Interface
2. **Discord** — an online chat app using typed commands

Both channels connect to the same account; images created from either channel appear in your full gallery.

---

## The website (midjourney.com)

### Strengths
- **Easy to use** — has buttons and menus to click, no need to memorize commands
- **Convenient viewing** — displays as a Gallery (showing images arranged beautifully)
- **Good work management** — has a Folder system to categorize images
- **Built-in Editor** — edit images directly on the web
- **Draft Mode** — a draft image-creation mode that uses fewer resources
- **Conversational Mode** — a mode for chatting with the AI to interactively adjust images

### Limitations
- Requires a modern browser
- Some features may not be as complete as Discord in older versions

### Good for
- Beginners unfamiliar with typing commands
- Those who want an organized Workflow
- Professional work requiring management of many files

---

## Discord

### Strengths
- **A big community** — see others' work in Real-time
- **Learn fast** — see the Prompts of work you like and adapt them
- **Flexible command typing** — use Parameters (special commands — extra options that control the result) fully
- **Direct Messages** — create images in a private room

### Limitations
- You must install the Discord app first
- You must memorize commands like `/imagine` to create images
- The Interface isn't designed specifically for image creation
- Work created in a public server is seen by everyone (unless you use Stealth Mode)

### Good for
- Those who already use Discord
- Those who like learning from the community
- Those who want to use advanced commands fully

## Comparison table

| Property | Website | Discord |
|----------|---------|---------|
| Ease of use | very easy | moderate |
| Built-in Editor | ✅ yes | ❌ no |
| Folder management | ✅ yes | ❌ no |
| View community work | partial | ✅ full |
| Conversational Mode | ✅ yes | ❌ no |
| Advanced Parameters | ✅ yes | ✅ yes |
| Must install an app | ❌ no | ✅ yes |
| Privacy | ✅ better | needs extra setup |

---

## Recommendations for choosing

### Use the website if...
- You're a beginner just starting
- You want a clear and organized Workflow
- You want to edit images after creating
- You create images for real work and need to manage files

### Use Discord if...
- You have a Discord account and already use it
- You want to learn from the creative community
- You like seeing others' work for inspiration
- You want Power User usage

---

## Tips

> **Recommendation:** Beginners should start with the website first, because it's much easier. Once familiar, try Discord to explore the community and learn new techniques.

Your account links both channels, so you can switch back and forth as you wish without losing any work.
