# Create video — from script to finished clip 🎞️

> Compiled in English from the official docs at [docs.heygen.com](https://docs.heygen.com/), the Create Video section

## 🧩 Components of a video

| Part | Description |
|---|---|
| **Avatar** | The character that speaks |
| **Voice** | The speaking voice (choose language/tone, or use a cloned voice) |
| **Script** | The lines the avatar will speak |
| **Scene** | One segment (you can switch scenes/backgrounds/text) |
| **Template** | A ready-made template with a layout provided |

## ▶️ Steps to create

1. Click **Create Video** and choose to start from a **Template** or a blank page
2. Choose an **Avatar** and **Voice** (you can set Thai)
3. Type the **Script** into each scene
4. Adjust the background, add text/images/logos as desired
5. Click **Submit/Generate** to render, then download

## 💡 Tips for a good-looking result

- Write the script in short, concise, smooth-reading sentences
- Add punctuation to help the speaking rhythm
- Split long content into multiple scenes so it's not boring
- Use a template as a starting point for faster, nicer results

## 🔁 Easy to repeat

If you want to make several clips with the same look (e.g. a tutorial series), save it as your own template and just change the script in each episode.
