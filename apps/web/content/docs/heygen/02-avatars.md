# AI Avatars — เลือกหรือสร้างอวตารของคุณ 🧑‍🎤

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [docs.heygen.com](https://docs.heygen.com/) หมวด Avatars

อวตารคือ "นักแสดง AI" ที่พูดบทให้คุณ HeyGen มีให้ทั้งแบบสำเร็จรูปและแบบสร้างเอง

## 🗂️ ประเภทอวตาร

| ประเภท | คืออะไร |
|---|---|
| **Stock Avatars** | อวตารสำเร็จรูปนับร้อย พร้อมใช้ทันที |
| **Instant Avatar** | อวตารของคุณเอง สร้างจากการอัดวิดีโอสั้น ๆ |
| **Photo Avatar** | อวตารจากรูปภาพ (รวมภาพที่สร้างด้วย AI) |
| **Studio Avatar** | อวตารคุณภาพสูง อัดในสตูดิโอ (สำหรับงานองค์กร) |

## 🎥 สร้าง Instant Avatar (ภาพรวม)

1. ไปที่ **Avatars → Create → Instant Avatar**
2. อัดวิดีโอตัวเองตามคำแนะนำ (มองกล้อง แสงดี พูดตามสคริปต์ที่ให้)
3. **ยืนยันความยินยอม** ว่าเป็นตัวคุณเอง
4. รอระบบประมวลผล แล้วนำอวตารไปใช้พูดบทใดก็ได้

## 🖼️ Photo Avatar

- อัปโหลดรูปคน (หรือใช้ภาพที่สร้างด้วย AI) แล้วทำให้พูด/ขยับได้
- เหมาะกับสร้างพรีเซนเตอร์เฉพาะตัวโดยไม่ต้องถ่ายวิดีโอ

## ⚠️ เรื่องความยินยอม

การสร้างอวตารจากใบหน้า/เสียงคนจริง ต้องเป็น **ตัวคุณเอง** หรือได้รับ **อนุญาต** — HeyGen มีระบบยืนยันตัวตนเพื่อกันการปลอมแปลง (deepfake) คนอื่น
