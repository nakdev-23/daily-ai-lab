# Canvas — a workspace for working with AI

> Primary reference: [OpenAI Help Center — ChatGPT](https://help.openai.com/en/collections/3742473-chatgpt)

---

## What is Canvas

**Canvas** is a new workspace (a screen area for creating and editing content) that opens alongside the regular conversation window. Instead of the answer showing in an ordinary chat bubble, Canvas opens a separate document on the right, where you can edit, polish, and develop content with the AI continuously.

Canvas is "ChatGPT's biggest interface (the program's look and operation) update in two years" — designed for work that needs many rounds of editing, such as writing long articles, developing code (instructions written to make a computer work), or detailed creative work.

---

## How to access Canvas

### Opens automatically
ChatGPT opens Canvas automatically when the system detects the task suits Canvas, e.g.:
- Asking it to write an article, report, or long document
- Asking it to write code for a large project
- Asking it to edit or review (check and comment on) content

### Open it yourself
1. Click the **"View tools"** or **"+"** icon in the message box
2. Choose **Canvas** from the menu
3. Or type in the chat *"open a Canvas for this task"* or *"write it as a document"*

> **Note**: Canvas works only with **GPT-4o** and newer models (the trained AI program).

---

## Writing features

### Main tools in the Canvas panel

**Suggest Edits**
The AI reads the whole document and shows inline comments (comments shown right at the relevant text, not separated elsewhere) with improvement suggestions, e.g. word changes, sentence restructuring, or added clarity.

**Adjust Length**
There's a slider (a bar you drag to adjust a value) to change the document's length:
- Shorten (cut unnecessary parts)
- Expand (add details, examples, or context)

**Reading Level**
Adjust the language level of the content from:
- Child level (easy to understand, short sentences)
- High school / university level
- Expert / graduate level

**Final Polish**
The AI checks and fixes:
- Grammar and spelling
- Sentence flow
- Consistency of tone and writing style

**Add Emojis**
Add appropriate emoji throughout the document, good for social media content or articles that want a fun feel.

### Inline editing (editing at the spot — editing right in the content without opening a new window)
- **Highlight** any text and type a command, e.g. "make this more concise" or "change the tone to formal"
- The AI edits only the selected part, not the rest

---

## Coding features

### Tools in Code mode

**Code Review (checking code quality)**
The AI reads all the code and shows yellow inline comments with suggestions, e.g. performance, security, or code-style issues.

**Add Logs**
Adds `console.log()`, `print()`, or logging statements (commands that record data while the program runs, to check what's happening) automatically to help debug (find and fix errors in the code).

**Add Comments**
Adds inline comments explaining how the code works, good for documentation or handing off to a team.

**Fix Bugs (fixing errors in the program)**
The AI finds and fixes bugs in the code automatically, explaining what it fixed and why.

**Port to Language**
Convert code between languages:
- JavaScript ↔ TypeScript ↔ Python
- Java ↔ C++ ↔ PHP
- and many more

### Inline code editing
Select the line or function (a set of instructions that work together to do one thing) you want and type a command, e.g. "add error handling (handling errors — coping with cases where the program goes wrong)" or "make it async (asynchronous — doing several things at once, without waiting one at a time)".

## Version History

Canvas has built-in version control (tracking changes and letting you roll back):
- Every time the AI edits the document, the system saves a new version (a copy of the document at one point in time)
- You can **roll back** to a previous version anytime
- A **visual diff** (a comparison showing the differences in color): deleted text shows in red, new text shows in green
- Hit **Undo/Redo** just like Google Docs

## Comparison: regular Chat vs Canvas

| | Regular Chat | Canvas |
|---|---|---|
| **Good for** | Q&A, finding info, short tasks | Writing documents, project code, work needing repeated edits |
| **Editing** | Must retype everything | Edit specific parts inline |
| **History** | Scroll to find in the chat | A clearly separate version history |
| **Tools** | None | A task-specific toolbar |
| **Copying** | Copy from the chat | Copy with one button |

## Tips for using Canvas effectively

1. **Start from an outline**: have the AI write an outline (the main and sub-headings before the details) first, then expand each section
2. **Highlight before commanding**: don't command an edit on the whole document; select the part you want first for a more on-target result
3. **Use Adjust Length**: if the content is too short or too long, adjust the slider instead of rewriting
4. **Note versions often**: before trying something new, note the current version so you can roll back
5. **Mix with Chat**: use Canvas for the main output (the result of the work), and use Chat to ask follow-up questions or ask for explanations
