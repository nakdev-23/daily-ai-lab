# Bolt — build a complete web app in the browser ⚡

> Adapted from the official documentation at [support.bolt.new](https://support.bolt.new/) (by StackBlitz)

**Bolt** (bolt.new) is an AI web-app builder from StackBlitz that **runs everything in the browser** — writing code, installing packages, running the server, and live preview — with no setup on your machine. You describe in text what app you want and Bolt builds a full project, then deploys it online in one click.

## 📖 Terms worth knowing

| Term | In plain words |
|---|---|
| **WebContainer** | The technology that runs Node.js in the browser (the heart of Bolt) |
| **Prompt** | The text instruction that tells the AI to build/edit the app |
| **Tokens** | The unit of AI usage, deducted by the amount of work |
| **Deploy** | Publish the app online (via Netlify) |
| **Integrations** | Services you can connect, e.g. Supabase, Figma, Expo |

## ⭐ Highlights

- **Runs purely in the browser** — nothing to install on your machine
- **Full stack** — frontend + backend + real execution in one place
- **Easy to deploy** — publish via Netlify instantly
- **Connect external services** — Supabase (database), Figma, Expo (mobile)
- **Sync with GitHub** to store code and keep working

## 🚀 Getting started

1. Go to [bolt.new](https://bolt.new/) and sign up / log in
2. Describe the app you want, e.g. "a to-do list site that saves tasks"
3. Watch Bolt write the code and run a live preview, then type to adjust
4. Hit **Deploy** to go online, or connect Supabase if you need to store data

> 💡 Token-saving tip: give clear, chunked instructions, and use targeted edits when tweaking small details.
