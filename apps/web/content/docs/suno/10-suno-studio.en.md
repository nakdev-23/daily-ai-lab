# Suno Studio — a DAW for professionals

**Suno Studio** is a **Generative Audio Workstation** (an AI-driven audio work tool — like a DAW but powered by AI), a special feature only for **Premier** plan users.

Studio lets you control every part of a song at a more detailed level than normal song creation — Mix, Record, Edit, and Export.

---

## What is Studio?

Suno Studio launched in 2025, blending Generative AI with a traditional DAW (Digital Audio Workstation — digital music-making software) Workflow, letting you:

- **Record** — record your own audio onto the Timeline
- **Mix** — adjust the volume and balance of each Track
- **Edit** — cut, move, and manage audio Regions
- **EQ** — adjust the audio frequencies in each Track
- **Export** — export in various formats

## The Timeline in Studio

The **Timeline** (the horizontal bar showing the song in time order) is the central axis of Studio.

### Elements of the Timeline

```
┌─────────────────────────────────────────────┐
│ Track 1: Vocals      ███████░░░░░░░░░░░░░░  │
│ Track 2: Guitar      ░░░░░░░███████░░░░░░░  │
│ Track 3: Drums       ████████████████████  │
│ Track 4: Bass        ████████████████████  │
└─────────────────────────────────────────────┘
         0:00          0:30          1:00
```

- **Track** — each row is one type of sound
- **Region** (a block of sound on the Timeline) — each colored block on the Timeline
- **Playhead** — the red point telling where playback is

**Transport Controls** (the Play, Stop, Record buttons in Studio)

| Button | Function |
|-----|---------|
| ▶ Play | start playback |
| ⏹ Stop | stop |
| ⏺ Record | start recording |

## Recording

### How to record audio in Studio

1. Click the Track you want to record on
2. Click the **Record** button (⏺)
3. The browser asks for Microphone access — press "Allow"
4. Accept and start recording
5. Press **Stop** when done

### Loop Recording

**Loop Recording** helps record repeatedly over the same time range to capture the best Take (each recording).

1. Select the time range you want to Loop
2. Enable **Loop** mode
3. Press Record — Studio records repeatedly in that range
4. Choose the best Take afterward

## Mixing

**Mixing** (adjusting and blending multiple Tracks to sound good) in Studio is done via:

### Mixer Panel

- **Volume** — adjust each Track's Fader
- **Pan** (the left-right direction of the sound) — adjust the sound's position in the Stereo Field
- **Mute** — temporarily mute a Track
- **Solo** (listen to only that Track) — listen to only the Track you want

---

## EQ

**EQ — Equalizer** (a tool to adjust audio frequencies, boosting or cutting bass, mids, or treble)

### How to use EQ in Studio

1. Select the Track you want
2. Click the **EQ** icon or open Track Settings
3. Adjust the Frequency Bands:

| Band | Frequency | Effect |
|-----|---------|---|
| **Low Bass** | 20–80 Hz | very deep sound |
| **Bass** | 80–250 Hz | heavy bass |
| **Mid** | 250 Hz–4 kHz | clear midrange |
| **Presence** | 4–8 kHz | sharp, clear sound |
| **Brilliance** | 8–20 kHz | treble, air |

## Stem Cover in Studio

**Stem Cover** transforms the sound in a Track into a new sound.

**Examples:**
- Change a Guitar Track to Orchestra Strings
- Change a Drum Track to a different-style Drum Kit
- Change a Vocal Track to a Choir

### How to use Stem Cover

1. Select a Region on the Timeline
2. Right-click and choose **"Stem Cover"**
3. Choose the target sound you want
4. Wait for the AI to transform the sound

---

## Fixing Tempo Drift

**Tempo Drift** (when some genres, e.g. 80s Disco, have an inconsistent rhythm) can be fixed in Studio:

1. Open the problem song in Studio
2. Use the **Time Correction** tool
3. Adjust the Tempo Map to line up

## Exporting

### Supported Export formats

| Format | Meaning | Used for |
|-------|---------|---------|
| **MP3** | a compressed audio file | Streaming, general uploads |
| **WAV** | a high-quality file (uncompressed) | Mastering, professional Production |
| **Stems** | separate files for each Track | letting others Remix, separate Mastering |

### How to Export

1. Click **File > Export** or the Export button
2. Choose the file format
3. Choose the Quality — for WAV, choose 24-bit or 32-bit
4. Click **"Export"** and wait for the download

## Tips for using Studio

> **Tip:** Start by bringing a song created in normal Suno into Studio, then Fine-tune in Studio instead of creating it all over.

> **Tip:** Use Loop Recording to record several Takes, then choose the best.

> **Tip:** Good EQ should cut unwanted frequencies first, then boost the wanted ones (Cut before Boost).

> **Tip:** Always Export as WAV first, then convert to MP3 in the final step.
