# Editor — แก้ไขภาพขั้นสูง

> อ้างอิงหลัก: [Editor](https://docs.midjourney.com/hc/en-us/articles/32764383466893-Editor)

---

## Editor คืออะไร

Editor (โปรแกรมแก้ไขภาพในตัว — เครื่องมือแก้ไขภาพที่สร้างด้วย Midjourney โดยตรงบนเว็บไซต์ ไม่ต้องใช้โปรแกรมแยก) เป็นฟีเจอร์ที่รวมเครื่องมือแก้ไขภาพไว้บนเว็บ Midjourney ช่วยให้ทำงานกับภาพได้โดยตรงโดยไม่ต้องออกไปใช้ Photoshop

---

## วิธีเข้า Editor

1. สร้างภาพและ Upscale ก่อน
2. คลิก **"Edit"** บนภาพ
3. Editor จะเปิดในหน้าใหม่

---

## เครื่องมือใน Editor

### Erase (ลบ — ลบส่วนที่ไม่ต้องการออกจากภาพ)
- วาดทับบนส่วนที่ต้องการลบ
- Midjourney จะเติมเนื้อหาใหม่ในพื้นที่ที่ลบ
- คล้ายกับ Content-Aware Fill ใน Photoshop

### Repaint (ทาสีใหม่ — วาดเลือกพื้นที่แล้วให้ AI สร้างใหม่)
- เลือกพื้นที่แล้วกำหนด Prompt
- เหมือน Vary Region แต่มีเครื่องมือที่ละเอียดกว่า

### Outpaint (ขยายออก — ขยายขอบเขตภาพออกไปนอกกรอบเดิม)
- ขยายภาพออกไปทิศทางใดก็ได้
- เหมือน Zoom Out หรือ Pan แต่ทำในหน้า Editor

### Adjust (ปรับแต่ง — แก้ไข Prompt เพื่อเปลี่ยนภาพ)
- ปรับ Prompt ของภาพทั้งหมด
- คล้ายกับ Remix Mode

---

## Workflow การใช้ Editor

### สถานการณ์ 1 — แก้ไขรายละเอียดเล็กน้อย
1. Upscale ภาพ
2. เปิด Editor
3. ใช้ Erase เพื่อลบส่วนที่ไม่ต้องการ
4. Midjourney เติมส่วนที่ลบด้วย AI โดยอัตโนมัติ

### สถานการณ์ 2 — เปลี่ยนส่วนสำคัญ
1. Upscale ภาพ
2. เปิด Editor
3. ใช้ Repaint + Prompt เพื่อเปลี่ยนส่วนที่ต้องการ

### สถานการณ์ 3 — สร้างภาพที่กว้างขึ้น
1. Upscale ภาพ
2. เปิด Editor
3. ใช้ Outpaint เพื่อขยายออกไปทิศทางต่างๆ

---

## ตัวอย่างการใช้ Editor จริง

### ลบสิ่งรบกวน
```
ภาพทิวทัศน์ที่มีสายไฟในภาพ
→ Erase ส่วนสายไฟ
→ Midjourney เติมท้องฟ้าในพื้นที่นั้น
```

### เปลี่ยนพื้นหลัง
```
ภาพ Portrait พื้นหลังขาว
→ Repaint พื้นหลัง + Prompt: "lush garden, soft bokeh"
→ ได้ Portrait เดิมแต่มีพื้นหลังสวน
```

### ขยายสำหรับ Banner
```
ภาพขนาด 1:1
→ Outpaint ซ้ายและขวา
→ ได้ภาพ 16:9 สำหรับ Banner
```

---

## เคล็ดลับ

1. **บันทึกบ่อย** — Editor ไม่มี Auto-save
2. **ทำทีละขั้น** — แก้ไขทีละส่วนจะควบคุมผลได้ดีกว่า
3. **ใช้ Erase + Prompt** — การระบุว่าต้องการอะไรในพื้นที่ที่ลบจะให้ผลดีกว่าปล่อยให้ AI เดาเอง

---

## สรุป

Editor เป็นศูนย์รวมเครื่องมือแก้ไขภาพที่สะดวก รวม Vary Region, Zoom Out, Pan และฟีเจอร์ Erase/Repaint ไว้ในที่เดียว เหมาะสำหรับการ Fine-tune ภาพขั้นสุดท้ายก่อนนำไปใช้งาน
