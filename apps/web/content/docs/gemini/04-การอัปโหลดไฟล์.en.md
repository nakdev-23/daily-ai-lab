# 04 — Uploading and analyzing files

Reference: [Upload & Analyze Files](https://support.google.com/gemini/answer/14903178) | [GitHub Repos](https://support.google.com/gemini/answer/16176929)

---

## What you can do by uploading files

You can upload documents, spreadsheets, images, videos, audio, code, and notebooks from NotebookLM so Gemini can:
- **Analyze** and summarize the content
- **Answer questions** about the data in the file
- **Compare** several files at once
- **Create charts** or visualizations from the data

---

## How to upload files

### Upload from your device
1. Go to [gemini.google.com](https://gemini.google.com)
2. Click the **Add files** icon (📎) in the message box
3. Click **Upload Files** → choose files from your device
4. Type a prompt and click Submit

### Upload a code folder
1. Click **Add files** → **More Uploads** → **Import Code** → **Upload folder**
2. Choose a code folder from your device

### Connect a GitHub Repository
1. Click **Add files** → **More Uploads** → **Import Code**
2. Paste the URL of a GitHub repository or branch
3. Gemini pulls the code to analyze

> **GitHub limit:** supports up to 5,000 files per repo and a total size of no more than 100 MB

### Upload from Google Drive
1. Click **Add files** → **Add from Drive** (the Drive icon)
2. You must turn on **Keep Activity** and connect Google Workspace first

### Upload from NotebookLM
1. Click **Add files** → **More Uploads** → **Notebooks** (the Notebook icon)
2. Choose the notebook you want

## Upload limits

| Type | Limit |
|---|---|
| **Files per prompt** | Up to 10 files (may change) |
| **Video size** | Up to 2 GB per file |
| **Other file sizes** | Up to 100 MB per file |
| **Total video length** | 5 minutes (free) / 1 hour (Pro/Ultra) |
| **Total audio length** | 10 minutes (free) / 3 hours (Pro/Ultra) |
| **Folder/GitHub repo** | Up to 5,000 files, no more than 100 MB |
| **ZIP file** | Up to 10 files inside, no more than 100 MB (video/audio in ZIP not supported) |

## Supported file types

Gemini supports most files, including:

**Documents:** PDF, DOCX, TXT, XLSX, CSV, PPTX, RTF, Markdown

**Images:** JPEG, PNG, GIF, WebP, HEIC/HEIF

**Video:** MP4, MOV, AVI, MKV, WebM, and others

**Audio:** MP3, WAV, FLAC, AAC, OGG, OPUS

**Code:** all kinds of code files, ZIP

## Error messages you might see

### "Delete data to upload file"
**Cause:** Your storage in Gemini Apps is full (separate from Google Drive)

**Fix:**
1. Go to gemini.google.com
2. Click **Settings & help** → **Activity**
3. Delete unwanted activity or chats
4. Wait a moment and try again

> **Tip:** Chats with video, images, or files from Drive take more space than ordinary chats.

### "You've reached your limit for chats with files"
**Cause:** You exceeded the upload quota for that period

**Fix:** Wait for the quota to reset, or upgrade to Google AI Pro/Ultra

### "Your uploads may be too large for the best results"
**Cause:** The file is too large for the context window to take fully

**Fix:** Split the file smaller, or upgrade to a plan with a 1-million-token context window

---

## The Context Window and uploading files

The **context window** defines how much data Gemini can "read":

- **32K tokens (free):** good for short documents
- **128K tokens (Plus):** takes more data
- **1M tokens (Pro/Ultra):** reads up to 1,500 pages or 30,000 lines of code

> If a file's content exceeds the context window, Gemini may "miss" some details, especially in files with data spread throughout.

## Summary

Uploading files turns Gemini into a powerful data-analysis tool, supporting almost every file type — documents, images, video, and code. For work that analyzes large files or several files at once, upgrade to Pro/Ultra for a larger context window.
