# The Kimi K2 model 🧠

> Compiled in English from Moonshot AI's official docs — [platform.moonshot.ai](https://platform.moonshot.ai/)

Behind Kimi is Moonshot AI's model family, with the best-known version being **Kimi K2**, which excels at reasoning, coding, and agentic work.

## ⭐ K2's highlights

- **Good at reasoning and code** — great for step-by-step thinking and programming
- **Agentic** — designed for tool use and multi-step work
- **Long context** — supports large inputs
- **An open model (open weights)** — some versions are open to download/run yourself (e.g. via Hugging Face)

## 🔢 Choosing which to use

- In Kimi (web), the system already picks the model suited to the task
- Via the API, you can specify the model name yourself (see the latest version names in the platform docs)

## 🆚 The strong version vs the fast version

In general there's a version focused on **quality/reasoning** and one focused on **speed/low cost** — choose by the task: heavy thinking uses the strong version, short/high-volume work uses the fast version.
