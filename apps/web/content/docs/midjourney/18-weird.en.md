# Weird — add strangeness

> Main reference: [Weird](https://docs.midjourney.com/hc/en-us/articles/32390120435085-Weird)

---

## What is Weird

The `--weird` or `--w` Parameter (the level of the unusual and unexpected that Midjourney adds to the image) gives the image strange, abnormal, or Surreal (dreamlike, unrealistic) elements.

---

## Values and results

```
--weird 0       → normal, no strangeness (default)
--weird 250     → slightly weird, more interesting
--weird 500     → moderately weird, with unexpected elements
--weird 1000    → very weird, Surrealist
--weird 2000    → extremely weird
--weird 3000    → maximum weird, may be hard to predict
```

**Can be shortened to `--w`:**
```
a garden --w 500
```

---

## Usage examples

### Add interest
```
a portrait of a woman --weird 250
```
→ may get an image with slightly unusual details, such as an abnormal drawing style

### Surreal Art
```
a city at night --weird 1000
```
→ may get a city image with Surreal elements, such as buildings flowing like water, an abnormal sky

### For Creative work
```
abstract nature concept --weird 2000
```
→ get an extremely creative image, good for an Art Print or Cover Art

---

## Weird and Stylize

| Parameter | Result |
|-----------|-----|
| `--stylize high` | a more beautiful, better-looking image |
| `--weird high` | a stranger, more unusual image |
| `--stylize 750 --weird 500` | an image that's beautiful and strange at the same time |

---

## When to use it

- Concept Art work needing novelty
- Poster Art needing to grab attention
- Exploring an unusual Aesthetic
- When you want Inspiration from an unexpected viewpoint

---

## Weird vs Chaos — how they differ

| Parameter | Affects |
|-----------|---------|
| `--chaos` | the variety among the 4 images in the same set |
| `--weird` | the strangeness of each individual image |

You can use both together:
```
a portrait --chaos 50 --weird 500
```
→ 4 varied images, each weird in its own way

---

## Weird at various levels with examples

### --weird 0 (normal)
```
a forest landscape --weird 0
```
→ a forest that looks realistic and normal

### --weird 500 (moderately weird)
```
a forest landscape --weird 500
```
→ a forest with a strange atmosphere, perhaps abnormal light or oddly shaped trees

### --weird 2000 (very weird)
```
a forest landscape --weird 2000
```
→ a forest that may have Surreal elements, such as crystal trees or unnatural colors

---

## Weird and creating Art

Weird is good for:

### Experimental Art
```
abstract composition --weird 1500 --stylize 800
```

### Dreamlike Imagery
```
a person walking through a door --weird 1000
```
→ a dreamlike atmosphere with unexpected elements

### Album Art / Poster
```
ethereal figure in cosmic space --weird 1200 --stylize 600
```
→ Art for an album cover or poster that grabs attention

---

## Tips for using Weird effectively

1. **Combine with high Stylize** — `--weird 500 --stylize 750` gives a strange yet beautiful image
2. **Use a simple Prompt** — a short Prompt with high Weird gives surprising results well
3. **Explore before real use** — test various values before choosing the one suited to your work
4. **Save the Seed** — if you get a weird image you like, save the Seed immediately

---

## Summary

`--weird` is a Parameter that lets you push the boundaries of creativity. Use a low value (250-500) to add interest without being too weird, a medium value (500-1000) for distinctive Artistic work, and a high value (1000+) when you want truly unusual Surreal Art. Combine with high `--stylize` to get both strangeness and beauty.
