# Vary Region — แก้ไขเฉพาะพื้นที่

> อ้างอิงหลัก: [Vary Region](https://docs.midjourney.com/hc/en-us/articles/32794723105549-Vary-Region)

---

## Vary Region คืออะไร

Vary Region (การปรับแต่งเฉพาะพื้นที่ — เลือกส่วนใดส่วนหนึ่งในภาพแล้วให้ Midjourney สร้างเนื้อหาใหม่เฉพาะในพื้นที่นั้น ส่วนอื่นคงเดิม) คล้ายกับฟีเจอร์ Inpainting (การวาดภายใน — แก้ไขส่วนที่ต้องการโดยไม่เปลี่ยนส่วนอื่น) ใน Photoshop

---

## วิธีใช้

1. Upscale ภาพที่ต้องการก่อน
2. คลิก **"Vary (Region)"**
3. เครื่องมือวาดจะปรากฏ:
   - **Rectangle** — วาดสี่เหลี่ยมเลือกพื้นที่
   - **Lasso** — วาดอิสระเลือกพื้นที่
4. วาดเลือกพื้นที่ที่ต้องการแก้ไข
5. พิมพ์ Prompt สำหรับพื้นที่นั้น (ไม่จำเป็นแต่แนะนำ)
6. คลิก Generate

---

## ตัวอย่างการใช้งาน

### แก้ไขท้องฟ้า
```
ภาพเดิม: ทิวทัศน์ ท้องฟ้าขาว
วาดเลือกท้องฟ้า + Prompt: "dramatic sunset sky, orange and pink clouds"
ผล: ทิวทัศน์เดิม แต่ท้องฟ้าสวยงาม
```

### เปลี่ยนเสื้อผ้า
```
ภาพเดิม: ตัวละครสวมชุดสีน้ำเงิน
วาดเลือกเสื้อผ้า + Prompt: "wearing a red dress"
ผล: ตัวละครเดิมแต่สวมชุดสีแดง
```

### เพิ่มองค์ประกอบ
```
ภาพเดิม: ทิวทัศน์ภูเขา
วาดเลือกพื้นที่ว่าง + Prompt: "a lone wolf silhouette"
ผล: มีหมาป่าปรากฏในพื้นที่ที่เลือก
```

### แก้ไขใบหน้า
```
ภาพเดิม: Portrait ที่ดูดีแต่ใบหน้าไม่สมจริง
วาดเลือกใบหน้า + Prompt: "realistic face, detailed features"
ผล: ใบหน้าที่สมจริงขึ้น
```

---

## เคล็ดลับ Vary Region

1. **เลือกพื้นที่ไม่เล็กเกินไป** — ถ้าเลือกเล็กมาก Midjourney อาจไม่สามารถสร้างเนื้อหาที่ดีได้
2. **ใส่ Prompt เสมอ** — แม้จะไม่บังคับ แต่ช่วยให้ผลลัพธ์ตรงกับต้องการมากขึ้น
3. **ลอง Generate หลายครั้ง** — แต่ละครั้งอาจให้ผลต่างกัน
4. **ไม่ต้อง Upscale ก่อนก็ได้** — แต่ Upscale ก่อนให้คุณภาพดีกว่า

---

## ข้อจำกัด

- การเปลี่ยนส่วนกลางของภาพที่ซับซ้อนอาจให้ผลไม่สม่ำเสมอ
- พื้นที่ที่เลือกต้องไม่เกิน 75% ของภาพ (ถ้ามากกว่านี้ใช้ Variation แทน)

---

## ตัวเลือกเครื่องมือวาด

ใน Vary Region มีเครื่องมือเลือกพื้นที่ 2 แบบ:

### Rectangle (สี่เหลี่ยม)
- วาดเลือกพื้นที่แบบสี่เหลี่ยม
- เหมาะสำหรับพื้นที่ที่มีขอบตรง เช่น ท้องฟ้า, พื้นหลัง

### Lasso (ฟรีสไตล์)
- วาดเลือกแบบอิสระตามรูปร่างที่ต้องการ
- เหมาะสำหรับพื้นที่ที่มีรูปร่างซับซ้อน เช่น รูปร่างคน, วัตถุ

---

## Vary Region กับ Editor

Vary Region เป็นส่วนหนึ่งของ Editor ด้วย โดย:
- **Vary Region** ในหน้าหลัก = เปิดหน้าต่างแยก
- **Repaint ใน Editor** = ทำงานเหมือนกัน แต่มีเครื่องมืออื่นเพิ่มด้วย

---

## Prompt ที่ดีสำหรับ Vary Region

เมื่อวาดเลือกพื้นที่แล้ว ใส่ Prompt ที่:
- บอกว่าต้องการ **อะไร** ในพื้นที่นั้น
- ไม่ต้องอธิบายส่วนอื่นของภาพ
- ใช้คำอธิบายที่สอดคล้องกับส่วนที่เหลือของภาพ

**ตัวอย่าง Prompt ดี:**
```
"dramatic sunset sky with orange and purple clouds"  ← สำหรับพื้นที่ท้องฟ้า
"a black cat sitting on a cushion"  ← สำหรับพื้นที่โซฟา
```

---

## สรุป

Vary Region เป็นเครื่องมือ Editing ที่ทรงพลัง ช่วยให้แก้ไขเฉพาะจุดโดยไม่ทำลายส่วนที่ดีของภาพ ใช้ Rectangle เพื่อเลือกพื้นที่ง่ายๆ หรือ Lasso เพื่อเลือกพื้นที่รูปร่างซับซ้อน เหมาะสำหรับการ Fine-tune ขั้นสุดท้ายก่อนนำไปใช้งาน
