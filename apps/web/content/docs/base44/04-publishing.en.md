# Integrations & Publishing 🚀

> Adapted from the official documentation at [docs.base44.com](https://docs.base44.com/)

## 🔌 Integrations (add-on services)

Even though Base44 is all-in-one, you can connect more services, such as:
- **Email** — send notification/confirmation emails
- **Payments** — take money in the app
- **Other external services** via connections/API calls

Request it in text, e.g. "send a confirmation email when there's a new booking"

## 🌐 Publishing

1. Check the app and its data-access permissions are in order
2. Hit **Publish**
3. You get a link others can use right away
4. Made changes and want to update? Just Publish again

## ✅ Checklist before going public

- The login system works correctly
- Data permissions are tight (users see only their own)
- The main features are tested and working
- The UI displays well on both mobile and desktop
