# Agent Manager — the agent command center 🎛️

> Adapted from the official documentation at [antigravity.google](https://antigravity.google/)

The **Agent Manager** is the view that lets you **assign work and control multiple agents at once** — like being a team lead directing several AI teammates.

## ⭐ What you can do

- **Assign tasks** to agents, one job at a time
- **Watch several agents work in parallel** — each on a different job
- **Track the progress** of each task
- **Review the output** (code/plan/screenshots) before accepting

## 🔄 How it works

1. Write a clear task, e.g. "add search to the products page"
2. The agent **plans** → asks for approval (if configured)
3. The agent **gets to work** writing code, running tests, testing in the browser
4. It sends **Artifacts** (the output) for you to review

## 💡 Tips

- Break a big job into several subtasks and let multiple agents help
- Write a clear goal + success criteria, and the agent will be more on target
- Always review the work before merging it into the real project
