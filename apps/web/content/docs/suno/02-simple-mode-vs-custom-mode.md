# Simple Mode vs Custom Mode — สองโหมดสร้างเพลง

Suno มีสองโหมดหลักสำหรับสร้างเพลง ได้แก่ **Simple Mode** (โหมดง่าย) และ **Custom Mode** (โหมดกำหนดเอง) แต่ละโหมดเหมาะกับวัตถุประสงค์ที่แตกต่างกัน

---

## Simple Mode (โหมดง่าย)

Simple Mode คือโหมดที่ Suno จัดการทุกอย่างให้ คุณแค่บอกว่าอยากได้เพลงแบบไหน แล้ว AI จะสร้างทั้งหมด

### วิธีใช้ Simple Mode

1. ไปที่หน้า **Create** (สร้าง)
2. ตรวจสอบว่าปุ่มสลับ (Toggle) อยู่ที่ **"Simple"** (ไม่ใช่ Custom)
3. พิมพ์คำอธิบายเพลงในช่อง **"Song Description"** (คำอธิบาย)
4. เลือกว่าต้องการ **Instrumental** (เพลงบรรเลง — ไม่มีเสียงร้อง) หรือไม่
5. คลิก **"Create"**

### สิ่งที่ AI จัดการให้ใน Simple Mode

| สิ่งที่ AI สร้างให้ | คำอธิบาย |
|--------------------|---------|
| **Lyrics** (เนื้อเพลง) | AI เขียนเนื้อเพลงทั้งหมด |
| **Style** (สไตล์) | AI เลือก Genre และเสียงดนตรี |
| **Structure** (โครงสร้าง) | AI กำหนด Verse, Chorus, Bridge เอง |
| **Vocals** (เสียงร้อง) | AI เลือกเสียงนักร้องที่เหมาะสม |

### ตัวอย่าง Prompt ใน Simple Mode

```
เพลง Pop สนุกสนาน เกี่ยวกับการไปเที่ยวทะเล กับเพื่อน ๆ
```

```
Upbeat jazz song about a busy city morning
```

```
Melancholic indie folk, feeling lost in life
```

---

## Custom Mode (โหมดกำหนดเอง)

Custom Mode ให้คุณควบคุมทุกส่วนของเพลงได้เอง เหมาะสำหรับผู้ที่ต้องการผลลัพธ์ที่แม่นยำ

### วิธีเปิด Custom Mode

1. ในหน้า **Create** คลิกปุ่ม **"Custom"** ที่มุมขวาบนของกล่องสร้างเพลง
2. จะปรากฏช่องใหม่ 3 ช่อง:
   - **Lyrics** (เนื้อเพลง) — ใส่เนื้อเพลงของคุณเอง
   - **Style of Music** (สไตล์เพลง) — ระบุแนวเพลงและลักษณะเสียง
   - **Title** (ชื่อเพลง) — ตั้งชื่อเพลง

### ฟิลด์ต่าง ๆ ใน Custom Mode

#### 1. Lyrics (เนื้อเพลง)

ใส่เนื้อเพลงที่คุณเขียนเอง โดยใช้ **Metatags** (แท็กพิเศษ) เพื่อบอก AI ว่าแต่ละส่วนคืออะไร:

```
[Verse] (ท่อนเวิร์ส — ท่อนเล่าเรื่อง)
เช้านี้ฟ้าสดใส
แสงแดดส่องสวยงาม

[Chorus] (ท่อนฮุก — ท่อนที่คนจำได้)
วันนี้วันดี ๆ
ทุกอย่างสดใสสวย
```

#### 2. Style of Music (สไตล์เพลง)

พิมพ์คำที่อธิบายเสียงดนตรีที่ต้องการ เช่น:

```
upbeat pop, female vocals, guitar, summer vibes
```

```
dark hip-hop, trap beats, 808 bass, male rap
```

```
cinematic orchestral, strings, epic, emotional
```

#### 3. Title (ชื่อเพลง)

ตั้งชื่อเพลงตามใจชอบ

## เปรียบเทียบ Simple Mode vs Custom Mode

| คุณสมบัติ | Simple Mode | Custom Mode |
|----------|------------|-------------|
| **ความยาก** | ง่ายมาก | ปานกลาง |
| **เนื้อเพลง** | AI สร้างให้ | คุณเขียนเอง |
| **สไตล์เพลง** | AI เลือกให้ | คุณกำหนดเอง |
| **ความยืดหยุ่น** | น้อย | สูงมาก |
| **เวลาที่ใช้** | เร็ว | ใช้เวลากว่า |
| **เหมาะกับ** | มือใหม่ / ทดลองสร้าง | ผู้ที่มีวิสัยทัศน์ชัดเจน |

---

## เมื่อไหร่ควรใช้โหมดไหน?

### ใช้ Simple Mode เมื่อ:
- ต้องการทดลองว่า Suno ทำงานอย่างไร
- ไม่มีเนื้อเพลงที่ต้องการใช้
- ต้องการแรงบันดาลใจจาก AI
- รีบสร้างเพลงเร็ว ๆ

### ใช้ Custom Mode เมื่อ:
- มีเนื้อเพลงที่เขียนเองแล้ว
- ต้องการสไตล์ดนตรีที่เฉพาะเจาะจง
- ทำงานระดับ Professional (มืออาชีพ)
- ต้องการควบคุมโครงสร้างเพลงอย่างละเอียด

---

## เคล็ดลับ

> **Tip:** ถ้าใช้ Custom Mode แต่ยังไม่มีเนื้อเพลง ให้พิมพ์ `[Instrumental]` ในช่อง Lyrics เพื่อสร้างเพลงบรรเลงโดยไม่มีเสียงร้อง

> **Tip:** ใน Custom Mode สามารถปล่อยช่อง Lyrics ว่างแล้วใส่แค่ Style เพื่อให้ AI สร้างเนื้อเพลงเองแต่ใช้สไตล์ที่คุณกำหนด

> **Tip:** ลองผสมทั้งสองโหมด — เริ่มจาก Simple Mode เพื่อหาแนวเพลงที่ชอบ แล้วค่อยมาปรับใน Custom Mode
