# Show Command — เรียกภาพกลับมา

> อ้างอิงหลัก: [Show Command](https://docs.midjourney.com/hc/en-us/articles/32635695384461-Show-Command)

---

## /show คืออะไร

คำสั่ง `/show` (แสดงงานเดิม — เรียกงานที่สร้างไว้แล้วกลับมาใน Discord โดยใช้ Job ID) ช่วยให้คุณดึงภาพเก่าๆ กลับมาพร้อมปุ่ม Upscale, Vary, และตัวเลือกต่างๆ

---

## Job ID คืออะไร

Job ID (รหัสงาน — ตัวเลขและตัวอักษรเฉพาะที่ระบุงานสร้างภาพแต่ละชิ้น) เป็นรหัสเฉพาะของงานแต่ละชิ้น รูปแบบเช่น `a1b2c3d4-e5f6-...`

---

## วิธีหา Job ID

### บน Discord
1. คลิก Emoji ✉️ บนข้อความภาพ
2. Midjourney Bot จะส่ง DM พร้อม Job ID

### บนเว็บ
1. ไปที่ Archive
2. คลิกที่ภาพ
3. ดู Job ID ในรายละเอียดภาพ
4. คัดลอก URL ซึ่งมี Job ID อยู่

---

## วิธีใช้ /show

```
/show job_id: [Job ID ของงาน]
```

**ตัวอย่าง:**
```
/show job_id: a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

Midjourney Bot จะส่งภาพกลับมาพร้อมปุ่มทั้งหมด (Upscale, Vary, ฯลฯ)

---

## กรณีที่ใช้ /show

1. **ภาพหายจากหน้าจอ** — Discord โหลดข้อความเก่าไม่แสดง
2. **ต้องการ Upscale ภาพเก่า** — งานที่สร้างไว้นานแล้ว
3. **แชร์ Job ID ให้คนอื่น** — คนอื่นสามารถดึงงานมาต่อยอดได้
4. **ย้าย Server** — เรียกงานเก่ามาในห้องใหม่

---

## การแชร์งานด้วย Job ID

Job ID ช่วยให้แชร์งานกับผู้อื่นได้:

**แชร์ให้เพื่อน:**
1. หา Job ID ของงาน
2. ส่ง Job ID ให้เพื่อน
3. เพื่อนใช้ `/show job_id: [ID]` เพื่อดูงานและต่อยอดได้

---

## URL ของงาน

นอกจาก Job ID ยังมี URL ตรงของงาน:
```
https://www.midjourney.com/jobs/[Job ID]
```

ใช้แชร์ลิงก์ตรงให้คนอื่นดูงานบนเว็บ

---

## ข้อควรรู้

- `/show` ใช้ได้เฉพาะใน Discord เท่านั้น
- งานที่เป็น Private จะไม่สามารถ Show ได้ในห้องสาธารณะ
- Job ID ใช้ได้ตลอดไปตราบที่งานยังอยู่ในระบบ

---

## กรณีที่ Job ID ไม่ทำงาน

- งานถูกลบออกจากระบบ
- งานเป็น Private และคุณไม่มีสิทธิ์
- พิมพ์ Job ID ผิด — ตรวจสอบอีกครั้ง

---

## สรุป

`/show` เป็นคำสั่งที่มีประโยชน์สำหรับเรียกงานเก่ากลับมาใน Discord เพื่อแก้ไขหรือต่อยอด ใช้คู่กับ Job ID ที่ได้จากการคลิก ✉️ บนงาน และยังใช้แชร์งานกับเพื่อนได้โดยส่ง Job ID ให้กัน
