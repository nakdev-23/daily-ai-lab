# Discord Overview — ภาพรวม Discord

> อ้างอิงหลัก: [Discord Overview](https://docs.midjourney.com/hc/en-us/articles/33330535666445-Discord-Overview)

---

## Midjourney Server บน Discord

เมื่อเข้าร่วม Midjourney Discord Server คุณจะเห็นหมวดหมู่ห้องต่างๆ ดังนี้:

---

## โครงสร้าง Server

### INFO หมวดข้อมูล
- **#announcements** — ประกาศอัปเดตและข่าวสารสำคัญ
- **#status** — สถานะระบบ (ว่ามีปัญหาหรือไม่)
- **#rules** — กฎระเบียบของ Server

### NEWCOMER ROOMS หมวดผู้เริ่มต้น
- **#newbies-1** ถึง **#newbies-N** — ห้องสำหรับผู้เริ่มต้น
- ใช้ `/imagine` ที่นี่ได้เลย
- เห็นงานของผู้อื่นใน Real-time

### GENERAL หมวดทั่วไป
- **#general** — ห้องสนทนาทั่วไป
- **#prompt-craft** — แชร์ Prompt เทคนิค

### DAILY หมวดรายวัน
- **#daily-theme** — ธีมภาพประจำวัน
- ท้าทายตัวเองด้วยธีมที่กำหนด

### IMAGE CREATION หมวดสร้างภาพ
- **#imagine** — ห้องสร้างภาพหลัก
- ห้องสร้างภาพเฉพาะประเภทต่างๆ

---

## Direct Messages กับ Midjourney Bot

ถ้าต้องการความเป็นส่วนตัวมากขึ้น:
1. ค้นหา **Midjourney Bot** ใน Server
2. คลิก "Message" เพื่อส่ง DM
3. ใช้ `/imagine` ใน DM ได้เลย

**ข้อสังเกต:** แม้ใช้ DM งานยังปรากฏสาธารณะ เว้นแต่มี Stealth Mode (แผน Pro+)

---

## เพิ่ม Midjourney Bot เข้า Server ส่วนตัว

สะดวกกว่าการใช้ Server กลาง เพราะ:
- ไม่มีงานของคนอื่นรบกวน
- จัดห้องแยกตามโปรเจกต์ได้
- เชิญเพื่อนร่วมงานเข้ามาได้

วิธีเพิ่ม:
1. ไปที่ Midjourney Server → คลิก Midjourney Bot
2. เลือก "Add to Server"
3. เลือก Server ของคุณ → Authorize

---

## Creation Settings ใน Discord

พิมพ์ `/settings` เพื่อเปิดแผงตั้งค่าที่มีปุ่มกด:

- เลือก Model Version
- เลือก Mode (Fast/Relax/Turbo)
- เปิด/ปิด Remix Mode
- ตั้งค่า Quality และ Stylize เริ่มต้น

---

## ข้อแตกต่างระหว่าง Discord Server กลาง กับ Server ส่วนตัว

| | Server กลาง | Server ส่วนตัว |
|--|------------|---------------|
| เห็นงานคนอื่น | ✅ เยอะมาก | ❌ มีแค่ทีมคุณ |
| เรียนรู้จากชุมชน | ✅ ดีมาก | ❌ น้อยกว่า |
| ความเป็นส่วนตัว | ❌ ต่ำ | ✅ สูงกว่า |
| จัดระเบียบงาน | ❌ ยาก | ✅ แยกห้องได้ |

---

## สรุป

Midjourney บน Discord มีทั้ง Server กลางที่เต็มไปด้วยชุมชนสำหรับเรียนรู้ และตัวเลือกใช้งาน DM หรือ Server ส่วนตัวสำหรับความเป็นส่วนตัว เลือกตามความต้องการ
