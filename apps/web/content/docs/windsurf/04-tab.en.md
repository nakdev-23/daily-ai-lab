# Tab — auto-completion ⌨️

> Compiled in English from the official docs at [windsurf.com/docs](https://docs.windsurf.com/), the Tab section

**Tab** is Windsurf's auto-completion system that predicts what you're about to type and offers code to accept with the `Tab` key — like having someone type half of it for you.

## ⭐ Highlights

- **Predicts a whole line/multiple lines**, not just a single word
- **Understands file context** — completes in a way consistent with the surrounding code
- **Predicts your next edit** — sometimes suggests jumping to a related spot to fix next
- **Easy to accept/reject** — press `Tab` to accept, keep typing to skip

## ▶️ How to use it

1. Type code as usual
2. When faint text appears = a Tab suggestion
3. Press `Tab` to accept, or keep typing to decline

> Tab differs from Cascade in that Tab helps "while typing," whereas Cascade takes on a big task as a whole
