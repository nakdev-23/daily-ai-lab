# Instrumental Mode — create instrumental songs with no vocals

**Instrumental** (a song with no vocals, only instruments) is one of Suno's most useful features, because it can quickly create background music for videos, Podcasts, presentations, and more.

---

## How to create an instrumental song in Simple Mode

1. Go to the **Create** page
2. Type the song description in the Song Description box
3. Check the **"Instrumental"** checkbox (or the toggle at the bottom)
4. Click **"Create"**

Example Prompts for an instrumental song:
```
calm lo-fi coffee shop jazz, piano and bass
```
```
epic cinematic orchestral, adventure theme, strings and brass
```
```
upbeat corporate background music, positive, professional
```

---

## How to create an instrumental song in Custom Mode

In Custom Mode, enter **`[Instrumental]`** in the Lyrics field to tell the AI you don't want vocals.

```
[Instrumental]
```

Or specify the instruments in each section:

```
[Intro - Instrumental]
[Verse - Instrumental]
[Chorus - Build Up]
[Outro - Fade Out]
```

## Popular types of instrumental music

### 1. Lo-fi Hip-Hop

A "study music" style that's easy to listen to, good for working or reading.

**Style Prompt:**
```
lo-fi hip-hop, chill beats, vinyl crackle, soft piano, slow jazz, 75 BPM, no vocals, study music
```

### 2. Cinematic Orchestral

A film-style track, good for YouTube videos or Presentations.

**Style Prompt:**
```
epic cinematic orchestral, no vocals, strings, brass, timpani drums, heroic, building tension, Hans Zimmer style
```

### 3. Ambient / Meditation

Soft music with no clear rhythm, good for Meditation or Yoga.

**Style Prompt:**
```
ambient meditation music, singing bowls, soft pads, nature sounds, no rhythm, peaceful, 432Hz
```

### 4. Corporate Background

**Style Prompt:**
```
upbeat corporate background music, acoustic guitar, light percussion, positive, professional, no vocals
```

### 5. Jazz

**Style Prompt:**
```
smooth jazz, saxophone, piano, upright bass, brushed drums, cocktail hour, evening vibes, no vocals
```

### 6. Gaming / Chiptune

**Style Prompt:**
```
8-bit chiptune, video game music, upbeat adventure theme, NES style, no vocals
```

## Using the `[Instrumental]` Metatag cleverly

You can mix vocal sections with instrumental sections in the same song:

```
[Verse]
First verse lyrics...

[Chorus]
Chorus lyrics...

[Instrumental Break]

[Verse 2]
Second verse lyrics...

[Guitar Solo]

[Chorus]
Chorus lyrics...

[Outro - Instrumental]
```

## Stem Extraction — separate the vocals from the music

**Stem Extraction** (separating the audio file into separate tracks, e.g. separating the vocals from the music) is a feature for Pro and Premier users that lets you:

- Download the vocals (Vocals Stem) separately
- Download the background music (Instrumental Stem) separately
- Use the Instrumental without vocals

### How to use Stem Extraction

1. Open the song you want
2. Click the menu (**...**) or the Options button
3. Choose **"Stem Extraction"**
4. Choose whether you want Vocals or Instrumental
5. Download the file

> **Note:** Stem Extraction uses extra credits and is only on the Pro/Premier plans.

## Special tips

> **Tip:** If you want a song of just the right length, use Extend to add length as needed.

> **Tip:** For background music, add words like `background music`, `subtle`, or `not too loud` to the Style Prompt so the music isn't too prominent.

> **Tip:** Use the word `loop-friendly` if your Instrumental needs to loop in a video or game.
