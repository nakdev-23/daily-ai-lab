# Bolt — สร้างเว็บแอปครบจบในเบราว์เซอร์ ⚡

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [support.bolt.new](https://support.bolt.new/) (โดย StackBlitz)

**Bolt** (bolt.new) คือเครื่องมือสร้างเว็บแอปด้วย AI จาก StackBlitz ที่ **รันทุกอย่างในเบราว์เซอร์** — ทั้งเขียนโค้ด ติดตั้งแพ็กเกจ รันเซิร์ฟเวอร์ และดูผลแบบสด โดยไม่ต้องตั้งค่าอะไรบนเครื่อง คุณบอกเป็นข้อความว่าอยากได้แอปแบบไหน Bolt ก็สร้างโปรเจกต์เต็มให้ แล้วดีพลอยขึ้นออนไลน์ได้ในคลิกเดียว

## 📖 คำศัพท์ที่ควรรู้

| คำศัพท์ | ความหมายง่าย ๆ |
|---|---|
| **WebContainer** | เทคโนโลยีรัน Node.js ในเบราว์เซอร์ (หัวใจของ Bolt) |
| **Prompt** | ข้อความสั่งให้ AI สร้าง/แก้แอป |
| **Tokens** | หน่วยการใช้งาน AI ที่ถูกหักตามปริมาณงาน |
| **Deploy** | เผยแพร่แอปขึ้นออนไลน์ (ผ่าน Netlify) |
| **Integrations** | บริการที่ต่อได้ เช่น Supabase, Figma, Expo |

## ⭐ จุดเด่น

- **ทำงานในเบราว์เซอร์ล้วน** — ไม่ต้องติดตั้งอะไรบนเครื่อง
- **เต็มสแตก** — frontend + backend + รันจริงในที่เดียว
- **ดีพลอยง่าย** — กดเผยแพร่ผ่าน Netlify ได้ทันที
- **ต่อบริการภายนอก** — Supabase (ฐานข้อมูล), Figma, Expo (มือถือ)
- **sync GitHub** เพื่อเก็บโค้ดและทำต่อ

## 🚀 เริ่มต้นใช้งาน

1. เข้า [bolt.new](https://bolt.new/) แล้วสมัคร/ล็อกอิน
2. พิมพ์บอกแอปที่อยากได้ เช่น "เว็บ to-do list ที่บันทึกงานได้"
3. ดู Bolt สร้างโค้ดและรันให้เห็นผลสด แล้วพิมพ์สั่งปรับแก้ต่อ
4. กด **Deploy** เพื่อนำขึ้นออนไลน์ หรือต่อ Supabase ถ้าต้องเก็บข้อมูล

> 💡 เคล็ดลับประหยัด Tokens: สั่งงานทีละก้อนชัด ๆ และใช้โหมดแก้เฉพาะจุดเมื่อปรับรายละเอียดเล็ก ๆ
