# Browser & Artifacts — verification you can actually trust 🌐

> Adapted from the official documentation at [antigravity.google](https://antigravity.google/)

Antigravity's standout feature is that the agent doesn't just write code — it can **test the work itself** through a built-in browser, then send you the evidence.

## 🌐 Browser (built-in)

- The agent opens the page it just wrote for **real testing**
- It clicks, fills out forms, and checks that things work
- When it hits a problem → it goes back and fixes the code itself

## 📦 Artifacts (the output the agent creates)

| Artifact | What it is |
|---|---|
| **Plan** | The steps the agent intends to take |
| **Screenshots** | Images of the screen during testing |
| **Report** | A summary of what was done and the results |
| **Work log** | A trail of commands/edits |

Artifacts let you **verify what the agent actually did**, instead of trusting it blindly.

## ▶️ In real use

1. Assign a task that has a web page to test
2. The agent writes the code + opens the browser to test + captures screenshots
3. Review the Artifacts (plan/screenshots/report) to confirm it's correct
4. Accept the work, or ask for more changes
