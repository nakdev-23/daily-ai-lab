# Stylize — ความสวยงามทางศิลปะ

> อ้างอิงหลัก: [Stylize](https://docs.midjourney.com/hc/en-us/articles/32196176868109-Stylize)

---

## Stylize คืออะไร

Parameter `--stylize` หรือ `--s` (ระดับสไตล์ — ความมากน้อยของความสวยงามและลักษณะศิลปะที่ Midjourney เพิ่มเข้าไปเอง) ควบคุมว่า Midjourney จะ "ตีความ" Prompt ของคุณในเชิงศิลปะมากแค่ไหน

- **ค่าต่ำ** = ตรงตาม Prompt มาก แต่ดูธรรมดา
- **ค่าสูง** = Midjourney เพิ่มความสวยงาม สี Composition และสไตล์เอง อาจห่างจาก Prompt

---

## ค่าและผลลัพธ์

| ค่า | ผลลัพธ์ |
|-----|---------|
| `--s 0` | ตรงตาม Prompt สูงสุด ดูเรียบง่าย |
| `--s 100` | ค่าเริ่มต้น สมดุล |
| `--s 250` | สวยงามขึ้น มีสไตล์ชัดเจนขึ้น |
| `--s 500` | สวยมาก Midjourney เพิ่มรายละเอียดศิลปะ |
| `--s 750` | Artistic มาก |
| `--s 1000` | สวยสุดขีด แต่ตีความ Prompt อิสระ |

---

## ตัวอย่างเปรียบเทียบ

**Prompt:** `a rose`

```
a rose --s 0        → ภาพดอกกุหลาบที่ตรงไปตรงมา เหมือนภาพในพจนานุกรม
a rose --s 100      → ดอกกุหลาบที่ดูดี
a rose --s 500      → ดอกกุหลาบสวยงาม แสง Shadow น่าสนใจ
a rose --s 1000     → ดอกกุหลาบในสไตล์ศิลปะ อาจเป็น Painting หรือ Illustration
```

---

## Stylize Default Settings

ในการตั้งค่า (Settings) คุณกำหนดค่า Stylize เริ่มต้นได้:
- **Stylize low** = 50
- **Stylize med** = 100 (ค่าเริ่มต้น)
- **Stylize high** = 250
- **Stylize very high** = 750

---

## เมื่อไรควรใช้ค่าสูง-ต่ำ

### ใช้ค่าต่ำ (0-100) เมื่อ:
- ต้องการภาพที่ตรงตาม Prompt อย่างแม่นยำ
- งาน Technical Illustration, Diagram
- ต้องการควบคุมผลลัพธ์เอง

### ใช้ค่าสูง (500-1000) เมื่อ:
- ต้องการภาพที่สวยงามโดยไม่ต้องระบุรายละเอียดมาก
- งาน Creative ที่ต้องการความน่าตื่นตาตื่นใจ
- ต้องการให้ Midjourney "ช่วยเสริม" ความสวยงาม

---

## Stylize กับ Raw Mode

- `--style raw` ปิด Stylize โดยสมบูรณ์ — ตรงตาม Prompt มากที่สุด
- ต่างจาก `--s 0` ตรงที่ Raw Mode ปิดการประมวลผลสไตล์ทั้งหมด

---

## เคล็ดลับ

1. **ลองค่า 250-500 ก่อน** — มักให้ผลดีที่สุดในหลายกรณี
2. **Prompt สั้น + Stylize สูง** = สร้างภาพสวยโดยไม่ต้องเขียน Prompt ยาว
3. **Prompt ละเอียด + Stylize ต่ำ** = ควบคุมผลลัพธ์ได้แม่นยำ

---

## สรุป

`--stylize` เป็น Parameter ที่ส่งผลต่อ "รสนิยม" ของภาพ ค่าต่ำให้ความแม่นยำ ค่าสูงให้ความสวยงามและความสร้างสรรค์ ทดลองเพื่อหาค่าที่เหมาะกับงานแต่ละประเภท
