## All of Grok's models

xAI divides its models into 4 main groups by type of work:

| Group | Main model | Good for |
|---|---|---|
| **Chat / Text** | grok-4.3 | Conversation, analysis, coding |
| **Coding Agent** | grok-build-0.1 | Writing/editing code agentically |
| **Voice** | Voice API | Voice interaction, STT/TTS |
| **Image & Video** | Imagine API | Creating/editing images and video |

## Details of each model

### Grok 4.3 (the main model)

Reference: [grok-4.3](https://docs.x.ai/developers/models/grok-4.3)

xAI's smartest and fastest model at present, good for almost every kind of work.

**Highlights:**
- A **1-million-token** context window (supports very long documents)
- Supports agentic tool calling (multi-step work)
- Very little hallucination (saying untrue things)
- Adjustable reasoning — choose deep thinking (reasoning) or fast (non-reasoning)
- Knowledge cutoff: **November 2024**

**Pricing:**
- Input: **$1.25 / 1M tokens**
- Cached input: **$0.20 / 1M tokens**
- Output: **$2.50 / 1M tokens**

**Model strings to use:**
```
grok-4.3           ← the latest stable version (recommended)
grok-4.3-latest    ← always the latest version
```

Reference: [grok-build-0.1](https://docs.x.ai/developers/models/grok-build-0.1)

## Model Aliases — how to reference models

xAI uses an alias system to make migration easier:

| Format | Meaning |
|---|---|
| `grok-4.3` | The latest stable version (auto-updates) |
| `grok-4.3-latest` | Always the latest version (may change) |
| `grok-4.20-0309-reasoning` | A specific version (doesn't change, good for production) |

> **Recommended:** Use `grok-4.3` or `grok-4.3-latest` for general use; use `grok-4.20-0309-reasoning` only when you need consistent results in production.

## Important notes about the models

- **No real-time data:** the model knows data only up to **November 2024**; if you need current data, enable Web Search or the X Search Tool
- **Image input:** supports JPEG/PNG only, up to **20MB** per image
- **Roles in chat:** you can freely alternate `system`, `user`, `assistant`, with no ordering restriction
- **logprobs:** not supported in grok-4.20 and newer

## Rate Limits

Reference: [Rate Limits](https://docs.x.ai/developers/rate-limits)

Rate limits are set by **RPM (Requests Per Minute)** and **TPM (Tokens Per Minute)**, divided by tier:

| Tier | Condition (cumulative spend since Jan 2026) |
|---|---|
| Tier 0 | $0 (default) |
| Tier 1 | $50 |
| Tier 2 | $250 |
| Tier 3 | $1,000 |
| Tier 4 | $5,000 |
| Enterprise | Contact xAI directly |

**Tokens counted toward TPM:**
- Prompt tokens
- Completion tokens
- Reasoning tokens
- Cached prompt tokens (still counted, but cheaper)

**When you exceed the rate limit:** the API returns HTTP `429 Too Many Requests`

**How to fix it:** use exponential backoff (wait and retry, gradually increasing the wait):

```python
import time
from openai import RateLimitError

def request_with_backoff(messages, max_retries=5):
    for attempt in range(max_retries):
        try:
            return client.responses.create(model="grok-4.3", input=messages)
        except RateLimitError:
            wait = 2 ** attempt  # wait 1, 2, 4, 8, 16 seconds
            time.sleep(wait)
    raise Exception("Out of retries")
```

**How to raise the limit:**
- Use it more → the tier upgrades itself
- Request a special increase via the [xAI Console](https://console.x.ai/team/default/rate-limits)
- Contact sales@x.ai for Enterprise
