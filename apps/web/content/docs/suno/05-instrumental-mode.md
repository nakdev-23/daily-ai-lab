# Instrumental Mode — สร้างเพลงบรรเลงไม่มีเสียงร้อง

**Instrumental** (เพลงบรรเลง — เพลงที่ไม่มีเสียงร้อง มีแต่เครื่องดนตรี) เป็นหนึ่งในฟีเจอร์ที่มีประโยชน์มากที่สุดของ Suno เพราะสามารถสร้างเพลงพื้นหลังสำหรับวิดีโอ Podcast งานนำเสนอ และอื่น ๆ ได้อย่างรวดเร็ว

---

## วิธีสร้างเพลงบรรเลงใน Simple Mode

1. ไปที่หน้า **Create**
2. พิมพ์คำอธิบายเพลงในช่อง Song Description
3. ติ๊กเครื่องหมายถูกที่ช่อง **"Instrumental"** (หรือ toggle ที่ด้านล่าง)
4. คลิก **"Create"**

ตัวอย่าง Prompt สำหรับเพลงบรรเลง:
```
calm lo-fi coffee shop jazz, piano and bass
```
```
epic cinematic orchestral, adventure theme, strings and brass
```
```
upbeat corporate background music, positive, professional
```

---

## วิธีสร้างเพลงบรรเลงใน Custom Mode

ใน Custom Mode ให้ใส่ **`[Instrumental]`** ในช่อง Lyrics เพื่อบอก AI ว่าไม่ต้องการเสียงร้อง

```
[Instrumental]
```

หรือระบุเครื่องดนตรีในแต่ละส่วน:

```
[Intro - Instrumental]
[Verse - Instrumental]
[Chorus - Build Up]
[Outro - Fade Out]
```

---

## ประเภทเพลงบรรเลงที่นิยม

### 1. Lo-fi Hip-Hop (โลไฟฮิปฮอป)

เพลงสไตล์ "เรียนหนังสือ" ฟังสบาย ๆ เหมาะสำหรับทำงานหรืออ่านหนังสือ

**Style Prompt:**
```
lo-fi hip-hop, chill beats, vinyl crackle, soft piano, slow jazz, 75 BPM, no vocals, study music
```

### 2. Cinematic Orchestral (ซีนีแมติกออร์เคสตรัล)

เพลงสไตล์ภาพยนตร์ เหมาะสำหรับวิดีโอ YouTube หรืองาน Presentation

**Style Prompt:**
```
epic cinematic orchestral, no vocals, strings, brass, timpani drums, heroic, building tension, Hans Zimmer style
```

### 3. Ambient / Meditation (แอมเบียนต์/เพลงสมาธิ)

เพลงเบา ๆ ไม่มีจังหวะชัด เหมาะสำหรับ Meditation หรือ Yoga

**Style Prompt:**
```
ambient meditation music, singing bowls, soft pads, nature sounds, no rhythm, peaceful, 432Hz
```

### 4. Corporate Background (เพลงพื้นหลังสำหรับธุรกิจ)

**Style Prompt:**
```
upbeat corporate background music, acoustic guitar, light percussion, positive, professional, no vocals
```

### 5. Jazz (แจ๊ส)

**Style Prompt:**
```
smooth jazz, saxophone, piano, upright bass, brushed drums, cocktail hour, evening vibes, no vocals
```

### 6. Gaming / Chiptune (เกมมิ่ง/ชิปทูน)

**Style Prompt:**
```
8-bit chiptune, video game music, upbeat adventure theme, NES style, no vocals
```

## การใช้ `[Instrumental]` Metatag อย่างชาญฉลาด

คุณสามารถผสมส่วนที่มีเสียงร้องกับส่วนบรรเลงในเพลงเดียวกันได้:

```
[Verse]
เนื้อเพลงท่อนแรก...

[Chorus]
เนื้อเพลงท่อนฮุก...

[Instrumental Break]

[Verse 2]
เนื้อเพลงท่อนสอง...

[Guitar Solo]

[Chorus]
เนื้อเพลงท่อนฮุก...

[Outro - Instrumental]
```

## Stem Extraction — แยกเสียงร้องออกจากเพลง

**Stem Extraction** (การแยก Stem — แยกไฟล์เสียงออกเป็นแทร็คแยก เช่น แยกเสียงร้องออกจากดนตรี) เป็นฟีเจอร์สำหรับผู้ใช้ Pro และ Premier ที่ทำให้คุณสามารถ:

- ดาวน์โหลดเสียงร้อง (Vocals Stem) แยกต่างหาก
- ดาวน์โหลดดนตรีพื้นหลัง (Instrumental Stem) แยกต่างหาก
- นำ Instrumental ไปใช้งานโดยไม่มีเสียงร้อง

### วิธีใช้ Stem Extraction

1. เปิดเพลงที่ต้องการ
2. คลิกเมนู (**...**) หรือปุ่ม Options
3. เลือก **"Stem Extraction"** (แยกแทร็ค)
4. เลือกว่าต้องการ Vocals หรือ Instrumental
5. ดาวน์โหลดไฟล์

> **หมายเหตุ:** Stem Extraction ใช้เครดิตเพิ่มเติม และมีแค่แผน Pro/Premier เท่านั้น

## เคล็ดลับพิเศษ

> **Tip:** ถ้าต้องการเพลงที่มีความยาวพอดี ให้ใช้ Extend (ขยาย) เพื่อเพิ่มความยาวตามต้องการ

> **Tip:** สำหรับเพลงพื้นหลัง ควรเพิ่มคำว่า `background music`, `subtle`, หรือ `not too loud` ใน Style Prompt เพื่อให้ดนตรีไม่โดดเด่นเกินไป

> **Tip:** ใช้คำว่า `loop-friendly` (เล่นวนซ้ำได้) หาก Instrumental ของคุณต้องเล่นวนซ้ำในวิดีโอหรือเกม
