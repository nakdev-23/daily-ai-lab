# ภาพรวมเว็บไซต์ Midjourney

> อ้างอิงหลัก: [Midjourney Website Overview](https://docs.midjourney.com/hc/en-us/articles/33329460426765-Website-Overview)

---

## หน้าหลักของเว็บไซต์

เมื่อล็อกอิน (เข้าสู่ระบบ) ที่ [midjourney.com](https://midjourney.com) คุณจะเห็น Navigation Bar (แถบเมนูนำทาง — แถบที่ช่วยให้คุณเดินทางไปยังส่วนต่างๆ ของเว็บ) ด้านซ้าย มีเมนูหลักดังนี้:

---

## เมนูหลัก

### Home
- หน้าแรกที่แสดงงานล่าสุดและแนะนำฟีเจอร์ใหม่
- มีลิงก์ด่วนไปยังส่วนต่างๆ ของเว็บ

### Explore
- **คือ**: แกลเลอรี่สาธารณะ (Public Gallery — คลังภาพที่เปิดให้ทุกคนดูได้) ของชุมชน Midjourney
- ดูภาพที่สร้างโดยผู้ใช้งานทั่วโลกแบบ Real-time
- **คลิกที่ภาพ** เพื่อดู Prompt ที่ใช้สร้าง — เป็นวิธีเรียนรู้ที่ดีที่สุด
- มีตัวกรอง (Filter — เงื่อนไขคัดเลือก) ตามสไตล์ เช่น Top, New, Hot
- สามารถ Like หรือ Save ภาพที่ชอบได้

### Create
- **พื้นที่สร้างภาพหลัก** ของคุณ
- มีช่องพิมพ์ Prompt (คำสั่งสร้างภาพ) ด้านบน
- แสดง Job Queue (คิวงาน — รายการงานที่กำลังรอสร้าง) ของคุณ
- ดูภาพที่เพิ่งสร้างเสร็จได้ทันที

### Archive
- **คลังภาพส่วนตัว** ของคุณ — เก็บทุกภาพที่เคยสร้าง
- ค้นหาภาพได้ด้วย Prompt หรือวันที่
- จัดเรียงตาม Created, Liked, หรือ Saved
- ดาวน์โหลด (Download — บันทึกไฟล์ลงเครื่อง) ภาพได้จากที่นี่

---

## ส่วนประกอบสำคัญในหน้า Create

### Prompt Bar (แถบพิมพ์คำสั่ง)
- อยู่ด้านบนของหน้า Create
- พิมพ์คำอธิบายภาพที่ต้องการเป็นภาษาอังกฤษ
- กด **Enter** หรือคลิกปุ่ม **Generate** เพื่อสร้างภาพ

### Settings Panel (แผงตั้งค่า)
- ปรับ Aspect Ratio (สัดส่วนภาพ — เช่น 16:9 หรือ 1:1)
- เลือก Model Version (เวอร์ชันโมเดล — รุ่น AI ที่ใช้สร้าง)
- ตั้งค่าต่างๆ เช่น Stylize, Weird, Raw Mode

### Image Grid (ตารางแสดงภาพ)
- แสดง 4 ภาพพร้อมกันหลังสร้างเสร็จ
- คลิกที่ภาพเพื่อขยายดูและเข้าถึงตัวเลือกต่างๆ

---

## ตัวเลือกหลังสร้างภาพ

เมื่อคลิกที่ภาพที่สร้างเสร็จแล้ว คุณจะเห็นตัวเลือก:

| ปุ่ม | ความหมาย |
|------|----------|
| **Upscale** | ขยายความละเอียดของภาพ |
| **Vary** | สร้างภาพแบบเดิมแต่ปรับรายละเอียดเล็กน้อย |
| **Zoom Out** | ขยายขอบเขตภาพออกไป |
| **Pan** | เลื่อนมุมมองภาพไปทิศทางต่างๆ |
| **Edit** | เปิด Editor แก้ไขภาพ |
| **Download** | บันทึกภาพลงเครื่อง |
| **Share** | แชร์ลิงก์ภาพ |

---

## การตั้งค่าบัญชี

คลิกรูปโปรไฟล์ที่มุมบนขวาเพื่อเข้าถึง:

- **Account Settings** — ตั้งค่าอีเมล รหัสผ่าน การแจ้งเตือน
- **Billing** — ดูแผนปัจจุบัน ประวัติการชำระเงิน
- **Subscription** — อัปเกรดหรือยกเลิกแผน
- **Visibility** — ตั้งค่าความเป็นส่วนตัวของงาน (Public/Private)

---

## Navigation ด้านซ้ายเพิ่มเติม

- **Folders** — โฟลเดอร์จัดหมวดหมู่ภาพ (ต้องสร้างเอง)
- **Liked** — ภาพที่คุณกดไลก์จาก Explore
- **Moodboards** — บอร์ดรวมภาพสำหรับวางแผนโปรเจกต์
- **Style Creator** — เครื่องมือสร้างสไตล์ส่วนตัว

---

## เคล็ดลับการใช้งานเว็บ

1. **Bookmark หน้า Create** — เข้าถึงง่าย ไม่ต้องเดินทางหลายหน้า
2. **ใช้ Explore เพื่อหา Inspiration** — คลิกภาพที่ชอบแล้วดู Prompt เพื่อนำมาดัดแปลง
3. **บันทึกใน Folders** — จัดระเบียบงานตั้งแต่เริ่ม จะหาง่ายขึ้นในอนาคต
4. **ตั้งค่า Visibility** — ถ้าต้องการความเป็นส่วนตัว ให้ตรวจสอบว่าแผนของคุณรองรับ Stealth Mode หรือไม่

---

## สรุป

เว็บไซต์ Midjourney มีการออกแบบที่ตรงไปตรงมา โดยหน้าหลักที่ใช้งานบ่อยที่สุดคือ **Create** (สร้างภาพ) และ **Archive** (เก็บงาน) ส่วน **Explore** เป็นแหล่งเรียนรู้ที่ดีที่สุดสำหรับมือใหม่
