# Pan — เลื่อนขยายภาพไปทิศทางต่างๆ

> อ้างอิงหลัก: [Pan](https://docs.midjourney.com/hc/en-us/articles/32570788043405-Pan)

---

## Pan คืออะไร

Pan (การเลื่อนขยาย — ขยายภาพออกไปในทิศทางเดียว ซ้าย ขวา บน หรือล่าง โดยเพิ่มเนื้อหาใหม่ในทิศทางนั้น) ต่างจาก Zoom Out ตรงที่ขยายแบบมีทิศทาง ไม่ใช่รอบทิศ

---

## ทิศทาง Pan

- **Pan Left** — ขยายไปทางซ้าย
- **Pan Right** — ขยายไปทางขวา
- **Pan Up** — ขยายขึ้นด้านบน
- **Pan Down** — ขยายลงด้านล่าง

---

## วิธีใช้

### บนเว็บไซต์
1. Upscale ภาพก่อน
2. เลือก **ลูกศร** ทิศทางที่ต้องการ (←↑→↓)
3. รอผลลัพธ์

### บน Discord
หลัง Upscale:
- กดปุ่มลูกศรที่ปรากฏใต้ภาพ

---

## ตัวอย่างการใช้งาน

### สร้าง Panoramic (ภาพพาโนรามา — ภาพกว้างมาก มักเป็นทิวทัศน์)
```
ภาพเดิม: ทิวทัศน์ภูเขา 1:1
Pan Left → Pan Right: ได้ภาพ Panoramic กว้างมาก
```

### เพิ่มองค์ประกอบข้างๆ
```
ภาพเดิม: คนยืนในสวน
Pan Right: อาจได้เห็นส่วนอื่นของสวนทางขวา
```

### สร้าง Vertical Story
```
ภาพเดิม: เมืองมุมกว้าง
Pan Up: ขยายขึ้นไปเห็นท้องฟ้าหรืออาคารสูง
Pan Down: ขยายลงมาเห็นถนนหรือรายละเอียดล่าง
```

---

## Pan + Prompt

ใน Pan Mode คุณสามารถกำหนด Prompt สำหรับพื้นที่ใหม่:
1. คลิก Pan แล้วดูช่อง Prompt
2. เพิ่มคำอธิบายสำหรับพื้นที่ที่ขยายออกไป

---

## Pan ซ้ำหลายครั้ง

คุณสามารถ Pan ซ้ำได้เพื่อสร้างภาพที่กว้างมาก:
```
Pan Right → Pan Right → Pan Right
```
→ ได้ภาพแนวนอนที่ยาวมาก เหมาะสำหรับ Banner

---

## ข้อควรรู้เกี่ยวกับ Pan

- **Pan ไม่สมมาตร** — ด้านที่ Pan อาจมีรายละเอียดต่างกัน
- **รอยต่อ** — บางครั้งอาจเห็นรอยต่อระหว่างส่วนเดิมและส่วนที่เพิ่มเข้ามา
- **ลองหลายครั้ง** — แต่ละครั้งที่ Pan จะได้ผลต่างกัน

---

## เปรียบเทียบ Pan กับ Zoom Out

| | Pan | Zoom Out |
|--|-----|---------|
| ขยายทิศทาง | 1 ทิศ | รอบทิศ |
| ภาพเดิม | ยังอยู่ที่เดิม (แค่ขยับ) | ยังอยู่ตรงกลาง (เล็กลง) |
| เหมาะสำหรับ | Panoramic, Banner | ดูบริบทกว้างขึ้น |

---

## ตัวอย่าง Use Case จริง

### สร้าง Banner โฆษณา
```
ภาพสินค้า 1:1 → Pan Right 2 ครั้ง → ได้ภาพแนวนอนกว้างสำหรับ Banner
```

### สร้าง Cover Art
```
ภาพ Character 1:1 → Pan Down → เห็นร่างกายส่วนล่าง
```

### Landscape Panoramic
```
ภาพทิวทัศน์ 1:1 → Pan Left → Pan Right → ได้ภาพ 3:1 แบบ Panoramic
```

---

## สรุป

Pan เหมาะสำหรับสร้างภาพ Panoramic, Widescreen หรือขยายภาพในทิศทางเฉพาะ ทำงานได้ดีที่สุดหลังจาก Upscale แล้ว สามารถ Pan ซ้ำหลายครั้งเพื่อสร้างภาพที่ยาวหรือสูงมากขึ้นเรื่อยๆ
