# HeyGen — วิดีโออวตาร AI ที่พูดแทนคุณได้ 🎬

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [docs.heygen.com](https://docs.heygen.com/)

**HeyGen** คือแพลตฟอร์มสร้างวิดีโอด้วย **อวตาร AI (avatar)** — พิมพ์บทพูด แล้วให้ตัวละคร AI พูดออกมาเหมือนคนจริง โดยไม่ต้องตั้งกล้องถ่ายเอง เหมาะกับทำวิดีโอสอน, การตลาด, พรีเซนต์, หรือคอนเทนต์หลายภาษา รองรับเสียงพูดหลายสิบภาษ รวมถึงภาษาไทย

## 📖 คำศัพท์ที่ควรรู้

| คำศัพท์ | ความหมายง่าย ๆ |
|---|---|
| **Avatar** | ตัวละคร AI ที่พูดและขยับปากตามบท |
| **Instant Avatar** | สร้างอวตารจากการอัดวิดีโอตัวเองสั้น ๆ |
| **Photo Avatar** | สร้างอวตารจากรูปภาพ |
| **Script** | บทพูดที่อวตารจะพูด |
| **Template** | แม่แบบวิดีโอสำเร็จรูปให้ปรับใช้ |
| **Video Translation** | แปล+พากย์วิดีโอเป็นภาษาอื่น |

## ⭐ ความสามารถหลัก (ตามเมนู official docs)

- **AI Avatars** — เลือกอวตารสำเร็จรูป หรือสร้างของตัวเอง
- **สร้างวิดีโอจากบท** — พิมพ์ข้อความ อวตารพูดให้
- **Templates** — เริ่มจากแม่แบบสวย ๆ ได้เร็ว
- **Video Translation** — ทำคลิปเดียวให้พูดได้หลายภาษา
- **Interactive / Streaming Avatar** — อวตารโต้ตอบแบบเรียลไทม์
- **API** — สร้างวิดีโออัตโนมัติจากโค้ด

## 🚀 เริ่มต้นใช้งาน

1. สมัครบัญชีที่ [heygen.com](https://www.heygen.com/)
2. เลือก **Create Video** → เลือกอวตารและเสียง
3. พิมพ์บทพูด (ไทย/อังกฤษ) แล้วกดสร้าง
4. รอเรนเดอร์ แล้วดาวน์โหลด/แชร์วิดีโอ
