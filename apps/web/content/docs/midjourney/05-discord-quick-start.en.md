# Getting started with Midjourney on Discord

> Main reference: [Discord Quick Start](https://docs.midjourney.com/hc/en-us/articles/32631709682573-Discord-Quick-Start)

---

## What is Discord

Discord is an Application for online chat, popular among gamers and Tech communities. Midjourney still supports use through Discord, which has a very large community.

---

## Getting-started steps

### Step 1 — Install Discord
1. Download Discord at [discord.com](https://discord.com)
2. Sign up for Discord free (no payment needed)
3. Log in

### Step 2 — Join the Midjourney Server
1. Go to [midjourney.com](https://midjourney.com)
2. Click **"Join the Beta"** or the Discord link
3. Press **"Accept Invite"** to join the Server (Midjourney's Discord server)

Or, search for Midjourney in Discord Discover and join the Server directly.

### Step 3 — Enter the newbies room
After joining the Server:
1. Look for the **"NEWCOMER ROOMS"** category in the left bar
2. Choose the room **#newbies-1** or **#newbies-2** (there are several rooms)
3. These rooms are designed specifically for beginners

---

## Basic commands

### /imagine — create an image
The main command used to create images:

```
/imagine prompt: a beautiful sunset over mountains, oil painting style
```

**How to use:**
1. Type `/imagine` in the chat box
2. Discord shows Autocomplete to choose
3. Type the Prompt after `prompt:`
4. Press Enter

### /info — view account information
```
/info
```
Shows: the plan used, remaining GPU Time, the number of images created

### /help — view help
```
/help
```
Shows the list of commands and links to the documentation

---

## Understanding the result in Discord

When finished, the Midjourney Bot (an automated program running in Discord) sends a reply with 4 images.

### Buttons under the image

**Top row — Upscale:**
- **U1 U2 U3 U4** — Upscale image 1, 2, 3, 4

**Bottom row — Variations:**
- **V1 V2 V3 V4** — create a new set of images similar to image 1, 2, 3, 4

**The 🔄 button (refresh):**
- create an entirely new set of images from the same Prompt

## Use in Direct Messages

If you don't want your work seen in a public room:
1. Find the **Midjourney Bot** in the Server's Users bar
2. Click the Bot and choose **"Message"**
3. Send the `/imagine` command in the DM (Direct Message) room

> **Note:** Using DM still counts GPU Time as usual, but the work won't appear in public rooms.

---

## Add the Midjourney Bot to your Server

If you want to use Midjourney in a private Server:
1. Go to [docs.midjourney.com](https://docs.midjourney.com) and see how to add the Bot
2. Or go to the Midjourney Server → click the Midjourney Bot → choose "Add to Server"
3. Choose your Server → confirm the Permissions

## Tips

1. **Use the newbies room** — don't be shy, everyone starts here
2. **Look at others' Prompts** — click an image in the Server to see the Prompt used
3. **Use DM** — if you want more privacy
4. **Add the Bot to a private Server** — more convenient than using the central Server

---

## Summary

Midjourney on Discord mainly uses the `/imagine` command. Add the Bot to your Server → type `/imagine prompt: [description]` → wait for the result → press U to Upscale or V to create a new variation. Easy, with plenty of community help.
