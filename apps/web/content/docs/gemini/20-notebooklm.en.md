# NotebookLM — AI for research and summarizing your own documents

**NotebookLM** is Google's AI (artificial intelligence) tool designed specifically for research and learning. The key difference from regular Gemini is that NotebookLM answers questions **from your documents only**, not from general knowledge, making the information reliable and verifiable.

---

## What is NotebookLM?

NotebookLM works as **"an AI that reads your documents"** — you upload various sources (PDFs, websites, YouTube videos, etc.) and the AI helps you:
- Summarize content
- Answer questions citing the documents
- Find connections between data
- Create various learning materials

---

## Supported source types

| Type | Details |
|---|---|
| PDF | Documents, articles, reports, books |
| Google Docs | Documents from your Drive |
| Google Slides | Presentation slides |
| Websites (URL) | Paste a link to the web page you want |
| YouTube Video | Analyze video content via the transcript (the text from the audio) |
| Audio files | Audio files (MP3, WAV) |
| Text files | Plain text (.txt) |
| Markdown | .md files |
| Copied text | Paste text directly |

**Each notebook supports up to 50 sources**, totaling up to 25 million words.

---

## Main features

### 1. Chat with your sources
- Ask questions and the AI answers with precise citations
- Click a citation to see the source in the original document
- No hallucinating (making up information that isn't real) because it answers only from the documents you provide

### 2. Audio Overview (automatic AI podcast)
- Create a podcast conversation between "two hosts" explaining the content from your sources
- Listen to a content summary on the go
- Customize the focus to emphasize a certain topic

### 3. Video Overview (a video content summary)
- Create a video summarizing the content from the documents

### 4. Mind Map
- Turn content into a mind map (an overview of interconnected ideas)
- Helps you see the relationships between ideas

### 5. Flashcards and Quiz
- Create flashcards from key content
- Test your understanding with an automatic quiz
- Good for studying and reviewing

### 6. Study Guide
- Summarize key topics, terms, and main concepts
- Create an outline of all the content

### 7. Infographic
- Turn data into an infographic (an image combining data and graphics)

### 8. Slide Deck
- Create a presentation deck from the documents' content

## How to get started with NotebookLM

### Step 1: Access NotebookLM
- Go to [notebooklm.google.com](https://notebooklm.google.com)
- Or access it from Gemini → click **NotebookLM** in the menu
- Sign in with a Google account

### Step 2: Create a new notebook
- Click **"New notebook"**
- Name the notebook (e.g. "Thesis research", "Marketing book")

### Step 3: Add a source
- Click **"Add source"**
- Choose the type: upload a file, paste a URL, connect Google Drive, or paste text
- Wait for the AI to process the source (may take 1–2 minutes)

### Step 4: Start chatting
- Type a question in the chat box
- E.g. "Summarize all the key points" or "Explain the difference between X and Y"

## Best use cases

### Students
- Upload textbooks, lecturer slides, and articles
- Create flashcards to review before exams
- Ask questions to understand the content more deeply

### Researchers
- Gather several research papers in one notebook
- Find connections between studies
- Create a literature review (a summary of related research)

### Business people
- Analyze reports, market data, and key documents
- Summarize contracts or long documents
- Create executive summaries

### Content Creators
- Research a topic from many sources at once
- Create an audio overview for a podcast
- Organize ideas before writing

## NotebookLM vs regular Gemini

| | Gemini | NotebookLM |
|---|---|---|
| Data used to answer | General knowledge + web | Only the sources you provide |
| Citations | Uncertain | Clear citations |
| Good for | General questions | Analyzing specific documents |
| Creating learning materials | Not directly supported | Audio, Flashcard, Quiz |
| Accuracy | May hallucinate (make up answers) | Higher (from real sources) |

---

## Privacy and security

- **Your sources are private** — not shared with others by default
- **Sharing option** — you can share a notebook publicly if you want
- **Data isn't used to train AI** — content in the notebook isn't used to train the model (the AI brain)

---

## Usage tips

- **Add high-quality sources** — the better the source, the more accurate the answer
- **Ask specifically** — "Summarize chapter 3" is better than "Summarize everything"
- **Use Audio Overview on the go** — listen to a summary instead of reading
- **Create separate notebooks per project** — don't combine everything in one place
- **Always click the citation** — verify the source before using it
