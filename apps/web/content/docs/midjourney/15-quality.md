# Quality — ปรับคุณภาพการ Render

> อ้างอิงหลัก: [Quality](https://docs.midjourney.com/hc/en-us/articles/32176522101773-Quality)

---

## Quality คืออะไร

Parameter `--quality` หรือ `--q` (คุณภาพ — ระดับเวลาและทรัพยากรที่ใช้ในการสร้างภาพ) ควบคุมว่า Midjourney จะใช้เวลา Render (ประมวลผลสร้างภาพ) มากน้อยแค่ไหน

ค่าสูง = ใช้เวลาและ GPU Time มากขึ้น แต่อาจได้รายละเอียดดีขึ้น
ค่าต่ำ = เร็วกว่า ประหยัด GPU Time แต่รายละเอียดน้อยกว่า

---

## ค่าที่ใช้ได้

| ค่า | ความหมาย | GPU Time ที่ใช้ |
|-----|---------|----------------|
| `--quality 0.25` | เร็วมาก คุณภาพน้อย | น้อยมาก |
| `--quality 0.5` | เร็ว | ครึ่งหนึ่งของค่าปกติ |
| `--quality 1` | ค่าเริ่มต้น — สมดุล | ปกติ |

---

## เมื่อไรควรใช้ค่าต่ำ

- **ทดสอบ Prompt** — ก่อนสร้างภาพจริง ทดสอบด้วย `--quality 0.25` เพื่อประหยัด GPU Time
- **Draft Mode** — ร่างภาพอย่างรวดเร็ว
- **Permutations จำนวนมาก** — เมื่อต้องสร้างหลายภาพพร้อมกัน

**ตัวอย่าง:**
```
a forest landscape --quality 0.25
```
→ ได้ภาพเร็ว ใช้ทดสอบทิศทาง Prompt ก่อน

---

## เมื่อไรใช้ค่าปกติ (1.0)

- สร้างภาพจริงที่ต้องการคุณภาพดี
- งาน Final (ขั้นสุดท้าย) ที่นำไปใช้จริง

---

## หมายเหตุสำคัญ

- ใน Midjourney เวอร์ชัน 5 ขึ้นไป ค่าสูงกว่า 1 ไม่ได้รับรองว่าดีกว่าเสมอ
- การ Upscale หลังสร้างจะเพิ่มรายละเอียดได้มากกว่าการเพิ่ม Quality เพียงอย่างเดียว

---

## ตัวอย่าง Workflow ที่ใช้ Quality

### Workflow ประหยัด GPU Time
```
ขั้น 1: ทดสอบ Prompt ด้วย --quality 0.25 (เร็วมาก)
ขั้น 2: เมื่อ Prompt ดีแล้ว ลองด้วย --quality 0.5
ขั้น 3: Final ด้วย --quality 1 และ Upscale
```

### ตัวอย่างคำสั่ง

**ทดสอบเร็ว:**
```
a mountain landscape --q 0.25 --chaos 80
```

**เปรียบเทียบ:**
```
a mountain landscape --q 0.25
a mountain landscape --q 1
```

---

## Quality กับ Model Version

ใน Midjourney V6 ขึ้นไป ค่า `--quality` มีผลต่อรายละเอียดที่ AI ใช้เวลาสร้าง อย่างไรก็ตาม ความแตกต่างระหว่าง 0.5 และ 1.0 อาจไม่ชัดเจนเสมอในทุก Prompt

---

## เคล็ดลับประหยัด GPU Time ด้วย Quality

1. **ใช้ Draft Mode** บนเว็บ แทน `--q 0.25` — ผลคล้ายกัน แต่สะดวกกว่า
2. **Relax + Quality 0.5** สำหรับงานทดสอบจำนวนมาก
3. **Turbo + Quality 1** สำหรับงาน Final ที่ต้องการเร็วและดี

---

## สรุป

ใช้ `--quality 0.25` หรือ `--q 0.25` เมื่อต้องการทดสอบ Prompt อย่างรวดเร็วและประหยัด GPU Time ใช้ค่า `1` (ค่าเริ่มต้น) เมื่อต้องการภาพคุณภาพดีสำหรับงานจริง สำหรับ Workflow ที่มีประสิทธิภาพ ทดสอบด้วยค่าต่ำก่อนแล้วสร้างจริงด้วยค่าสูง
