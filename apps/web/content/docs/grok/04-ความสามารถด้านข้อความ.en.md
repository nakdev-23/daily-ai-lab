## Text Generation

Reference: [Text Generation](https://docs.x.ai/developers/model-capabilities/text/generate-text)

### What is this topic?
Text Generation is Grok's most basic ability — take a prompt and generate a text response. It supports both single-turn and multi-turn conversation.

### How to use it

**Python (xAI SDK):**
```python
import os
from xai_sdk import Client
from xai_sdk.chat import user, system

client = Client(api_key=os.getenv("XAI_API_KEY"))

chat = client.chat.create(model="grok-4.3")
chat.append(system("You are a helpful AI assistant"))
chat.append(user("Explain what Machine Learning is"))

response = chat.sample()
print(response.content)
```

**Python (OpenAI SDK):**
```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_XAI_API_KEY",
    base_url="https://api.x.ai/v1",
)

response = client.responses.create(
    model="grok-4.3",
    input=[
        {"role": "system", "content": "You are an AI assistant"},
        {"role": "user", "content": "Explain what Machine Learning is"},
    ],
)

print(response.output_text)
```

### Multi-turn Chat

```python
chat = client.chat.create(model="grok-4.3")
chat.append(system("You are a Thai teacher"))
chat.append(user("Hello"))

response1 = chat.sample()
chat.append(response1)  # add the first answer to the context

chat.append(user("Can you teach me about writing good sentences?"))
response2 = chat.sample()
print(response2.content)
```

### Important parameters

| Parameter | Meaning | Default |
|---|---|---|
| `model` | The model name | Required |
| `temperature` | Creativity (0=fixed, 2=very creative) | 1.0 |
| `max_tokens` | Max tokens to generate | Depends on the model |
| `top_p` | Nucleus sampling | 1.0 |

## Reasoning — deep thinking

Reference: [Reasoning](https://docs.x.ai/developers/model-capabilities/text/reasoning)

### What is this topic?
Reasoning is a mode where Grok "thinks before answering," making it more accurate for complex problems like math, hard coding, or multi-step analysis.

### reasoning_effort — adjust the level of thinking

Grok 4.3 supports adjusting the reasoning level:

| Value | Meaning | Good for |
|---|---|---|
| `"low"` | Thinks little, fast, cheap | Easy work |
| `"medium"` | Balanced | General work |
| `"high"` | Thinks deeply, slow, but accurate | Complex work |
| `"none"` | Turns off reasoning, uses non-reasoning mode | Work needing speed |

**Example:**
```python
response = client.responses.create(
    model="grok-4.3",
    input=[{"role": "user", "content": "Solve the equation: x² + 5x + 6 = 0"}],
    reasoning={"effort": "high"},  # think deeply
)
print(response.output_text)
```

### Cautions
- Reasoning tokens have a cost (counted as normal tokens)
- Use `reasoning_effort: "none"` when you want non-reasoning mode and need speed

## Structured Outputs

Reference: [Structured Outputs](https://docs.x.ai/developers/model-capabilities/text/structured-outputs)

### What is this topic?
Instead of Grok answering in plain text, you can force it to answer as JSON per a predefined structure, good for apps that process the result further.

### What is it used for?
- Extracting data from text
- Creating JSON for a database
- Analyzing and separating points
- Creating structured data for an app

### How to use it (Python + Pydantic)

```python
from pydantic import BaseModel
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_XAI_API_KEY",
    base_url="https://api.x.ai/v1",
)

class ProductInfo(BaseModel):
    name: str
    price: float
    category: str
    in_stock: bool

response = client.beta.chat.completions.parse(
    model="grok-4.3",
    messages=[
        {"role": "user", "content": "Extract the product info: iPhone 16 Pro, price 45,900 baht, phone category, in stock"}
    ],
    response_format=ProductInfo,
)

product = response.choices[0].message.parsed
print(f"Name: {product.name}")
print(f"Price: {product.price}")
```

### Example output
```json
{
  "name": "iPhone 16 Pro",
  "price": 45900.0,
  "category": "phone",
  "in_stock": true
}
```

## Streaming — receive results in real time

Reference: [Streaming](https://docs.x.ai/developers/model-capabilities/text/streaming)

### What is this topic?
Instead of waiting for Grok to finish the whole text and send it at once, streaming sends the text piece by piece in real time, so the user sees the answer flow out like live typing.

### What is it used for?
- Creating a lively experience
- Reducing wait time for long answers
- A chatbot that feels natural

### How to use it

**Python (xAI SDK):**
```python
chat = client.chat.create(model="grok-4.3")
chat.append(user("Write a long article about AI"))

for response, chunk in chat.stream():
    if chunk.content:
        print(chunk.content, end="", flush=True)  # show piece by piece
```

**Python (OpenAI SDK):**
```python
stream = client.responses.create(
    model="grok-4.3",
    input=[{"role": "user", "content": "Write an article about AI"}],
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="", flush=True)
```

## Multi Agent — a multi-agent system

Reference: [Multi Agent](https://docs.x.ai/developers/model-capabilities/text/multi-agent)

### What is this topic?
Multi Agent means using several Groks at once, each doing its own work and passing results on, good for complex, multi-step work.

### What is it used for?
- Research that needs separate searching and summarizing
- A pipeline with several steps
- An orchestrator agent that directs sub-agents

### What to know
- You can use the same xAI API key in every agent
- Each agent has its own context
- You can pass a result from one agent to another

## Completions API (Legacy)

Reference: [Chat Completions](https://docs.x.ai/developers/model-capabilities/legacy/chat-completions)

The **Completions API** is the older API, still usable. The **Responses API** is the new recommended one to use instead.

| | Completions API (Legacy) | Responses API (recommended) |
|---|---|---|
| Format | `client.chat.completions.create()` | `client.responses.create()` |
| Tools | Partial support | Full support |
| Streaming | Supported | Supported |
| Citations | Not supported | Supported |

---

## Important notes about Chat Models

- **Role order:** no restriction; you can freely alternate `system`, `user`, `assistant`
- **logprobs:** not supported in grok-4.20 and newer
- **Context Window:** Grok 4.3 supports **1 million tokens**, enough for very long documents
