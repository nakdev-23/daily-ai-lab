# Weird — เพิ่มความแปลกประหลาด

> อ้างอิงหลัก: [Weird](https://docs.midjourney.com/hc/en-us/articles/32390120435085-Weird)

---

## Weird คืออะไร

Parameter `--weird` หรือ `--w` (ความแปลกประหลาด — ระดับของความไม่ธรรมดา ไม่คาดคิด ที่ Midjourney เพิ่มเข้าไปในภาพ) ทำให้ภาพมีองค์ประกอบที่แปลก ไม่ปกติ หรือ Surreal (เหนือจริง — มีความรู้สึกเหมือนความฝัน ไม่สมจริง)

---

## ค่าและผลลัพธ์

```
--weird 0       → ปกติ ไม่มีความแปลก (ค่าเริ่มต้น)
--weird 250     → แปลกเล็กน้อย น่าสนใจขึ้น
--weird 500     → แปลกปานกลาง มีองค์ประกอบไม่คาดคิด
--weird 1000    → แปลกมาก Surrealist
--weird 2000    → แปลกมากๆ
--weird 3000    → แปลกสูงสุด อาจยากต่อการคาดเดา
```

**ย่อได้เป็น `--w`:**
```
a garden --w 500
```

---

## ตัวอย่างการใช้งาน

### เพิ่มความน่าสนใจ
```
a portrait of a woman --weird 250
```
→ อาจได้ภาพที่มีรายละเอียดแปลกตาเล็กน้อย เช่น สไตล์การวาดที่ไม่ปกติ

### Surreal Art
```
a city at night --weird 1000
```
→ อาจได้ภาพเมืองที่มีองค์ประกอบ Surreal เช่น ตึกที่ไหลเหมือนน้ำ ท้องฟ้าที่ผิดปกติ

### สำหรับงาน Creative
```
abstract nature concept --weird 2000
```
→ ได้ภาพที่สร้างสรรค์อย่างสุดขีด เหมาะสำหรับ Art Print หรือ Cover Art

---

## Weird กับ Stylize

| Parameter | ผล |
|-----------|-----|
| `--stylize สูง` | ภาพสวยขึ้น ดูดีขึ้น |
| `--weird สูง` | ภาพแปลกขึ้น ไม่ธรรมดาขึ้น |
| `--stylize 750 --weird 500` | ภาพที่สวยและแปลกในเวลาเดียวกัน |

---

## เมื่อไรควรใช้

- งาน Concept Art ที่ต้องการความแปลกใหม่
- Poster Art ที่ต้องการดึงดูดสายตา
- การสำรวจ Aesthetic ที่ไม่ธรรมดา
- เมื่อต้องการ Inspiration จากมุมมองที่ไม่คาดคิด

---

## Weird กับ Chaos — ต่างกันอย่างไร

| Parameter | ส่งผลต่อ |
|-----------|---------|
| `--chaos` | ความหลากหลายระหว่าง 4 ภาพในชุดเดียวกัน |
| `--weird` | ความแปลกประหลาดของภาพแต่ละรูป |

ใช้ทั้งคู่พร้อมกันได้:
```
a portrait --chaos 50 --weird 500
```
→ 4 ภาพที่มีความหลากหลาย และแต่ละรูปแปลกในแบบของตัวเอง

---

## Weird ในระดับต่างๆ พร้อมตัวอย่าง

### --weird 0 (ปกติ)
```
a forest landscape --weird 0
```
→ ป่าที่ดูสมจริงและปกติ

### --weird 500 (แปลกปานกลาง)
```
a forest landscape --weird 500
```
→ ป่าที่มีบรรยากาศแปลกตา อาจมีแสงไม่ปกติ หรือต้นไม้รูปร่างแปลกๆ

### --weird 2000 (แปลกมาก)
```
a forest landscape --weird 2000
```
→ ป่าที่อาจมีองค์ประกอบ Surreal เช่น ต้นไม้ที่เป็นผลึก หรือสีที่ไม่ธรรมชาติ

---

## Weird กับการสร้างงาน Art

Weird เหมาะสำหรับ:

### Experimental Art (งานทดลองทางศิลปะ)
```
abstract composition --weird 1500 --stylize 800
```

### Dreamlike Imagery (ภาพแบบความฝัน)
```
a person walking through a door --weird 1000
```
→ บรรยากาศคล้ายความฝัน มีองค์ประกอบที่ไม่คาดคิด

### Album Art / Poster
```
ethereal figure in cosmic space --weird 1200 --stylize 600
```
→ งาน Art สำหรับปกอัลบั้มหรือโปสเตอร์ที่ดึงดูดสายตา

---

## เคล็ดลับการใช้ Weird อย่างมีประสิทธิภาพ

1. **ผสมกับ Stylize สูง** — `--weird 500 --stylize 750` ให้ภาพแปลกที่ยังสวยงาม
2. **ใช้ Prompt เรียบง่าย** — Prompt สั้นกับ Weird สูงให้ผลที่น่าประหลาดใจได้ดี
3. **สำรวจก่อนนำไปใช้จริง** — ทดสอบค่าต่างๆ ก่อนเลือกค่าที่เหมาะกับงาน
4. **บันทึก Seed** — ถ้าได้ภาพแปลกที่ถูกใจ บันทึก Seed ไว้ทันที

---

## สรุป

`--weird` เป็น Parameter ที่ให้คุณผลักขอบเขตความคิดสร้างสรรค์ ใช้ค่าต่ำ (250-500) เพื่อเพิ่มความน่าสนใจโดยไม่แปลกเกินไป ค่ากลาง (500-1000) สำหรับงาน Artistic ที่มีเอกลักษณ์ และค่าสูง (1000+) เมื่อต้องการ Surreal Art ที่ไม่ธรรมดาจริงๆ ผสมกับ `--stylize` สูงเพื่อให้ได้ทั้งความแปลกและความสวยงาม
