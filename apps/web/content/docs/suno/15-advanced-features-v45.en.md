# Advanced features v4.5 — Creative Sliders, Song Editor, Inspire

Suno v4.5, also called the **"Artist Update,"** comes with a set of new features that give users more detailed and creative control over the song-creation process.

---

## Creative Sliders

**Creative Sliders** are controls that let you adjust how "unusual" and "intense" the AI-created song is.

### The two sliders

#### 1. Creativity

```
Conservative ◄──────────────────────────► Experimental

Conservative = the song looks normal, predictable, close to the specified genre
Experimental = the song is unusual, surprising, may mix unexpected Genres
```

#### 2. Intensity

```
Subtle ◄──────────────────────────────► Intense

Subtle = quieter sound, relaxed, no intensity
Intense = full-power sound, intense, high Dynamics
```

### When to use each level

| Goal | Creativity | Intensity |
|--------|-----------|---------|
| Lullaby | Conservative | Subtle |
| Standard Pop song | medium | medium |
| Workout song | Conservative | Intense |
| Experiment with a new style | Experimental | medium |
| Avant-garde song | Experimental | Intense |

## Creative Prompt Boosting

**Creative Prompt Boosting** in v4.5 automatically helps the AI understand the Style Prompt better.

When Boosting is on, Suno:
- Interprets vague Prompts more clearly
- Adds missing details
- Makes the result match the intent more closely

### How to enable Creative Prompt Boosting

1. On the Create Page, click the ⚡ icon or **"Boost"**
2. Toggle it "On"
3. Type the Style Prompt as usual — Suno handles the rest

## Song Editor

**Song Editor** in v4.5 lets you edit various parts of a song directly, without recreating it entirely.

### Song Editor features

| Feature | Usage |
|--------|---------|
| **Edit Lyrics** | change the lyrics in the selected section |
| **Change Style** | change the music style for that section |
| **Replace Section** | recreate that section completely |
| **Adjust Timing** | adjust the length of each section |

### How to use the Song Editor

1. Open the song you want to edit
2. Click **"Edit"** or **"Song Editor"**
3. Select the part of the song you want to edit on the Timeline
4. Make the edits as desired
5. Click **"Generate"** or **"Apply"**

## Stem Extraction

**Stem Extraction** (separating the audio file into parts, such as separate vocals and separate music) is an advanced feature for Pro/Premier.

### Stem types you can download

| Stem | Meaning |
|------|---------|
| **Vocals** | only the vocals |
| **Instrumental** | the song with no vocals |
| **Drums** | only the drums |
| **Bass** | only the bass |
| **Other** | the remaining instruments |

> **Note:** Not all Stems will be available; it depends on the song.

### How to use Stem Extraction

1. Open the song you want
2. Click **"..."** and choose **"Stems"** or **"Stem Extraction"**
3. Choose the Stem you want
4. Wait for processing (may take 1–3 minutes)
5. Download the Stem you want

### Benefits of Stem Extraction

- Use the **Vocal Stem** for Karaoke
- Use the **Instrumental Stem** as background music
- Use the **Drum Stem** in your own Mix
- Send the files to a Mastering Engineer to work on separately

## Inspire

**Inspire** is a feature that helps generate a Prompt for you when you don't know what song to create.

### How to use Inspire

1. Click **"Inspire"** on the Create page
2. Suno generates 3–5 example Prompts
3. Choose a Prompt you like, or tweak it before using
4. Click Create

### Example Inspire results

```
"Dreamy synthwave ballad about neon-lit rainy streets"
```
```
"Cheerful bossa nova for a lazy Sunday afternoon"
```
```
"Intense electronic battle theme for a video game boss fight"
```

## Add Vocals

**Add Vocals** in v4.5 lets you add vocals into an existing Instrumental song.

### How to use Add Vocals

1. Open the Instrumental song you want
2. Click **"Add Vocals"**
3. Specify:
   - **Lyrics** for the part you want sung
   - **Vocal Style** for the singer's voice you want
4. Click Generate

## Detailed Style Instructions

In v4.5 you can use more complex and detailed **Detailed Style Instructions** in the Style field.

### Example of using detailed Style Instructions

The plain way:
```
pop rock
```

The detailed v4.5 way:
```
indie pop rock with jangly guitar, warm analog synths, driving rhythm section,
intimate vocals with subtle reverb, bridge drops to half-time with atmospheric pads,
chorus explodes with layered harmonies, bridge brings back full energy for final chorus
```

### Elements you can specify in a Style command

```
Instruments: guitar, piano, synth, drums, bass, violin, cello, flute...
Sound character: warm, crisp, bright, dark, lo-fi, hi-fi, vintage, modern...
Mix techniques: reverb, chorus effect, distortion, compression...
Structure: verse builds to chorus, half-time bridge, dramatic drop...
Era reference: 80s, 90s, 2000s, modern...
Tempo: slow at 70 BPM, driving at 128 BPM...
```

## Personas (song personalities)

**Personas** let you save the "DNA" of a song you like to reuse.

### How to create a Persona

1. Open the song whose Vibe you want to save
2. Click **"Save as Persona"** or **"Create Persona"**
3. Name the Persona, e.g. "Dark Electronic", "Warm Indie Folk"
4. Use that Persona when you want to create songs in the same style

### Using a Persona

1. On the Create page, click **"Personas"**
2. Choose the Persona you want
3. Create a new song with that Persona as the base

## Remaster

**Remaster** (improving quality — taking an old song and remaking it with a better model) lets you:

- Upgrade songs created with v3 or v4 to be better
- Create a slight Variation of the existing song
- Improve the sound without changing the content

### How to use Remaster

1. Open the song you want
2. Click **"Remaster"** in Creative Tools
3. Choose the change level (Subtle / Moderate / Major)
4. Wait for the result

> Remaster doesn't replace the original song; it creates a new version separately.

## Suno Sounds — create Audio Samples

**Suno Sounds** is an Experimental feature that helps create **Custom Audio Samples** (short audio files for use in Production).

Examples of what you can create:
- Sound Effects for videos or games
- Short music Loops
- Ambient textures
- Various accompanying sounds

### How to use Suno Sounds

1. Go to **Create > Sounds**
2. Describe the sound you want, e.g. `"mysterious forest at night with crickets and distant owl"`
3. Click Create
4. Download the resulting file

> **Note:** Suno Sounds is still experimental and may change.
