# Models — choose the right GLM model for the job 🧩

> Compiled in English from the official docs at [docs.z.ai](https://docs.z.ai/guides/llm/glm-4.6)

Z.ai has several models in the **GLM** family — choose by the job and budget.

## 📋 Language models (LLM)

| Model | Highlight | Good for |
|---|---|---|
| **GLM-4.6** | Flagship, good at code/reasoning/agents, long context | Hard work, programming, agents |
| **GLM-4.5** | Well-rounded, balanced quality/price | Serious general work |
| **GLM-4.5-Air** | Lighter, faster, cheaper | High-volume work |
| **GLM-4.5-Flash** | The economical/free version | Experimenting, prototypes |
| **GLM-4.5V** | **Vision** — understands images | Work with images/image documents |

## 🎨 Media-generation models

| Model | What it does |
|---|---|
| **CogVideoX** | Generate video from text/image |
| **CogView** | Generate images from text |

## 🧭 How to choose

- Heavy thinking/coding/agents → **GLM-4.6**
- General work focused on value → **GLM-4.5 / Air**
- Prototype/experiment → **GLM-4.5-Flash**
- Have images to analyze → **GLM-4.5V**

## 💡 Tips

- Specify the version name in `model` per the latest docs
- See each version's price/max context on the Models page of the official docs
- Many versions support **deep-thinking (reasoning) mode** — see [Reasoning](10-reasoning)
