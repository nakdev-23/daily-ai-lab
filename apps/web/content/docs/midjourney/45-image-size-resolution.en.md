# Image Size and Resolution

> Main reference: [Image Size Resolution](https://docs.midjourney.com/hc/en-us/articles/33329374594957-Image-Size-Resolution)

---

## Default image resolution

Midjourney creates images at a resolution of about:

| Aspect Ratio | Approximate size |
|-------------|--------------|
| 1:1 | 1024 × 1024 pixels |
| 16:9 | 1456 × 816 pixels |
| 9:16 | 816 × 1456 pixels |
| 4:3 | 1024 × 768 pixels |
| 3:2 | 1152 × 768 pixels |
| 2:3 | 768 × 1152 pixels |

These images are good for **digital use** (screens, Social Media), but if you want high-resolution **print work**, you must Upscale first.

---

## After Upscale

Upscale increases resolution about **2 times**:

| Before Upscale | After Upscale |
|-------------|--------------|
| 1024 × 1024 | ~2048 × 2048 |

---

## Resolution for printing

For high-quality print work, you need **300 DPI** (Dots Per Inch — the more, the sharper)

| Print size | Pixels needed at 300 DPI |
|----------|--------------------------|
| Business card (3.5×2 in) | 1050 × 600 |
| A4 (8.27×11.69 in) | 2481 × 3508 |
| A3 (11.69×16.54 in) | 3508 × 4961 |
| A1 poster | 7016 × 9933 |

**Conclusion:** An Upscaled image from Midjourney (~2048×2048) is good for printing up to about 15×15 cm at 300 DPI.

---

## How to enlarge further

If you want a larger size:

### Option 1 — an external AI Upscaler
Use an additional Upscale program, such as:
- **Topaz Gigapixel AI** (AI resolution-increasing software)
- **Adobe Firefly Super Resolution**
- **Magnific AI**

### Option 2 — Vector
Convert the image to Vector (a line-based image — scalable infinitely without losing sharpness) for logos or images with sharp edges, using Adobe Illustrator or Inkscape.

---

## Use by type

### Social Media
| Platform | Recommended Aspect Ratio | Normal size |
|----------|-------------------|---------|
| Instagram Post | 1:1 | 1080×1080 |
| Instagram Story | 9:16 | 1080×1920 |
| Facebook Cover | 16:9 | 820×312 |
| Twitter Header | 3:1 | 1500×500 |
| LinkedIn Cover | 4:1 | 1584×396 |

A Midjourney image after Upscale has a sufficient size for all the platforms above.

### Print work
For small to medium print work (business cards, Flyers, small posters), an Upscaled image is enough.

For large print work (Banners, Billboards), you need an additional AI Upscaler.

---

## Tips

1. **Upscale before Download** — get a larger file for various uses
2. **Download PNG** — the best Format for the highest quality
3. **For the web** — reduce the Size to JPG or WebP for loading speed

---

## Summary

Images Midjourney creates are good for Social Media and digital work right away. For small to medium print work, Upscale is enough. Large print work needs an additional external AI Upscaler.
