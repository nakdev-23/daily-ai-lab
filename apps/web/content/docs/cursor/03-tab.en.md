# Tab — code auto-completion ⌨️

> Adapted from the official documentation at [cursor.com/docs](https://cursor.com/docs), the Tab section

**Tab** is Cursor's auto-completion system, smarter than ordinary autocomplete — it predicts the whole next line or several lines, based on the context of the file you're writing.

## ⭐ Highlights

- **Completes multiple lines**, not just a single word
- **Understands context** — looks at the surrounding code and related files
- **Predicts the next edit** — sometimes it suggests jumping to the next related spot (e.g. renaming a variable everywhere)
- **Easy to accept/reject** — press `Tab` to accept, `Esc` or keep typing to skip

## ▶️ How to use it

1. Type code as usual
2. Faded text = Tab's suggestion
3. Press `Tab` to accept
4. If there's a suggestion to "jump" to the next spot, press `Tab` again to follow it

## 💡 Tips

- Write a short comment saying what you want to do first, and Tab will predict the code more accurately
- Tab is good for "while-typing" work; for a whole big job, use the Agent
