# Moodboards — กระดานบรรยากาศ

> อ้างอิงหลัก: [Moodboards](https://docs.midjourney.com/hc/en-us/articles/39193335040013-Moodboards)

---

## Moodboard คืออะไร

Moodboard (กระดานบรรยากาศ — กระดานรวมภาพที่แสดงทิศทาง สไตล์ สี และ Aesthetic ที่ต้องการสำหรับงาน) เป็นเครื่องมือที่นักออกแบบใช้มายาวนานเพื่อวางแผนและสื่อสาร Visual Direction

ใน Midjourney Moodboard เป็นฟีเจอร์ที่ช่วยให้คุณ:
- รวมภาพ Reference ทั้งจาก Explore และ Archive
- วางแผน Prompt ก่อนสร้างจริง
- แชร์ Concept กับทีมหรือลูกค้า
- ใช้เป็น Style Reference สำหรับงานต่อเนื่อง

---

## วิธีสร้าง Moodboard

1. ไปที่เมนู **"Moodboards"** ในแถบซ้าย
2. คลิก **"New Moodboard"** หรือปุ่ม **"+"**
3. ตั้งชื่อ Moodboard
4. เพิ่มภาพจากแหล่งต่างๆ

---

## วิธีเพิ่มภาพใน Moodboard

### จาก Explore
1. คลิกภาพที่ชอบใน Explore
2. เลือก **"Save to Moodboard"**
3. เลือก Moodboard ที่ต้องการ

### จาก Archive
1. คลิกขวาบนภาพใน Archive
2. เลือก **"Add to Moodboard"**

### จากภาพที่เพิ่งสร้าง
- หลังสร้างภาพ → คลิกที่ภาพ → "Add to Moodboard"

---

## การใช้ Moodboard เป็น Reference

### ดู Prompts จาก Moodboard
คลิกภาพใน Moodboard เพื่อดู Prompt ที่ใช้สร้าง ช่วยให้เรียนรู้สไตล์ที่ชอบ

### ใช้ภาพใน Moodboard เป็น Style Reference
นำ URL ของภาพใน Moodboard มาใช้กับ `--sref`:
```
a new scene --sref [URL จากภาพใน Moodboard]
```

## ตัวอย่าง Moodboard ตามประเภทงาน

### Branding Project
```
📋 Brand Identity - Modern Luxury
  → ภาพ Minimalist สี Black/Gold
  → Typography Style References
  → Product Photography Styles
  → Color Palette Examples
```

### Editorial / Fashion
```
📋 Summer Campaign 2025
  → ภาพแฟชั่น Summer Vibes
  → ภาพถ่ายกลางแจ้งแสงธรรมชาติ
  → Color Story: Warm Coral, Sand, Sky Blue
```

### Concept Art
```
📋 Sci-Fi Environment - Project X
  → Reference ดาวเคราะห์ต่าง
  → Futuristic Architecture References
  → Lighting References
```

---

## เคล็ดลับ

1. **สร้าง Moodboard ก่อนเริ่มโปรเจกต์** — ช่วยกำหนดทิศทางได้ชัดเจน
2. **รวมหลาย Reference** — ยิ่งมีภาพมาก ยิ่งเห็น Pattern ที่ชอบชัดขึ้น
3. **แชร์กับลูกค้า** — ยืนยัน Aesthetic ก่อนลงมือสร้างจริง
4. **อัปเดต Moodboard** — เพิ่มภาพใหม่เมื่อหา Inspiration ใหม่

---

## สรุป

Moodboards เป็นเครื่องมือวางแผนที่มีประสิทธิภาพ ช่วยให้มีทิศทางชัดเจนก่อนสร้างภาพ และสื่อสาร Visual Direction กับทีมได้ง่าย
