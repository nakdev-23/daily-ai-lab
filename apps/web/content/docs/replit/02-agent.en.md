# Replit Agent — describe it in text, get a whole app 🤖

> Compiled in English from the official docs at [docs.replit.com](https://docs.replit.com/)

**Replit Agent** is an AI assistant that builds an app for you from start to finish — writing code, installing what's needed, connecting a database, and getting it ready to deploy.

## ▶️ Getting started

1. Log in at [replit.com](https://replit.com/)
2. Start a new project with **Replit Agent**
3. Type out the app you want, e.g. "A survey website with a results page that shows graphs"
4. Watch the Agent plan → write code → run it
5. Type to refine it, then Deploy

## 🧠 What the Agent can do

- Build an entire new project structure
- Write/edit code across multiple files
- Install the needed dependencies
- Connect a database/login system
- Help fix errors it encounters

## 💡 Tips

- Explain the goal clearly + give a usage example
- Break a big task into steps
- Check the result of each step before continuing
- Report errors directly — the Agent will help track them down
