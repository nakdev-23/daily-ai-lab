# Interactive Avatar — อวตารที่คุยโต้ตอบสด ๆ 💬

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [docs.heygen.com](https://docs.heygen.com/) หมวด Streaming / Interactive Avatar

ต่างจากวิดีโอที่อัดไว้ล่วงหน้า **Interactive Avatar** คืออวตารแบบ **สตรีมมิงเรียลไทม์** ที่ฟังผู้ใช้แล้วพูดตอบกลับทันที เหมาะกับทำผู้ช่วยหน้าร้านดิจิทัล, ติวเตอร์เสมือน, หรือพนักงานต้อนรับในแอป

## 🧩 ทำงานอย่างไร

| ขั้น | อธิบาย |
|---|---|
| **ฟัง** | รับเสียง/ข้อความจากผู้ใช้ |
| **คิด** | ส่งให้ LLM (ของคุณหรือที่เชื่อมไว้) ประมวลผลคำตอบ |
| **พูด** | อวตารพูดคำตอบพร้อมขยับปากแบบสด |

## ⭐ จุดเด่น

- **เรียลไทม์** — โต้ตอบทันที ไม่ต้องรอเรนเดอร์
- **ฝังได้** — ใส่ลงเว็บ/แอปผ่าน SDK (เช่น ใช้ WebRTC สตรีมวิดีโอ)
- **ต่อสมองเองได้** — เชื่อมกับ LLM/ฐานความรู้ของคุณ
- เลือกอวตารและเสียงได้เหมือนโหมดวิดีโอ

## 🛠️ สำหรับนักพัฒนา

- มี **Streaming API / SDK** ให้ฝังอวตารสตรีมมิงลงแอป
- ต้องมี **API key** และจัดการการเชื่อมต่อสตรีม (session)
- ออกแบบให้ต่อกับ STT + LLM + ตรรกะของแอปได้

## ▶️ เริ่มต้น (ภาพรวม)

1. เปิดใช้ฟีเจอร์ Interactive/Streaming Avatar ในบัญชี
2. เลือกอวตาร + เสียง
3. ใช้ SDK สร้าง session แล้วส่งข้อความ/เสียงเข้าไป
4. รับสตรีมวิดีโออวตารกลับมาแสดงในแอป
