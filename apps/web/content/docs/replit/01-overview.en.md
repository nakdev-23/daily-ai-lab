# Replit — write, run, and publish code in the cloud 🌐

> Compiled in English from the official docs at [docs.replit.com](https://docs.replit.com/)

**Replit** is a cloud programming environment (Cloud IDE) where you can write and run code right in your browser without installing anything. It supports many languages and has **Replit Agent**, an AI assistant that **builds whole apps from a text description** — from writing the code and connecting a database to deploying it online.

## 📖 Terms worth knowing

| Term | Plain meaning |
|---|---|
| **Repl / Workspace** | A project space for writing-running code in the cloud |
| **Replit Agent** | An AI assistant that builds/edits apps from plain-language instructions |
| **Deployment** | Publishing the app online for people to use |
| **Database** | A built-in database (stores the app's data) |
| **Hosting** | A hosting service that keeps the app online continuously |

## ⭐ Highlights

- **Open a browser and code** — no machine setup needed
- **Replit Agent** — describe it in text, get a whole app
- **Supports many languages** — Python, JavaScript, etc.
- **Built-in deploy** — publish online from one place
- **Real-time collaboration** like a Google Docs for code

## 🚀 Getting started

1. Sign up at [replit.com](https://replit.com/)
2. Try **Replit Agent** by typing out the app you want, e.g. "A survey website with a results summary"
3. Watch the Agent build the project + run it, then type to refine it
4. Click **Deploy** to publish it online
