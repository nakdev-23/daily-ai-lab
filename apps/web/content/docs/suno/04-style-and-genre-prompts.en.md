# Style Prompts and specifying the song Genre

The **Style Prompt** is the most important heart of Custom Mode. This field tells Suno how your song should sound, from the Genre to the instrument sounds and the overall mood.

---

## What is the Style of Music Field?

**Style of Music** is the field where you type a description of the music sound you want. Suno uses these words to set:

- **Genre** — e.g. Pop, Rock, Jazz, Hip-Hop
- **Mood** — e.g. Happy, Sad, Dark, Energetic
- **Instruments** — e.g. Guitar, Piano, Drums
- **Tempo** — e.g. Slow, Upbeat, Fast
- **Vocal Style** — e.g. Male Vocals, Female Vocals, Choir

## How to write a good Style Prompt

### The basic formula

```
[Genre] + [mood] + [main instrument] + [vocal style] + [era/reference]
```

### Good examples

```
upbeat pop, female vocals, acoustic guitar, piano, summer vibes, 2020s
```

```
dark trap, male rap, 808 bass, hi-hats, atmospheric synths, cinematic
```

```
romantic jazz ballad, soft female vocals, piano, saxophone, late night
```

```
epic cinematic orchestral, no vocals, strings, brass, drums, heroic
```

```
indie folk, warm acoustic, storytelling, gentle male vocals, introspective
```

### Common words for Mood

| Word | Meaning |
|----|---------|
| `upbeat` | bright, energetic |
| `melancholic` | slightly sad, longing |
| `dark` | dark, heavy |
| `ethereal` | dreamlike, floating |
| `aggressive` | aggressive, intense |
| `chill` | relaxed, comfortable |
| `nostalgic` | longing for the past |
| `epic` | grand, spectacular |
| `romantic` | romantic, sweet |
| `groovy` | catchy, makes you move |

### Words for Tempo

| Word | Approximate BPM | Meaning |
|----|-------------|---------|
| `slow` | 60–80 BPM | slow |
| `mid-tempo` | 90–110 BPM | moderate |
| `upbeat` | 110–130 BPM | fairly fast |
| `fast` | 130–160 BPM | fast |
| `frantic` | 160+ BPM | very fast, frenetic |

> **BPM — Beats Per Minute** (the higher it is, the faster)

## Creative Prompt Boosting

In Suno v4.5 there's a **Creative Prompt Boosting** feature that helps the AI understand the Style Prompt better, by using more varied and detailed language.

### A detailed style command

Instead of typing:
```
sad pop song
```

Try typing:
```
tender melancholic indie pop, fingerpicked acoustic guitar with gentle strings,
breathy female vocals with emotional vibrato, slow tempo, bittersweet lyrics
about longing and loss, reminiscent of Phoebe Bridgers or Bon Iver
```

### For relaxing/sleeping music


### For workout music
```
high energy EDM, aggressive synths, fast tempo, 140 BPM, power drop, motivational
```

### For children's music
```
cheerful children's song, ukulele, light percussion, happy female vocals, simple melody
```

### For Podcast or Video background music
```
background ambient music, no vocals, soft piano, minimal, corporate, professional
```

## What not to do

- **Don't include artist names** such as "a song like Taylor Swift" — Suno won't follow it and may not give the result you want
- **Don't include copyrighted song titles** such as "a melody like Shape of You" — it's considered copyright infringement
- **Don't make the Prompt longer than 120 characters** — Suno may cut off or ignore the end
- **Don't use contradictory commands** such as "slow fast tempo" — it confuses the AI
