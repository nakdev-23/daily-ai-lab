# Gemini in Google Workspace — Docs, Gmail, Sheets, Slides, Meet

**Gemini in Google Workspace** integrates AI (artificial intelligence) into the work apps you use every day, helping you write, analyze, summarize, and create content without leaving the app you're in.

---

## Gemini in Gmail

### Main features

**Help me write**
- Start drafting an email from a short prompt (a short instruction or description telling the AI what you want)
- Example: "Write a thank-you email to a client after a meeting" → Gemini drafts a professional email instantly
- Adjustable tone: formal, casual, concise, detailed

**Summarize this email**
- Open a long email and hit "Summarize" to see the key points
- Works on a whole email thread, not just one email

**Smart Reply**
- Gemini suggests short reply messages suited to the context

**Context-aware drafts**
- Gemini reads the email thread and helps you write following the existing conversation

### How to use it in Gmail
1. Open Gmail → click **Compose** to write a new email
2. Click the ✨ icon (Help me write) in the toolbar
3. Type a short description of what you want to write
4. Gemini drafts the email — edit or regenerate as you want

## Gemini in Google Docs

### Main features

**Help me write**
- Create content from scratch, or continue from existing text
- Adjust the style (writing format), tone, and length

**Proofread**
- Check grammar, style, and clarity
- Suggest improvements with explanations

**Summarize document**
- Summarize a long document into key points
- Create bullet points from selected content

**Ask about the document**
- Ask questions about the document's content
- Find specific information in a long document

**Rewrite / Change tone**
- Select text → ask Gemini to adjust the tone or rewrite it
- Example: change academic language into easy-to-understand language

### Gemini Sidebar in Docs
- A sidebar you can keep open for asking questions, getting suggestions, or writing new sections
- It can reference the current document's content automatically

---

## Gemini in Google Sheets

### Main features

**Help me organize**
- Create tables and data structures from a description
- Example: "Create a table to track the monthly budget"

**Analyze data**
- Ask questions about the data in the sheet, e.g. "Which product sold best in Q3?"
- Gemini reads the data and answers in natural language

**Formula suggestions**
- Describe what you want to calculate → Gemini suggests a suitable formula
- Helps explain complex formulas

**Create charts**
- Ask Gemini to create a chart from selected data, without configuring it yourself

---

## Gemini in Google Slides

### Main features

**Help me create a presentation**
- Create a whole deck from a topic or outline
- Example: "Create a 10-slide deck about 2025 marketing strategy"

**Generate images for slides**
- Create AI images for each slide based on the content

**Rewrite slide content**
- Make slide text more concise, or expand it
- Change the tone for different audiences

**Speaker notes**
- Create speaker notes (notes for the presenter) automatically for each slide

---

## Gemini in Google Meet

### Main features

**Meeting notes**
- Take notes automatically during the meeting
- Summarize key points and action items after the meeting

**Transcription**
- Transcribe speech into text in real time
- Supports many languages

**Gemini sidebar in Meet**
- Ask questions, find information, or see a summary of the conversation

## Requirements for use

### Personal account
- Requires the **Google One AI Premium** plan (Gemini Advanced)
- Supports all personal Workspace apps

### Google Workspace account (work/school)
- Requires a **Gemini for Workspace** license
  - **Gemini Business** — basic features
  - **Gemini Enterprise** — full features, including Meet AI
- The administrator must enable it for the organization first

## Usage tips

- **Give clear context** — always specify the audience, tone, and purpose
- **Use the Gemini sidebar** — keep it open to ask questions anytime
- **Always check the results** — Gemini is an assistant, not the final decision
- **Use it in meetings** — turn on auto notes in Meet so you don't miss anything important
