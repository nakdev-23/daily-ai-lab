# เริ่มต้นใช้งาน Cursor 🚀

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [cursor.com/docs](https://cursor.com/docs) หมวด Getting Started

**Cursor** เป็นโปรแกรมแก้โค้ดที่มี AI ในตัว สร้างต่อยอดจาก VS Code ถ้าคุณเคยใช้ VS Code จะคุ้นมือทันที

## 🧭 ขั้นตอนติดตั้ง

1. ดาวน์โหลดจาก [cursor.com](https://cursor.com/) (Windows / macOS / Linux)
2. ติดตั้งและเปิดโปรแกรม แล้วล็อกอิน/สมัครบัญชี
3. ตอนเปิดครั้งแรก เลือก **import จาก VS Code** เพื่อย้ายธีม คีย์ลัด และส่วนขยายมาได้เลย

## 🗂️ ฟีเจอร์ AI หลัก 3 อย่าง

| ฟีเจอร์ | ทำอะไร | ปุ่มลัด (ค่าเริ่มต้น) |
|---|---|---|
| **Tab** | เติมโค้ดอัตโนมัติขณะพิมพ์ | `Tab` |
| **Inline Edit** | สั่งแก้โค้ดที่เลือกด้วยภาษาคน | `Ctrl/Cmd + K` |
| **Chat / Agent** | คุย/สั่งงานทั้งโปรเจกต์ | `Ctrl/Cmd + L` |

## ▶️ ลองใช้ครั้งแรก

1. เปิดโฟลเดอร์โปรเจกต์ (File → Open Folder)
2. รอ Cursor ทำ **index โค้ดเบส** (เพื่อให้ AI เข้าใจทั้งโปรเจกต์)
3. ลองพิมพ์โค้ด แล้วกด `Tab` รับคำแนะนำ
4. เลือกโค้ดสักท่อน กด `Ctrl/Cmd + K` แล้วพิมพ์ "แก้ให้เป็น async"
