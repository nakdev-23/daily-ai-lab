# Integrations — connecting external services 🔌

> Adapted from the official documentation at [support.bolt.new](https://support.bolt.new/)

Bolt connects to popular services to make your app end-to-end.

## 🗄️ Supabase (database + Auth)

- Store real app data and build a login system
- Connect it in the project, then have Bolt add features that use the data
- Good when the app needs to persist data / have multiple users

## 🎨 Figma

- Bring a Figma design in as the starting point for the app's UI
- Helps the app match the design you made

## 📱 Expo (mobile apps)

- Connect to **Expo** to build mobile apps (iOS/Android) from Bolt
- Good when you want a cross-platform app, not just web

## ▶️ How to use it

1. Open the Integrations menu in the project
2. Pick the service you want and connect it
3. Tell Bolt to use it, e.g. "save user data to Supabase"

## 💡 Tips

- Connect Supabase as soon as you start storing real data
- Set up data-access permissions tightly
