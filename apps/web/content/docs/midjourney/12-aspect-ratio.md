# Aspect Ratio — สัดส่วนภาพ

> อ้างอิงหลัก: [Aspect Ratio](https://docs.midjourney.com/hc/en-us/articles/31894244298125-Aspect-Ratio)

---

## Aspect Ratio คืออะไร

Aspect Ratio (สัดส่วนภาพ — อัตราส่วนระหว่างความกว้างและความสูงของภาพ) กำหนดรูปร่างของภาพที่ Midjourney สร้างออกมา

ตัวอย่าง:
- `1:1` = สี่เหลี่ยมจัตุรัส (กว้าง 1 ส่วน สูง 1 ส่วน)
- `16:9` = ภาพวางนอน (กว้าง 16 ส่วน สูง 9 ส่วน)
- `9:16` = ภาพแนวตั้ง (กว้าง 9 ส่วน สูง 16 ส่วน)

---

## วิธีใช้

ใช้ Parameter `--ar` หรือ `--aspect` ต่อท้าย Prompt:

```
a beautiful sunset --ar 16:9
```

```
a portrait of a woman --ar 2:3
```

---

## สัดส่วนที่นิยมใช้

| Aspect Ratio | รูปร่าง | การใช้งาน |
|-------------|---------|----------|
| **1:1** | สี่เหลี่ยมจัตุรัส | โพสต์ Instagram, รูปโปรไฟล์ |
| **4:3** | วางนอนมาตรฐาน | งานพิมพ์ทั่วไป, นำเสนอ |
| **3:2** | วางนอนภาพถ่าย | ภาพถ่าย DSLR, การ์ด |
| **16:9** | Widescreen | วิดีโอ, วอลเปเปอร์, YouTube |
| **21:9** | Ultrawide | หน้าจอกว้างพิเศษ, ภาพแบนเนอร์ |
| **2:3** | แนวตั้งมาตรฐาน | โปสเตอร์, หน้าปกหนังสือ |
| **9:16** | แนวตั้ง Vertical | Instagram Story, TikTok, Reels |
| **3:4** | แนวตั้งทั่วไป | Pinterest, โพสต์บล็อก |

---

## ตัวอย่างการเลือกตามแพลตฟอร์ม

### Social Media

```
a product photo of sneakers --ar 1:1
```
→ สำหรับโพสต์ Instagram หน้า Feed

```
a fashion model portrait --ar 9:16
```
→ สำหรับ Instagram Story / TikTok

```
a landscape photo --ar 16:9
```
→ สำหรับ YouTube Thumbnail หรือ Facebook Cover

### งานพิมพ์

```
a movie poster design --ar 2:3
```
→ โปสเตอร์มาตรฐาน (เช่น ขนาด A4 แนวตั้ง)

```
a business card design --ar 7:4
```
→ นามบัตร

```
a book cover design --ar 2:3
```
→ หน้าปกหนังสือ

### งาน Digital

```
a website hero banner --ar 21:9
```
→ แบนเนอร์เว็บไซต์

```
a wallpaper for desktop --ar 16:9
```
→ วอลเปเปอร์คอมพิวเตอร์

---

## ข้อจำกัดของ Aspect Ratio

- ค่าสัดส่วนสูงสุดที่ Midjourney รองรับคือ **2:1** ถึง **1:2** ในรุ่นเก่า
- เวอร์ชัน 5 ขึ้นไปรองรับสัดส่วนที่กว้างกว่า เช่น **1:3** หรือ **3:1** ได้
- สัดส่วนที่ผิดปกติมากอาจให้ผลลัพธ์ที่ประหลาด

---

## Image Size และ Resolution

Aspect Ratio ไม่ได้กำหนดขนาดพิกเซล (Pixel — จุดภาพที่เล็กที่สุดในภาพดิจิทัล) โดยตรง แต่กำหนดรูปร่าง

ภาพที่ Midjourney สร้างมีความละเอียดประมาณ **1024x1024 pixels** (สำหรับ 1:1) และจะปรับตาม Aspect Ratio:
- `--ar 16:9` → ประมาณ 1456x816 pixels
- `--ar 9:16` → ประมาณ 816x1456 pixels

หากต้องการความละเอียดสูงขึ้น ให้ใช้ **Upscale** หลังสร้างภาพ

---

## เคล็ดลับ

1. **วางแผนก่อนสร้าง** — รู้ว่าจะเอาภาพไปใช้ที่ไหน แล้วเลือก Aspect Ratio ให้เหมาะ
2. **ทดสอบหลาย Ratio** — บางครั้ง Aspect Ratio ต่างกันให้ผล Composition ที่ต่างกัน
3. **ใช้ตัวเลขกว้างๆ** — `--ar 16:9` และ `--ar 32:18` ให้ผลเหมือนกัน แต่แบบแรกง่ายกว่า
4. **แนวตั้งสำหรับ Portrait** — ภาพบุคคลมักดูดีที่ `--ar 2:3` หรือ `--ar 3:4`

---

## สรุป

`--ar` หรือ `--aspect` เป็น Parameter ที่ใช้บ่อยที่สุด เลือกสัดส่วนให้ตรงกับการใช้งาน: `1:1` สำหรับ Instagram, `9:16` สำหรับ Story, `16:9` สำหรับวิดีโอ และ `2:3` สำหรับโปสเตอร์
