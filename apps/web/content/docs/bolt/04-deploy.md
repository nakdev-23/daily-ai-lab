# Deploy & GitHub — เอาแอปขึ้นเว็บ 🚀

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [support.bolt.new](https://support.bolt.new/)

## 🌐 Deploy ขึ้นออนไลน์

Bolt เผยแพร่แอปผ่าน **Netlify** ได้ในไม่กี่คลิก:

1. กดปุ่ม **Deploy** ในโปรเจกต์
2. Bolt จะ build และนำขึ้น Netlify ให้
3. ได้ **ลิงก์สาธารณะ** มาแชร์ได้ทันที

ทุกครั้งที่แก้แล้วอยากอัปเดตเว็บจริง ก็กด Deploy ใหม่

## 🐙 sync กับ GitHub

เชื่อม GitHub เพื่อ:
- **เก็บโค้ด** ไว้ใน repository (backup)
- แก้โค้ดเองนอก Bolt แล้วซิงก์
- ทำงานร่วมกับนักพัฒนาคนอื่น

## 💡 เคล็ดลับ

- ทดสอบแอปในตัว preview ก่อน Deploy
- ใช้ GitHub เป็นทางออกถ้าอยากย้ายไปพัฒนาต่อเองภายหลัง
- ถ้าต่อ Supabase ตรวจว่าตั้งค่า production ครบก่อนเปิดสาธารณะ
