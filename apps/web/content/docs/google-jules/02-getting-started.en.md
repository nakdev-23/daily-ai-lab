# Getting started with Jules 🤖

> Adapted from the official documentation at [jules.google](https://jules.google/docs)

## 🔗 Getting-started steps

1. Go to [jules.google](https://jules.google/) and log in with a Google account
2. **Connect GitHub** — allow Jules to access the repository you want
3. Choose the repo and branch to work on
4. Assign your first task in plain language

## 🐙 Connecting GitHub

Jules works mainly through GitHub:
- Choose which repos to give access to (you can select only the ones you want)
- Jules clones the code to work in its own virtual machine
- The work comes out as a **Pull Request** for you to review

## ✍️ Assign your first task

Write the task clearly, e.g.:
> "Fix the bug where the submit button on the contact page doesn't work, and add email validation"

Jules will:
1. **Plan** the fix steps
2. Ask you to confirm the plan (if configured)
3. Get to work fixing + run tests
4. Open a PR

## 💡 Tips

- Jules does clearly scoped tasks better than broad ones
- Adding context (relevant files, success criteria) makes the result more on target
