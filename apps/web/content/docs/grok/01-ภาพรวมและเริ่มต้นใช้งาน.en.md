# Grok (xAI) — overview and getting started

> Reference: [Overview](https://docs.x.ai/overview) | [Quickstart](https://docs.x.ai/developers/quickstart) | [Grok.com User Guide](https://docs.x.ai/grok/user-guide)

---

## What is Grok?

**Grok** is a conversational AI (chatbot) developed by **xAI**, the AI company founded by Elon Musk. Grok's main goal is to be a "truth-seeking" AI that answers questions directly, plus it has abilities for image and video creation and voice interaction.

xAI offers Grok through 2 main channels:

- **Grok.com / mobile app** — for general users who want conversational interaction
- **xAI API** — for developers who want to build applications with Grok

---

## Grok's main abilities

Grok supports many kinds of work in one place:

- **Text** — conversation, answering questions, writing code, analyzing data
- **Images** — create images from a prompt, edit images, create several images at once
- **Video** — create videos, extend videos, edit videos from text or images
- **Audio** — talk in real time, speech-to-text, and text-to-speech
- **Find real data** — search the internet and posts on X (Twitter)

---

## How to access Grok

### 1. Grok.com (general users)

Go to [grok.com](https://grok.com) and log in with:

- An xAI account
- An X (Twitter) account
- A Google account
- An Apple account

There are apps on both **iOS** and **Android**.

### 2. xAI API (developers)

You need an API key to connect to the Grok models directly via code.

## Getting started with the API (Quickstart)

Reference: [Quickstart](https://docs.x.ai/developers/quickstart)

### Step 1 — Sign up for an xAI account

Go to [accounts.x.ai](https://accounts.x.ai/sign-up?redirect=cloud-console) to sign up, then top up credits to start using the API.

### Step 2 — Create an API Key

Go to [console.x.ai/team/default/api-keys](https://console.x.ai/team/default/api-keys) and create an API Key.

Then set the environment variable:

```bash
export XAI_API_KEY="your_api_key"
```

Or put it in your project's `.env`:

```
XAI_API_KEY=your_api_key
```

### Step 3 — Install the SDK

Choose your language:

**Python (xAI SDK):**
```bash
pip install xai-sdk
```

**Python (OpenAI SDK — interchangeable):**
```bash
pip install openai
```

**JavaScript (AI SDK):**
```bash
npm install ai @ai-sdk/xai zod
```

**JavaScript (OpenAI SDK):**
```bash
npm install openai
```

### Step 4 — Send your first request

**Python (xAI SDK):**
```python
import os
from xai_sdk import Client
from xai_sdk.chat import user, system

client = Client(api_key=os.getenv("XAI_API_KEY"))

chat = client.chat.create(model="grok-4.3")
chat.append(system("You are Grok, a smart and helpful AI assistant"))
chat.append(user("Hi, can you explain what AI is?"))

response = chat.sample()
print(response.content)
```

**Python (OpenAI SDK):**
```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("XAI_API_KEY"),
    base_url="https://api.x.ai/v1",
)

response = client.responses.create(
    model="grok-4.3",
    input=[
        {"role": "system", "content": "You are Grok, an AI assistant"},
        {"role": "user", "content": "Hi, can you explain what AI is?"},
    ],
)

print(response.output_text)
```

**cURL (test via the terminal):**
```bash
curl https://api.x.ai/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $XAI_API_KEY" \
  -d '{
    "model": "grok-4.3",
    "input": [
        {"role": "user", "content": "Hi, can you explain what AI is?"}
    ]
  }'
```

> **Note:** The xAI API is compatible with the OpenAI SDK; just change the `base_url` to `https://api.x.ai/v1` and it works.

### Step 5 — Create an image (try the Imagine API)

```python
import os
import xai_sdk

client = xai_sdk.Client(api_key=os.getenv("XAI_API_KEY"))

response = client.image.sample(
    prompt="A future city view at sunset",
    model="grok-imagine-image-quality",
)

print(response.url)  # The URL of the created image
```

## Grok.com — user guide for general users

Reference: [Grok.com User Guide](https://docs.x.ai/grok/user-guide)

### Workspace types

**Grok Business** has 2 workspace types:

| Type | Used for | Accessible when |
|---|---|---|
| **Personal Workspace** | Personal use | You have a Grok account (may be disabled by the organization) |
| **Team Workspace** | Team use, with extra privacy | You have an active license |

Change workspaces from the **Workspace selector button at the bottom left** on grok.com.

![Workspace Selector](screenshots/02-workspace-selector.png)

### Benefits in the Team Workspace

- Enterprise-grade privacy protection, per the [Terms of Service Enterprise](https://x.ai/legal/terms-of-service-enterprise)
- Full SuperGrok use (higher quota, all features)
- Conversations can be shared only with team members who have a license

### Sharing conversations in the team

1. Open the conversation in the Team Workspace
2. Hit the **Share** button and choose members
3. Create a link and send it to the team

See shared conversations at: [grok.com/history?tab=shared-with-me](https://grok.com/history?tab=shared-with-me)

> A share link only opens for members who have a license; if sent to someone outside the team, it won't open.

### Activating a license

1. Go to [console.x.ai](https://console.x.ai)
2. Hit **"Assign license"** and choose the license type
3. The Team Workspace is ready on grok.com immediately

## Main API endpoints

| Endpoint | Used for |
|---|---|
| `https://api.x.ai/v1/responses` | Send a prompt and receive a text answer |
| `https://api.x.ai/v1/images/generations` | Create images |
| `https://api.x.ai/v1/audio/speech` | Text-to-Speech |
| `https://api.x.ai/v1/audio/transcriptions` | Speech-to-Text |
