# Integrations — connect Supabase and GitHub 🔌

> Compiled in English from the official docs at [docs.lovable.dev](https://docs.lovable.dev/)

Lovable can build the interface, but a real app needs data storage and a membership system — that's where Supabase comes in.

## 🗄️ Supabase (database + Auth)

**Supabase** is the database + login service Lovable connects for you built-in.

- **Database** — store the app's data (e.g. notes, users, orders)
- **Authentication** — sign-up/login system
- **Storage** — store files/images

How to connect (overview):
1. Click to connect Supabase in your Lovable project
2. Authorize/create a Supabase project
3. Tell Lovable to add features that use data, e.g. "Save notes to the database and let users see only their own"

## 🐙 GitHub (sync code)

Connect GitHub to:
- **Sync code** out to a repository
- Edit code yourself outside Lovable, then sync back
- Collaborate with developers on your team

## 💡 Tips

- Connect Supabase from the moment you start storing real data
- Use GitHub as a backup and an exit if you later want to edit it yourself
- Be careful about data access permissions (let users see only their own data)
