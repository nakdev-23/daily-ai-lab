# สร้างวิดีโอ — จากบทพูดสู่คลิปสำเร็จ 🎞️

> เรียบเรียงเป็นภาษาไทยจากเอกสารทางการ [docs.heygen.com](https://docs.heygen.com/) หมวด Create Video

## 🧩 องค์ประกอบของวิดีโอ

| ส่วน | อธิบาย |
|---|---|
| **Avatar** | ตัวละครที่พูด |
| **Voice** | เสียงพูด (เลือกภาษา/โทน หรือใช้เสียงโคลน) |
| **Script** | บทพูดที่อวตารจะพูด |
| **Scene** | ฉากหนึ่งช่วง (สลับฉาก/พื้นหลัง/ข้อความได้) |
| **Template** | แม่แบบสำเร็จรูปที่มีเลย์เอาต์มาให้ |

## ▶️ ขั้นตอนสร้าง

1. กด **Create Video** แล้วเลือกเริ่มจาก **Template** หรือหน้าว่าง
2. เลือก **Avatar** และ **Voice** (ตั้งภาษาไทยได้)
3. พิมพ์ **Script** ลงในแต่ละฉาก
4. ปรับพื้นหลัง ใส่ข้อความ/รูป/โลโก้ตามต้องการ
5. กด **Submit/Generate** เพื่อเรนเดอร์ แล้วดาวน์โหลด

## 💡 เคล็ดลับให้ออกมาดูดี

- เขียนบทเป็นประโยคสั้น กระชับ อ่านลื่น
- ใส่เครื่องหมายวรรคตอนช่วยจังหวะการพูด
- แบ่งเนื้อหายาว ๆ เป็นหลายฉากจะดูไม่น่าเบื่อ
- ใช้เทมเพลตเป็นจุดเริ่ม จะได้งานเร็วและสวยขึ้น

## 🔁 ทำซ้ำได้ง่าย

อยากทำหลายคลิปที่หน้าตาเหมือนกัน (เช่น ซีรีส์สอน) ให้บันทึกเป็นเทมเพลตของตัวเอง แล้วเปลี่ยนแค่บทในแต่ละตอน
