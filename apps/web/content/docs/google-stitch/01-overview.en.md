# Google Stitch — design UI with AI 🎨

> Adapted from the official documentation at [stitch.withgoogle.com](https://stitch.withgoogle.com/)

**Google Stitch** is a tool from Google Labs that helps **design app and web screens with AI** — just describe it in text (or attach a sketch) and Stitch creates a beautiful, usable UI screen, ready to export as **code** or to edit further in **Figma**. Powered by Gemini.

## 📖 Terms worth knowing

| Term | In plain words |
|---|---|
| **UI** | The app/web look that users see and tap |
| **Prompt to UI** | Create a screen from a text description |
| **Screen** | One screen in the app (e.g. login page, profile page) |
| **Standard / Experimental mode** | A fast mode vs an experimental mode with more varied results |
| **Export** | Export the design as code (HTML/CSS) or to Figma |

## ⭐ Highlights

- **Describe in words, get a UI screen** — no starting from scratch
- **Attach a sketch/reference image** to set the design direction
- **Edit in natural language** — say what to adjust and the AI does it
- **Export to Figma or as code** to continue
- **Multiple screens** — build the whole app flow

## 🚀 Getting started

1. Go to [stitch.withgoogle.com](https://stitch.withgoogle.com/) and log in with Google
2. Describe the app you want, e.g. "a coffee-ordering app page with a menu and a cart"
3. Choose Standard or Experimental mode and have the AI create the screen
4. Edit with commands, then hit Export to Figma or grab the code
