# Writing lyrics and Metatags

In Custom Mode, you can enter **Lyrics** (the words you want the AI to sing) and use **Metatags** (special tags — special commands in square brackets that tell the AI what each section is) to create a song with a clear structure.

---

## Basic Song Structure

Most songs consist of these sections:

| Song section | Metatag | Meaning |
|------------|---------|----------|
| **Verse** | `[Verse]` | The narrative section — usually changes content each round |
| **Chorus** (Hook) | `[Chorus]` | The most memorable part — sung repeatedly |
| **Bridge** | `[Bridge]` | The section that changes the mood or perspective |
| **Pre-Chorus** | `[Pre-Chorus]` | A short section before the chorus, building anticipation |
| **Outro** | `[Outro]` | The closing section of the song |
| **Intro** | `[Intro]` | The opening section (usually no lyrics) |

---

## All the Metatags Suno supports

### Structural Metatags

```
[Verse]          — the verse section
[Chorus]         — the chorus/hook section
[Bridge]         — the bridge section
[Pre-Chorus]     — the pre-chorus section
[Intro]          — the opening section
[Outro]          — the closing section
[Hook]           — the hook section (similar to Chorus)
[Refrain]        — a repeated section (similar to Chorus)
[Break]          — a break, mostly purely instrumental
[Interlude]      — a section between parts, usually music
[Solo]           — an instrument Solo section, e.g. Guitar Solo
[Ad-lib]         — free improvised singing, no fixed lyrics
```

### Special Metatags

```
[Instrumental]   — a section with no vocals, only music
[Spoken Word]    — speaking instead of singing
[Rap]            — a Rap section (rhythmic speaking)
[Whisper]        — singing in a whisper
[Falsetto]       — an extra-high voice (Falsetto — singing higher than normal)
[Call and Response] — a back-and-forth pattern between voices
```

### Sound Direction Metatags

```
[Build Up]       — gradually increasing intensity
[Drop]           — the point where the music bursts out (popular in EDM)
[Fade Out]       — gradually getting quieter until it disappears
[Big Finish]     — a grand ending
```

## Tips for writing good lyrics

### 1. Appropriate length

- A **Verse** should have 4–8 lines
- A **Chorus** should have 4–6 lines (easy to remember, repeatable)
- A **Bridge** should have 2–4 lines

### 2. Rhythm and Rhyme

A good song should have rhymes (words that sound similar), including end rhymes:

```
bright sky (rhymes with) feeling confident
golden sunlight (rhymes with) like the rain
```

### 3. Common structures

```
Basic structure:
Verse → Chorus → Verse → Chorus → Bridge → Chorus → Outro

Short structure:
Verse → Chorus → Verse → Chorus

Pop structure:
Intro → Verse → Pre-Chorus → Chorus → Verse → Pre-Chorus → Chorus → Bridge → Chorus → Outro
```

## Using ReMi — the lyric-writing assistant

**ReMi** is Suno's specialized AI model that helps create Lyrics for you automatically, before creating the song.

### How to use ReMi

1. In Custom Mode, click the **"Write with ReMi"** button
2. Tell ReMi what kind of song you want
3. ReMi writes the lyrics with Metatags for you
4. Edit as you like, then press Create

---

## Limitations on using lyrics

- **Thai lyrics** — Suno supports Thai lyrics, but the pronunciation may not always be perfect
- **Lyric length** — shouldn't be too long, because Suno has a limited song length
- **Prohibited content** — you can't use violent, obscene, or copyright-infringing content
- **Copyrighted lyrics** — avoid copying copyrighted lyrics from other artists
