# การเขียนเนื้อเพลงและ Metatags

ใน Custom Mode คุณสามารถใส่ **Lyrics** (เนื้อเพลง — คำร้องที่ต้องการให้ AI ร้อง) และใช้ **Metatags** (แท็กพิเศษ — คำสั่งพิเศษในวงเล็บเหลี่ยมที่บอก AI ว่าแต่ละส่วนคืออะไร) เพื่อสร้างเพลงที่มีโครงสร้างชัดเจน

---

## โครงสร้างพื้นฐานของเพลง (Song Structure)

เพลงส่วนใหญ่ประกอบด้วยส่วนต่าง ๆ ดังนี้:

| ส่วนของเพลง | Metatag | ความหมาย |
|------------|---------|----------|
| **Verse** (เวิร์ส) | `[Verse]` | ท่อนเล่าเรื่อง — มักเปลี่ยนเนื้อหาในแต่ละรอบ |
| **Chorus** (คอรัส/ฮุก) | `[Chorus]` | ท่อนที่คนจำได้มากที่สุด — ร้องซ้ำ ๆ |
| **Bridge** (บริดจ์) | `[Bridge]` | ท่อนที่เปลี่ยนอารมณ์หรือมุมมอง |
| **Pre-Chorus** (พรีคอรัส) | `[Pre-Chorus]` | ท่อนสั้น ๆ ก่อนคอรัส เพื่อสร้างความคาดหวัง |
| **Outro** (เอาโทร) | `[Outro]` | ท่อนปิดท้ายเพลง |
| **Intro** (อินโทร) | `[Intro]` | ท่อนเปิดเพลง (มักไม่มีเนื้อ) |

---

## Metatags ทั้งหมดที่ Suno รองรับ

### Structural Metatags (แท็กโครงสร้าง)

```
[Verse]          — ท่อนเวิร์ส
[Chorus]         — ท่อนคอรัส/ฮุก
[Bridge]         — ท่อนบริดจ์
[Pre-Chorus]     — ท่อนพรีคอรัส
[Intro]          — ท่อนเปิด
[Outro]          — ท่อนปิด
[Hook]           — ท่อนเกี่ยว (คล้าย Chorus)
[Refrain]        — ท่อนที่ซ้ำ ๆ (คล้าย Chorus)
[Break]          — ช่วงพัก ส่วนมากเป็นดนตรีล้วน
[Interlude]      — ช่วงระหว่างท่อน มักเป็นดนตรี
[Solo]           — ช่วง Solo เครื่องดนตรี เช่น Guitar Solo
[Ad-lib]         — การร้องแบบอิสระ ไม่มีเนื้อที่แน่นอน
```

### Special Metatags (แท็กพิเศษ)

```
[Instrumental]   — ส่วนที่ไม่มีเสียงร้อง มีแต่ดนตรี
[Spoken Word]    — พูดแทนร้อง
[Rap]            — ท่อน Rap (แร็พ — การพูดแบบจังหวะ)
[Whisper]        — ร้องแบบกระซิบ
[Falsetto]       — เสียงสูงพิเศษ (เสียง Falsetto — เสียงที่ร้องสูงกว่าปกติ)
[Call and Response] — รูปแบบโต้ตอบระหว่างเสียง
```

### Sound Direction Metatags (แท็กกำหนดทิศทางเสียง)

```
[Build Up]       — ค่อย ๆ เพิ่มความเข้มข้น
[Drop]           — จุดที่ดนตรีระเบิดออกมา (นิยมใน EDM)
[Fade Out]       — ค่อย ๆ เบาลงจนหาย
[Big Finish]     — จบแบบยิ่งใหญ่
```

## ตัวอย่างการเขียนเนื้อเพลงที่ดี

### ตัวอย่างที่ 1: เพลง Pop ทั่วไป

```
[Intro]
(เสียงกีตาร์นุ่มนวล)

[Verse 1]
เช้านี้ฟ้าสดใส แสงแดดส่องสวยงาม
ลมพัดเบาสบาย ใจเบิกบานทุกเวลา
ก้าวเดินไปข้างหน้า ไม่หวั่นใจวันใหม่
เพราะมีเธออยู่ข้าง ๆ ทุกก้าวทุกวัน

[Pre-Chorus]
และวันนี้ฉันรู้แล้ว
ว่าทุกอย่างมันดี

[Chorus]
วันนี้วันดี ๆ ที่ได้มีเธอ
ทุกอย่างสดใสสวย เพราะเธออยู่ตรงนี้
ฉันจะไม่ปล่อยมือ ไม่ว่าอะไรจะมา
ขอให้รักนี้ยืนยาว ตลอดไปเธอและฉัน

[Verse 2]
เวลาผ่านไปเร็ว แต่รักเรายังคงมี
ทุกความทรงจำ ยังสดใหม่เหมือนเดิม
ไม่มีอะไรเปลี่ยน ในหัวใจของฉัน
มีแค่เธอคนเดียว ที่ฉันต้องการ

[Chorus]
วันนี้วันดี ๆ ที่ได้มีเธอ
ทุกอย่างสดใสสวย เพราะเธออยู่ตรงนี้
ฉันจะไม่ปล่อยมือ ไม่ว่าอะไรจะมา
ขอให้รักนี้ยืนยาว ตลอดไปเธอและฉัน

[Bridge]
บางครั้งโลกมันยาก บางวันมีพายุ
แต่ถ้ามีเธออยู่ ฉันไม่เคยกลัว

[Chorus]
วันนี้วันดี ๆ ที่ได้มีเธอ
ทุกอย่างสดใสสวย เพราะเธออยู่ตรงนี้

[Outro]
เธอและฉัน... ตลอดไป...
```

### ตัวอย่างที่ 2: เพลงภาษาอังกฤษ Hip-Hop

```
[Verse]
Started from the bottom now I'm climbing high
Every single day I'm reaching for the sky
No time for doubters, I got work to do
Building every dream, making visions true

[Chorus]
Rise up, rise up, never gonna stop
From the very bottom to the very top
Hustle every day, grind until it's done
Watch me rise and shine like the morning sun

[Bridge]
They said I couldn't do it
But I proved them wrong
Every setback made me stronger
Now I'm standing strong

[Outro]
Rise up...
```

## เคล็ดลับการเขียนเนื้อเพลงที่ดี

### 1. ความยาวที่เหมาะสม

- **Verse** ควรมี 4–8 บรรทัด
- **Chorus** ควรมี 4–6 บรรทัด (จำง่าย ซ้ำได้)
- **Bridge** ควรมี 2–4 บรรทัด

### 2. จังหวะและสัมผัส (Rhyme)

เพลงที่ดีควรมีสัมผัส (คำที่ออกเสียงคล้ายกัน) ทั้งสัมผัสปลาย:

```
ฟ้าสดใส (สัมผัสกับ) อยู่มั่นใจ
แสงแดดทอง (สัมผัสกับ) ดั่งสายฝน
```

### 3. โครงสร้างที่พบบ่อย

```
โครงสร้างพื้นฐาน:
Verse → Chorus → Verse → Chorus → Bridge → Chorus → Outro

โครงสร้างสั้น:
Verse → Chorus → Verse → Chorus

โครงสร้างแบบ Pop:
Intro → Verse → Pre-Chorus → Chorus → Verse → Pre-Chorus → Chorus → Bridge → Chorus → Outro
```

## การใช้ ReMi — ผู้ช่วยเขียนเนื้อเพลง

**ReMi** คือโมเดล AI เฉพาะทางของ Suno ที่ช่วยสร้าง Lyrics (เนื้อเพลง) ให้คุณโดยอัตโนมัติ ก่อนที่จะสร้างเพลง

### วิธีใช้ ReMi

1. ใน Custom Mode คลิกปุ่ม **"Write with ReMi"** (เขียนด้วย ReMi)
2. บอก ReMi ว่าต้องการเพลงแบบไหน
3. ReMi จะเขียนเนื้อเพลงพร้อม Metatags ให้
4. แก้ไขตามใจชอบ แล้วกด Create

---

## ข้อจำกัดในการใช้เนื้อเพลง

- **เนื้อเพลงภาษาไทย** — Suno รองรับเนื้อเพลงภาษาไทยได้ แต่อาจออกเสียงได้ไม่สมบูรณ์แบบเสมอไป
- **ความยาวเนื้อเพลง** — ไม่ควรยาวเกินไป เพราะ Suno มีความยาวเพลงจำกัด
- **เนื้อหาต้องห้าม** — ไม่สามารถใช้เนื้อหาที่รุนแรง ลามก หรือละเมิดลิขสิทธิ์
- **เนื้อเพลงที่มีลิขสิทธิ์** — หลีกเลี่ยงการคัดลอกเนื้อเพลงที่มีลิขสิทธิ์ของศิลปินอื่น
