## 1. What is Kling AI?

### What is this topic?

Kling AI is the latest AI tool for creating digital works, developed by the Large Model Algorithm team at **Kuaishou** (the maker of Kwai, the famous video app). It combines two core technologies:

- **@Kolors** → image-generation technology (Image Generation)
- **@Kling** → video-generation technology (Video Generation)

into one platform that does both images and video, with controllable content-editing tools.

### What you can use it for

Kling AI supports two main user groups:

**[1] For creators (individuals / organizations)**
- An online creation platform on web and mobile
- Access at: [kling.ai/app](https://kling.ai/app)

**[2] For developers (individuals / organizations)**
- An API to build on within your own systems
- Access the API at: [kling.ai/dev](https://kling.ai/dev)

### Quick summary

Kling AI = a professional-grade AI platform for image + video creation from Kuaishou, with an API for developers.

## 2. Quick Start — get started with the API in 5 steps

> Reference: [Quick Start Guide](https://kling.ai/document-api/quickStart%2FuserManual)

### What is this topic?

A detailed getting-started guide for connecting to the Kling AI API, from the beginning until it's actually working.

### How to use it (Step-by-Step)

---

#### Step 1: Go to the KlingAI API Platform

1. Go to **[https://kling.ai/dev](https://kling.ai/dev)**
2. View the Product page you want:
   - **Video Generation Model** → [kling.ai/dev/pricing?scrollTo=video](https://kling.ai/dev/pricing?scrollTo=video)
   - **Image Generation Model** → [kling.ai/dev/pricing?scrollTo=image](https://kling.ai/dev/pricing?scrollTo=image)
   - **Intelligent Scenarios** (Virtual Try-On) → [kling.ai/dev/pricing?scrollTo=tryon](https://kling.ai/dev/pricing?scrollTo=tryon)

---

#### Step 2: Buy a Resource Package

There are 3 types of packages to choose from:
- **Video Generation Package** — for creating video
- **Image Generation Package** — for creating images
- **Virtual Try-On Package** — for virtually trying on clothes

> 💡 There's also a **Trial Resource Package** for testing before buying.

---

#### Step 3: Get your API Credentials

After buying a package, go to the Account page to get:
- **AccessKey** (`ak`) — your identity code
- **SecretKey** (`sk`) — your secret code

> ⚠️ Keep the SecretKey secret; don't share it with anyone.

---

#### Step 4: Connect to the API

Use the info from Step 3 to create a JWT Token, then call the API (see how to create the JWT in `02-api-reference-ทั่วไป.md`).

**Base URL:**
```
https://api-singapore.klingai.com
```

---

#### Step 5: Test it

Call a simple API first, e.g. create a video from Text:

```python
import requests

API_TOKEN = "your_jwt_token_here"
BASE_URL = "https://api-singapore.klingai.com"

response = requests.post(
    f"{BASE_URL}/v1/videos/text2video",
    headers={
        "Authorization": f"Bearer {API_TOKEN}",
        "Content-Type": "application/json"
    },
    json={
        "model": "kling-v2-6",
        "prompt": "A cat playing piano in a cozy jazz bar, warm lighting",
        "duration": "5",
        "aspect_ratio": "16:9"
    }
)

data = response.json()
task_id = data["data"]["task_id"]
print(f"Task ID: {task_id}")
```

Then use the `task_id` to query the status until it's done.

### Cautions

- Generated videos are **deleted within 30 days**; download them before they expire
- The result URL is **temporary only**; save it immediately upon receipt
- The API is Async — you must **poll** the status until the job is done

## 3. Changelog — latest updates

> Reference: [Changelog](https://kling.ai/document-api/apiReference%2FupdateNotice)

### What's interesting in the latest update (2026)

**🚀 Kling Native 4K (Kling VIDEO 3.0)**

Kling supports **Native 4K video generation** with one click, good for:
- Advertising work
- Films
- Commercial content

Benefits of Native 4K:
- Professional-grade quality, no upscaling that degrades the image
- Easy to use, no technical knowledge needed
- More cost-effective than expensive third-party tools

**💳 Payment system changed to Stripe**

From Checkout to Stripe for greater security and convenience.

> ⚠️ If purchasing in an organization's name and you need a tax invoice, you must select **"I'm purchasing as a business"** and enter the Tax ID at payment, otherwise it's treated as a personal purchase and the tax invoice details can't be edited later.
