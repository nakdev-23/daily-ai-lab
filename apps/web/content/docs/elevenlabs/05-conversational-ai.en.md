# Conversational AI — a voice assistant that converses 🗣️

> Adapted from the official documentation at [elevenlabs.io/docs](https://elevenlabs.io/docs), the Conversational AI / Agents section

**Conversational AI** lets you build a **voice agent** that converses with users in real time, e.g. a call bot, a voice Q&A assistant, or a speaking character in an app.

## 🧩 Components of an agent

| Part | Role |
|---|---|
| **Speech to Text** | Listen and transcribe the user's speech into text |
| **LLM** | The brain that understands and works out the answer |
| **Text to Speech** | Turn the answer into speech |
| **Turn-taking** | Manage the speak-listen rhythm naturally (no talking over each other) |
| **Knowledge base** | Documents/data the agent references in its answers |

## ⭐ Customizable

- The agent's **personality/role** (system prompt)
- The **voice** it speaks in (choose/clone)
- The **knowledge base** — upload documents so it answers from real data
- **Tools** — let the agent call APIs / take further action
- **Languages** — supports many languages

## ▶️ Start building (overview)

1. Go to the **Conversational AI → Create agent** menu
2. Set the role/instructions (e.g. "you're a coffee shop receptionist, speak politely")
3. Choose a voice and language
4. Add a knowledge base if you want it to answer from specific data
5. Test the conversation on the web, then embed it in a website/app or call it via API/SDK
