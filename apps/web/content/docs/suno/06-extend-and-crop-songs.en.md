# Extend and Crop — extend and trim songs

One of the most common problems is "the song is too short." Suno has two important features to handle this: **Extend** and **Crop**.

---

## How long is a Suno song?

The length of a song created in Suno depends on the version:

| Model | Initial length | Max length after Extend |
|-------------|--------------|----------------------|
| **v4** | ~2–4 min | ~8 min |
| **v4.5** | ~2–4 min | ~8 min |
| **v5** | ~2–4 min | ~8 min |

> A single song can be Extended multiple times up to a maximum of about 8 minutes.

---

## Extend

**Extend** is the feature that continues a song to be longer from where it stopped; the AI creates a continuing section that sounds smooth (flows well).

### How to use Extend

1. Open the song you want to extend
2. Click the **"..."** button (three dots) or the Options menu
3. Choose **"Extend"**
4. Suno creates a new continuing section after the original song
5. Check the result and repeat if you want it longer

### Extend Options

When you click Extend, you can:

- **Let the AI decide** — the AI continues the song in the original style
- **Specify new Lyrics** — enter lyrics for the next section
- **Specify a new Style** — change the style slightly for the Bridge or Outro
- **Choose the starting point** — set what second to continue from

### Use Extend to build a complete song structure

The way the pros like to use it:

```
Step 1: create the song (Verse + Chorus)
Step 2: Extend to add a Bridge
Step 3: Extend to add a repeated Chorus
Step 4: Extend to add an Outro
```

Result = a perfect song with a complete structure.

## Crop

**Crop** (cutting unwanted parts out of the song) helps you pick only the best parts of the song.

> **Note:** Crop is a feature only for **Pro** and **Premier** users.

### How to use Crop

1. Open the song you want to trim
2. Click the **"..."** button and choose **"Crop"**
3. Drag the Handles on the Timeline to select the range you want
4. Click **"Confirm"** or **"Save"**

### Use Crop when:

- The song has a bad opening you want to cut out
- The end of the song is too long
- You want only the Chorus section for use

---

## Replace Section

**Replace Section** (replacing a part you don't like with a new one) is a feature that lets you fix a specific spot without creating an entirely new song.

### How to use Replace Section

1. Open the song in edit mode
2. Select the section you want to change (drag on the Timeline)
3. Click **"Replace Section"**
4. Specify new Lyrics or Style for that section
5. The AI creates a new section to replace the old one

### Examples of using Replace Section

- The vocals in the 2nd verse are bad → use Replace Section just for that verse
- The Bridge doesn't fit the song → change the Bridge without affecting other parts
- You want different lyrics in the same section → replace only the Lyrics

---

## Tips for using Extend effectively

### 1. Plan the structure in advance

Before creating the song, plan how many sections you want:
```
Intro (4 bars) → Verse 1 → Pre-Chorus → Chorus → Verse 2 → Chorus → Bridge → Chorus → Outro
```

### 2. Extend step by step

Don't Extend too long at once; do 1–2 minutes at a time to check quality.

### 3. Add Lyrics in the Extend

If you add Lyrics for the continuing section, the song flows more than letting the AI think it up:
```
[Bridge]
Some days are hard, some days it hurts
But I still fight, I won't give up easily
```

### 4. Beware of sudden style changes

If you Extend and change the Style entirely, it may make the song sound jarring; change gradually.

## FAQ about Extend

**Q: How many times can I extend?**
A: You can extend multiple times up to a total length of about 8 minutes.

**Q: Will an Extended song sound continuous?**
A: The AI is designed to flow well, but sometimes it may be slightly jarring; try again if not satisfied.

**Q: Can I Extend any song?**
A: You can with any song created in Suno, but old songs created with old models may have limitations.

**Q: If an Extend turns out bad, can I delete it?**
A: The Extended part is a new song; you can delete it without affecting the original song.
