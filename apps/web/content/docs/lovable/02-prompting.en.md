# Write Prompts for Lovable 💬

> Compiled in English from the official docs at [docs.lovable.dev](https://docs.lovable.dev/)

How good the app turns out depends on how you instruct it — Lovable understands plain language, but the clearer the better.

## ✍️ Instruction principles

- **Start from the big picture** — say what kind of app it is and what it does
- **Then get into details** — add features one at a time
- **Be specific** — say the look, the data you store, the behavior you want
- **Step by step** — don't ask for ten changes in one message

Example:
> "Build a note-taking site where users can log in and each person sees only their own notes; a note has a title, content, and a date"

## 💬 Chat mode vs ✏️ Edit

| Mode | What it's for |
|---|---|
| **Chat / Default** | Chat to adjust the app, add features, change behavior |
| **Specific Edit** | Point directly at the element to edit (e.g. a button's text/color) |

## 💡 Tips

- If the result isn't right, explain more specifically instead of repeating the same instruction
- Say "why" too, e.g. "the button should stand out more because it's the main action"
- Check each feature works before moving on
