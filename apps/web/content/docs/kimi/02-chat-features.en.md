# Kimi chat features 💬

> Compiled in English from Kimi's (Moonshot AI) official docs — [kimi.com](https://www.kimi.com/)

**Kimi** is an AI assistant from Moonshot AI famous for its **very long context (long context)** — it reads large documents/files in one go, great for summarizing, analyzing, and researching.

## ⭐ Highlights

| Feature | Description |
|---|---|
| **Long context** | Accepts very long text/documents in a single conversation |
| **File reading** | Upload PDF, Word, images, etc. for it to summarize/follow up on |
| **Web search** | Pulls the latest information from the internet to answer |
| **Multilingual** | Understands and answers in many languages |

## ▶️ General usage

1. Go to [kimi.com](https://www.kimi.com/) and start chatting
2. Upload a file (e.g. a PDF report), then ask "Summarize the key points for me"
3. Turn on web-search mode when you want current information
4. Keep asking in one conversation — Kimi remembers long context

## 💡 What kind of work is it good for

- Summarizing long documents/research
- Comparing several files at once
- Researching topics that require referencing the latest information
