# Lovable — chat and get a whole web app 💗

> Compiled in English from the official docs at [docs.lovable.dev](https://docs.lovable.dev/)

**Lovable** is an AI web-app builder that works as "type a conversation, get an app" — you describe in plain language the kind of app you want, and Lovable builds both the frontend and the backend for you, with a built-in database and login system. It's great for people who want to make a real website without knowing how to code.

## 📖 Terms worth knowing

| Term | Plain meaning |
|---|---|
| **Prompt** | The text we give the AI to say what we want |
| **Frontend** | The web interface users see |
| **Backend** | The back-end system, e.g. database/authentication |
| **Supabase** | The database+auth service Lovable connects for you built-in |
| **Publish** | Put the app online for others to use |
| **Chat / Edit mode** | The mode to chat-adjust the app vs the mode to edit specific details |

## ⭐ Highlights

- **Type plain language, get a real app** — no coding needed
- **Complete frontend + backend** in one place
- **Connects Supabase** for database and login
- **Connects GitHub** to sync code out for further editing
- **Publish instantly** with your own domain

## 🚀 Getting started

1. Go to [lovable.dev](https://lovable.dev/) and sign up
2. Type out the app you want, e.g. "A note-taking site with login that saves each person's notes"
3. Watch Lovable build the app, then chat to refine it (change colors, add pages, etc.)
4. Connect Supabase if you need to store data, then click **Publish** to go online
