# GLM Coding Plan — use GLM with coding tools 💻

> Compiled in English from the official docs at [docs.z.ai](https://docs.z.ai/devpack/overview)

The **GLM Coding Plan** is a flat monthly package that lets you use GLM models (e.g. GLM-4.6) with popular **AI coding tools**, at a more economical price than paying per token.

## 🔌 What tools can it be used with?

Because Z.ai has an **Anthropic/OpenAI-compatible** endpoint, it connects to many code tools, e.g.:
- **Claude Code**
- **Cline / Roo Code / Kilo Code**
- **OpenCode** and other tools that accept an OpenAI/Anthropic-style API

## ⚙️ General setup

The idea is to point the tool to use **z.ai's base URL** + your **API key**. For example, with Claude Code:
- Set the base URL to z.ai's Anthropic-compatible endpoint (`https://api.z.ai/api/anthropic`)
- Enter your z.ai API key
- Choose a GLM model

> For the exact steps for each tool, see the Coding/DevPack section of the z.ai docs

## 💰 Why people like it

- **Better value** than paying per token for heavy coders
- GLM-4.6 is good at code/agent work
- Use the familiar flow of your preferred tool

## 💡 Tips

- Start with a small package to try it first
- Use it with Cursor/Claude Code/Cline as you prefer
- Watch the quota/limits of your chosen package
