# การแก้ไขและปรับแต่งงาน

> อ้างอิงหลัก: [Modifying Your Creations](https://docs.midjourney.com/hc/en-us/articles/33329329805581-Modifying-Your-Creations)

---

## ภาพรวมตัวเลือกแก้ไข

หลังสร้างภาพ Midjourney มีตัวเลือกแก้ไขมากมาย แบ่งตามวัตถุประสงค์:

---

## 1. เพิ่มคุณภาพ

### Upscale Subtle
- เพิ่มความละเอียด 2x
- รักษาสไตล์เดิม
- ใช้เมื่อ: พอใจกับภาพแล้ว แค่ต้องการขนาดใหญ่ขึ้น

### Upscale Creative
- เพิ่มความละเอียด 2x + เพิ่มรายละเอียดใหม่
- Midjourney ตีความและเพิ่มรายละเอียด
- ใช้เมื่อ: ต้องการให้ภาพดูสมบูรณ์ยิ่งขึ้น

---

## 2. สร้างแบบปรับแต่ง

### Vary Subtle
- เปลี่ยนเล็กน้อย
- ใช้เมื่อ: ชอบภาพมาก ต้องการปรับ Refinement เล็กน้อย

### Vary Strong
- เปลี่ยนมากขึ้น
- ใช้เมื่อ: ต้องการทางเลือกใหม่ในทิศทางเดิม

### Vary Region
- เลือกพื้นที่เฉพาะแล้วสร้างใหม่แค่ส่วนนั้น
- ใช้เมื่อ: ต้องการแก้ไขจุดเฉพาะ

---

## 3. ขยายขอบเขต

### Zoom Out 2x
- ขยายออกทุกทิศ 2 เท่า
- ใช้เมื่อ: ต้องการเห็นบริบทกว้างขึ้น

### Zoom Out 1.5x
- ขยายออกเล็กน้อย
- ใช้เมื่อ: ต้องการขยายนิดเดียว

### Pan (ซ้าย/ขวา/บน/ล่าง)
- ขยายในทิศทางเดียว
- ใช้เมื่อ: ต้องการภาพ Panoramic หรือขยายเฉพาะด้าน

---

## 4. แก้ไขด้วย Editor

### Erase (ลบ)
- ลบส่วนที่ไม่ต้องการ
- AI เติมส่วนที่ลบอัตโนมัติ

### Repaint (ทาสีใหม่)
- เลือกพื้นที่และสร้างใหม่ด้วย Prompt

### Outpaint (ขยายออก)
- ขยายภาพออกไปทิศทางใดก็ได้ใน Editor

---

## 5. ปรับ Prompt

### Remix Mode
- แก้ไข Prompt ขณะทำ Vary
- ใช้เมื่อ: ต้องการเปลี่ยน Prompt แต่ยังรักษาโครงสร้างหลัก

---

## Workflow แนะนำ

### Workflow 1 — สำหรับงาน Exploration
```
Generate → ถ้าไม่ถูกใจ → Re-run
         → ถ้าใกล้เคียง → Vary Strong
         → ถ้าเกือบดี → Vary Subtle
         → ถ้าพอใจ → Upscale
```

### Workflow 2 — สำหรับงาน Commercial
```
Generate ด้วย Draft Mode → 
ทดสอบหลาย Prompt →
เลือก Direction →
Generate จริง →
Upscale →
แก้ไขด้วย Vary Region ถ้าจำเป็น →
Download
```

---

## สรุป

Midjourney มีเครื่องมือแก้ไขครบครัน ตั้งแต่การขยายคุณภาพ การสร้าง Variation การขยายขอบเขต และการแก้ไขในตัว ทำความเข้าใจแต่ละเครื่องมือจะช่วยให้ Workflow มีประสิทธิภาพและได้ภาพที่ดีที่สุด
