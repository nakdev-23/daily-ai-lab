# Workspace — your cloud workroom 💻

> Compiled in English from the official docs at [docs.replit.com](https://docs.replit.com/)

The **Workspace** is Replit's code-writing-and-running area that works in the browser, with nothing to install on your machine.

## 🗂️ Key parts

| Part | What it does |
|---|---|
| **Editor** | Write/edit code (with autocomplete, AI help) |
| **Console / Output** | See the program's results |
| **Shell / Terminal** | Run commands, install packages |
| **Files** | Manage files in the project |
| **Run ▶️** | Run the app and see results instantly |

## 🌐 Running in the cloud

- Click **Run** and the code runs on Replit's servers
- See results in the preview window in your browser
- Supports many languages (Python, JavaScript, etc.)

## 👥 Collaboration

Replit lets multiple people edit the same code **at the same time in real-time** (like a Google Docs for code), great for learning, teaching, or doing team projects.

## 💡 Tips

- Use the built-in AI to help explain/fix code
- Everything is in the cloud — open any machine and continue working
- Use the Shell to freely install extra libraries
