# Troubleshooting and account management

This section gathers the problems users encounter most often and clear ways to fix them, covering everything from login to Credits and download issues.

---

## Login Issues

### Problem: can't log in with a phone number

Suno has discontinued phone-number login for some users.

**How to fix:**
1. Use Google, Discord, Microsoft, or Apple instead
2. If you previously used a phone number, try logging in with the Email linked to that account
3. Contact Support if you still can't get in

### Problem: can't log in with Email

**Fix steps:**
1. Check that you typed the Email correctly
2. Click **"Forgot Password"** to reset the password
3. Check the Spam Folder in your email for the reset link
4. If it still doesn't work, try logging in another way (Google, Discord)

### Problem: the account is Suspended

**Common causes:**
- Violating the Community Guidelines
- Suspected of being under 13
- Unusual activity (Spam or Bot)

**How to fix:** Contact Suno Support directly via email or Discord.

## Credit issues

### Problem: Credits disappeared or reset abnormally

**How to check:**
1. Go to **Settings > Account** or **Profile**
2. Look at the remaining Credits and the reset date

**Reasons Credits disappear:**
- Credits reset on the plan's monthly cycle (not the 1st of the month, but on the signup date)
- Add-on Credits you bought may expire
- A Failed song creation may sometimes have already deducted credits

**How to fix:** If Credits disappear for no reason, contact Support and state the date and time.

### Problem: I've run out of Credits, what do I do?

**Options:**
1. **Wait for the reset** — Credits reset on your membership anniversary
2. **Buy more** — buy more Credits from Settings > Billing
3. **Upgrade the plan** — switch to a plan with more Credits

## Download problems

### Problem: can't download WAV

**Cause:** WAV (a high-quality, uncompressed audio file) is supported only on the **Premier** plan.

**How to fix:**
- Upgrade to Premier to download WAV
- Or use MP3, which is supported on the Pro and Premier plans

### Problem: a song doesn't show in the profile

**Common causes:**
- The song is set to Private — it won't show on the public page
- The song was deleted or is in the Trash
- The Browser's Cache is stuck

**How to fix:**
1. Go to **Library** to see all your songs (including Private)
2. Check the **Trash** for songs that may have been deleted
3. Press Ctrl+F5 or Cmd+Shift+R to Hard Refresh the Browser

### Problem: the downloaded file is incomplete

**How to fix:**
1. Try downloading again
2. Use a different Browser (Chrome recommended)
3. Check your Internet speed

## Account Management

### Change the Display Name

**Display Name** (the name others see in Suno)

1. Go to **Profile** or **Settings**
2. Click **"Edit Profile"** or **"Display Name"**
3. Type the new name
4. Save

> **Note:** The Display Name can't duplicate another user's.

### Change the Profile Avatar

1. Go to **Profile > Settings**
2. Click your current profile picture
3. Upload a new picture (supports JPG, PNG, GIF)
4. Save

### Check the plan type

1. Go to **Settings > Billing**
2. It shows:
   - The current plan type (Free/Pro/Premier)
   - The expiration date
   - The remaining Credits
   - The payment history

## Common technical problems

### A song won't finish / is stuck

**How to fix:**
1. Wait 1–2 minutes; sometimes the Server is slow
2. Refresh the web page
3. Check that you're connected to the Internet
4. Try creating a new song with a different Prompt

### The created song doesn't match what you want

**Cause:** The AI creates varied results, different each time.

**How to fix:**
- Try creating several times; each time gives a different song
- Make the Style Prompt more detailed
- Use Custom Mode instead of Simple Mode for more control
- Try lowering Creativity with the Creative Sliders

### The vocals still aren't clear

**How to fix:**
- Use a Style Prompt like `"clear vocals"`, `"articulate singing"`, `"crisp vocals"`
- Avoid very Dense Styles, such as Heavy Metal + Choir + Orchestra in one song

## Getting Help

### Ways to contact Support

| Channel | Detail |
|--------|---------|
| **Help Center** | help.suno.com |
| **Discord** | the Suno Discord server — a large community |
| **Email Support** | via the form in the Help Center |
| **Feedback Form** | sunomusic.typeform.com |

### Before contacting Support, you should:

1. Check the Help Center first — there may already be an answer
2. Note the details: date/time, what happened, the steps you took before the problem
3. Take a Screenshot to attach

## Performance tips

> **Tip:** Use the latest Chrome for maximum performance, especially for Studio.

> **Tip:** Clear the Browser's Cache if Suno is slow or showing old data.

> **Tip:** Don't open Suno in many Tabs at once, especially when using Studio.

> **Tip:** If a song takes very long to create, it may be because the Server is congested during Peak Time; try creating at a different time.
