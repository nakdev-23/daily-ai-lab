# Getting started with Cursor 🚀

> Adapted from the official documentation at [cursor.com/docs](https://cursor.com/docs), the Getting Started section

**Cursor** is a code editor with AI built in, built on top of VS Code. If you've used VS Code before, it'll feel familiar immediately.

## 🧭 Installation steps

1. Download from [cursor.com](https://cursor.com/) (Windows / macOS / Linux)
2. Install, open the program, then log in / sign up
3. On first launch, choose **import from VS Code** to bring over your theme, shortcuts, and extensions

## 🗂️ The 3 main AI features

| Feature | What it does | Shortcut (default) |
|---|---|---|
| **Tab** | Auto-completes code while typing | `Tab` |
| **Inline Edit** | Command edits to selected code in plain language | `Ctrl/Cmd + K` |
| **Chat / Agent** | Chat with / command the whole project | `Ctrl/Cmd + L` |

## ▶️ Try it for the first time

1. Open your project folder (File → Open Folder)
2. Wait for Cursor to **index the codebase** (so the AI understands the whole project)
3. Try typing code and pressing `Tab` to accept a suggestion
4. Select a chunk of code, press `Ctrl/Cmd + K`, and type "make it async"
