# Logging in and connecting accounts

> Main reference: [Logging In Connecting Accounts](https://docs.midjourney.com/hc/en-us/articles/33390994570509-Logging-In-Connecting-Accounts)

---

## How to log in

### On the website
1. Go to [midjourney.com](https://midjourney.com)
2. Click **"Sign In"**
3. Choose a login method:
   - **Google** — use a Gmail account
   - **Discord** — use a Discord account
   - **Email** — use email and password

---

## Connecting a Discord account

If you've used Midjourney through Discord before:
1. Log in with Discord on the web
2. The same account, same GPU Time, everything stays intact
3. Old images from Discord appear in the Archive on the web

---

## Moving from Discord to the web

Those who used Discord before can move to the web easily:
- Use the same account, no need to sign up again
- GPU Time and the plan don't change
- All images stay in the Archive

---

## Common login problems

**Logged in with Google and found a new account**
→ Check that you're using the same Email you signed up with

**Forgot password**
→ Use "Forgot Password" and reset via email

**Discord account is Disconnected**
→ Go to Account Settings → Connections → reconnect Discord

---

## Account settings

After logging in, you can manage your account from Settings:

### Personal information
- Change the Username or Display Name
- Update the profile picture
- Change the primary email

### Notification Settings
- Choose to accept or decline email notifications
- Set up the Newsletter (news emails from Midjourney)

### Connected Accounts
- See which accounts are connected (Google, Discord)
- Add or remove connections

---

## Two-Factor Authentication (2FA)

Midjourney recommends enabling 2FA (two-step authentication — a security system that requires verifying your identity with a second method, such as SMS or an Authenticator App) for account security.

1. Go to Settings → Security
2. Choose "Enable Two-Factor Authentication"
3. Use an App such as Google Authenticator or Authy

---

## Summary

Logging in with Google or Discord uses the same account; no need to sign up again if you've used Discord before. Enable 2FA for account security, and connect several accounts as you wish.
