# What is Perplexity

**Perplexity AI** is a new-generation search engine that uses Artificial Intelligence (AI) to search and summarize information from the internet. Instead of showing a list of links like Google, Perplexity **answers your question directly**, attaching citations (links to the websites used as the basis for the answer) so you can verify immediately.

---

## Why is Perplexity different from Google?

| Feature | Google | Perplexity |
|---|---|---|
| How it shows results | A list of links | A summarized answer with citations |
| Answering questions | You must click in and read yourself | Answers directly on one page |
| Sources | Has links but doesn't specify which data was used | Clearly specifies which site the data came from |
| Interaction | Search anew every time | Ask follow-ups like a conversation |

---

## How does Perplexity work?

When you type a question into Perplexity, the system:

1. **Searches the internet** — scans many websites in real time (live data from the internet at that moment)
2. **Analyzes the content** — the AI reads and compares data from many sources
3. **Summarizes an answer** — writes a concise, easy-to-understand answer
4. **Attaches Citations** — specifies every source so the user can click to verify

---

## Who should use Perplexity?

Perplexity is good for:

- **Students** — research for studies, find research data
- **Business people** — follow the news, analyze markets, find competitor info
- **Developers** — use the API (Application Programming Interface — a channel for programs to connect and use a service) to build applications with information-search capability
- **Those who need accurate information** — because every answer has a verifiable citation

---

## Perplexity's main products

Perplexity is available in two main forms:

### 1. Perplexity.ai (website and app)
A search tool used through a browser or mobile app, good for general users who want to search for information in daily life.

### 2. Perplexity API (the connector for developers)
A channel for software developers to use Perplexity's capabilities in their own applications. There are 4 main APIs:

- **Agent API** — an API for building an AI Agent (an AI agent that can do multiple steps itself), using models from many providers in one place
- **Search API** — an API for searching the web Raw (raw — you get a list of links and text, not a summarized answer), good for developers who want raw data
- **Sonar API** — an API for AI Q&A with built-in web search, similar to using Perplexity via API
- **Embeddings API** — an API for converting text into vectors (Vector — numbers representing the meaning of text), used in semantic search systems

---

## Perplexity's highlights

- **Live data** — pulls data from the internet in real time, not static data
- **Transparent** — every answer has a verifiable citation
- **Easy to use** — ask in natural language, no need to memorize keywords
- **Extensible** — has an API for developers who want to build their own apps

## Summary

Perplexity is the next step in information search, combining the convenience of an AI Chatbot with the reliability of real web search, giving you fast, accurate answers with always-verifiable sources. Whether used as a personal tool or developed into an application via the API, it can do it all.
