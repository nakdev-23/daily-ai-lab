# Modifying and refining your work

> Main reference: [Modifying Your Creations](https://docs.midjourney.com/hc/en-us/articles/33329329805581-Modifying-Your-Creations)

---

## An overview of the editing options

After creating an image, Midjourney has many editing options, divided by purpose:

---

## 1. Increase quality

### Upscale Subtle
- Increases resolution 2x
- Keeps the original style
- Use when: you're satisfied with the image, just want it larger

### Upscale Creative
- Increases resolution 2x + adds new detail
- Midjourney interprets and adds detail
- Use when: you want the image to look more complete

---

## 2. Create with adjustments

### Vary Subtle
- Changes slightly
- Use when: you like the image a lot, want slight Refinement

### Vary Strong
- Changes more
- Use when: you want a new option in the same direction

### Vary Region
- Select a specific area and recreate only that part
- Use when: you want to fix a specific spot

---

## 3. Expand the boundaries

### Zoom Out 2x
- Expand all directions 2 times
- Use when: you want to see a wider context

### Zoom Out 1.5x
- Expand a little
- Use when: you want to expand just a bit

### Pan (left/right/up/down)
- Expand in one direction
- Use when: you want a Panoramic image or to expand a specific side

---

## 4. Edit with the Editor

### Erase
- Remove unwanted parts
- The AI fills the erased part automatically

### Repaint
- Select an area and recreate it with a Prompt

### Outpaint
- Expand the image in any direction in the Editor

---

## 5. Adjust the Prompt

### Remix Mode
- Edit the Prompt while doing a Vary
- Use when: you want to change the Prompt but still keep the main structure

---

## Recommended Workflows

### Workflow 1 — for Exploration work
```
Generate → if you don't like it → Re-run
         → if close → Vary Strong
         → if almost good → Vary Subtle
         → if satisfied → Upscale
```

### Workflow 2 — for Commercial work
```
Generate with Draft Mode → 
test several Prompts →
choose a Direction →
Generate for real →
Upscale →
edit with Vary Region if needed →
Download
```

---

## Summary

Midjourney has a complete set of editing tools, from increasing quality, creating Variations, expanding the boundaries, to built-in editing. Understanding each tool helps your Workflow be efficient and get the best image.
