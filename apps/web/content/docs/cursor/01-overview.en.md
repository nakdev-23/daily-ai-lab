# Cursor — a code editor with AI built in

> Adapted from the official documentation at [cursor.com/docs](https://cursor.com/docs)

**Cursor** is a **code editor designed to work alongside AI**, developed by Anysphere. It builds on VS Code (familiar look/extensions) but adds AI abilities deep into every step of coding — from auto-completing code to letting the AI be an "agent" that edits multiple files on its own.

---

## 📖 Terms worth knowing

| Term | In plain words |
|---|---|
| **Tab** | AI auto-completion — press Tab to accept what it predicts you'll type next |
| **Inline Edit (Cmd/Ctrl-K)** | Highlight code and command an edit in plain language, e.g. "make it async" |
| **Chat** | A Q&A chat about your code in the side panel |
| **Agent** | Have the AI edit/create multiple files itself, run commands, and check the work |
| **@-symbols** | A way to reference context, e.g. `@file` `@codebase` `@web` `@docs` |
| **Rules** | Rules/guidelines that tell the AI to follow the project's style |
| **MCP** | A standard for connecting the AI to external tools/data |

---

## ⭐ Main abilities

- **Tab — smart code completion** predicts multiple lines/spots at once
- **Inline Edit (Cmd-K)** command edits to the selected code in natural language
- **Chat (Ask)** ask about the code, explain, find bugs, referencing the codebase
- **Agent** the agent works on its own: edits multiple files, runs the terminal, installs packages, then loops until done
- **Understands the whole codebase** by indexing + referencing with @-symbols (`@web`, `@docs`, `@file`)
- **Choose your model** — Claude, GPT, Gemini, etc.
- **Rules & MCP** adapt it to your project and connect external tools

---

## 🚀 Getting started

1. Download Cursor from [cursor.com](https://cursor.com/) (macOS / Windows / Linux)
2. Open your project (open your code folder) — you can migrate from VS Code with extensions/keymaps
3. Try it: type code and press **Tab**, select code and press **Cmd/Ctrl-K** to command an edit, open the **Chat/Agent** panel to have the AI help with a whole job
4. Set up the project's **Rules** so the AI writes in the team's style
