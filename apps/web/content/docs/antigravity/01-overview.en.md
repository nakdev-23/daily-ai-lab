# Google Antigravity — coding alongside AI agents 🚀

> Adapted from the official documentation at [antigravity.google](https://antigravity.google/)

**Google Antigravity** is Google's new-generation software development platform, designed for **an era where AI agents do the coding for us** — instead of typing every line yourself, you give it a task and the agent plans, writes code, runs tests, and even opens a browser to check its own work. It's powered by Gemini models.

## 📖 Terms worth knowing

| Term | In plain words |
|---|---|
| **Agent** | An AI assistant that carries out multi-step work on its own to completion, not just answering message by message |
| **Agent Manager** | The control view for dispatching and watching multiple agents work at once |
| **Editor** | The code-editing window (like VS Code) with an agent built in |
| **Artifacts** | The work agents produce, e.g. plans, screenshots, reports |
| **Browser** | A built-in browser the agent uses to test the web pages it writes |

## ⭐ Highlights

- **Works at the agent level** — give it a task and the agent handles the steps itself
- **Control multiple agents at once** via the Agent Manager
- **Real verification** — the agent opens a browser to test and sends you screenshots
- **Powered by Gemini** — Google's latest model
- **Familiar** — the Editor builds on the VS Code style

## 🚀 Getting started

1. Download Antigravity from [antigravity.google](https://antigravity.google/) and log in with your Google account
2. Open your project folder
3. Type a task, e.g. "add a login page with email validation"
4. Watch the agent plan → write code → test, then review the Artifacts/screenshots it produces
