# Describe — analyze an image into a Prompt

> Main reference: [Describe](https://docs.midjourney.com/hc/en-us/articles/32497889043981-Describe)

---

## What is Describe

The `/describe` command (analyzing an image — a feature that has Midjourney look at an image and create the Prompt expected to create it, working opposite to /imagine) lets you "go backward" from an image to a Prompt.

---

## How to use

### On Discord
```
/describe [upload an image]
```

1. Type `/describe`
2. Upload the image you want
3. Midjourney returns 4 different Prompts
4. Click 1, 2, 3, or 4 to create an image from that Prompt

### On the website
1. Go to the Create page
2. Click the Describe icon (or find it in the tools menu)
3. Upload the image

---

## Benefits of Describe

### 1. Learn to write Prompts
- Find an image you like on the Internet
- Use `/describe` to see what kind of Prompt creates that image
- Learn the vocabulary and patterns

### 2. Create images in the same style
- You have an image you like but don't know what Prompt was used
- Use `/describe` to find a close Prompt
- Adapt the Prompt and create new images

### 3. Analyze an artist's style
- Take an image by an artist you like and analyze it
- See how Midjourney describes that style
- Use those descriptions in your Prompt

---

## Example

**Input image:** a beautiful photo of a forest in autumn

**Prompts Midjourney returns:**
1. *"autumn forest path, golden leaves carpeting the ground, misty morning light filtering through ancient trees, serene and atmospheric, nature photography"*
2. *"fall foliage in old-growth forest, dappled sunlight through canopy, warm orange and yellow tones, wide angle landscape, photorealistic"*
3. *"peaceful woodland trail in October, fallen maple leaves, soft bokeh background, golden hour, canon 5d photography"*
4. *"enchanted forest in autumn, mystical light rays, red and amber leaves, impressionist painting style"*

---

## Observations

- The Prompt Midjourney returns may not produce an image 100% like the source
- But it gives a very good Vocabulary (the set of words used to write a Prompt)
- It's better for Inspiration than for Copying

---

## Tips

1. **Try every Prompt** — press 1-4 to see which Prompt gives the closest result
2. **Adjust the Prompt** — take the resulting Prompt and adjust it to match your needs
3. **Blend Prompts** — combine the good parts of several Prompts

---

## Summary

`/describe` is an excellent learning tool that helps you understand how Midjourney sees images and what kind of Vocabulary works well. Use it often to develop your Prompt-writing skills.
