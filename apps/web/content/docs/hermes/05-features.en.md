# Features — Hermes's capabilities

> Compiled from the official docs at [hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs/), the Features section

## 🔁 Learning Loop (learn and improve itself)

Hermes's unique heart — a closed feedback loop that lets it:
- **Build skills from experience** and improve them as it's used
- Remind itself to save knowledge
- Search its own past conversations for reference
- Understand "you" more deeply over time, across sessions

## 🧠 Persistent memory

Remembers data across sessions, searched with **FTS5 (full-text search)** and summarized with an **LLM** — close and reopen and it still remembers the context.

## 🧰 60+ built-in tools

Including:
- **Web** — search the web + browser control (web control)
- **Vision** — understand images
- **Image generation** — generate images
- **Text-to-Speech (TTS)** — convert text to speech
- and dozens more tools for general tasks

## 🔌 Supports MCP

Connect to **MCP servers** to add capabilities/connect external tools.

## 🧮 Multi-model reasoning

Can use multiple models to think/work, and connect to several providers (see **Integrations**).

> These capabilities are accessible via both the Terminal UI and the Gateway (chat on 20+ platforms — see **Messaging Platforms**)
